# Data license & provenance

This file records, for each kind of material in this repository, who produced it
and on what basis First Proof publishes it. `NOTICE` states the licenses; this
file states the provenance behind them.

The governing principle: **First Proof licenses only what First Proof produced or
holds the rights to.** Nothing here is a blanket grant over third-party work.

## Covered by CC-BY-SA-4.0 (see `LICENSE-DOCS`)

**Problem statements** (`batch-3-problems/`). Contributed by their authors for this
batch and curated by First Proof; published with the authors' names, as the call
for submissions announced (quoted below).

**Human solutions** (`batch-3-human-solution/`). Written by the problem authors for
First Proof as part of the benchmark design, and published as part of it.

**AI-generated solutions** (`batch-3-AI-solutions/`) **and raw run outputs**
(`batch-3-raw-outputs/`). These are the outputs of runs First Proof commissioned,
configured and executed. Each team supplied its system's source code, prompt and
configuration; First Proof supplied the LaTeX source of the ten problems as the
common input and ran each system on its own cloud account. The resulting corpus —
solutions, thinking traces, token logs, run metadata, and any scratch code the
models wrote while working — is published by First Proof as the evidence base the
benchmark exists to produce. The scratch code is a run artifact and is licensed
CC-BY-SA-4.0 with the rest of the output, not AGPL-3.0.

**Referee reports** (`batch-3-reviews/`). The referees wrote their comments into
review documents First Proof generated and supplied for the purpose. Publication
of the referee reports was announced in advance in First Proof's Batch 3 call for
submissions (quoted below), which states that the editorial board "will also
publish the source code for all tested systems, the AI solutions, the referee
reports, and the editorial board's scores for each solution." The reports are
published anonymized: each is identified by a stable reviewer number within its
submission (reviewer-1, reviewer-2, …), not by name. First Proof does not publish
referees' names, and names a referee only with their written consent.

**Cost table** (`batch-3-costs/`). Compiled by First Proof from run logs and
provider bills; see the README in that folder.

**Documentation.** READMEs and editorial material authored by First Proof.

## Covered by AGPL-3.0 (see `LICENSE`)

Source code First Proof wrote, wherever it appears in this repository.

## NOT licensed here — the participating teams' submitted code

    batch-3-submissions/

These are the participating teams' own codebases (harnesses, prompts and runners),
contributed so that First Proof could run them against the batch. They are
**not** First Proof's work, are **not** covered by either license file here, and
remain the copyright of their authors.

They are published on the basis of the Batch 3 call for submissions, which set the
terms of participation and made publication a condition of taking part. Under
"Eligibility of AI Systems" it reads: "An AI system will be eligible for the
benchmark if it is an open-source harness which calls publicly available models
via API." Under "Testing Protocol": "The source code/prompt/API keys for each AI
system must be provided to First Proof by October 1, 2026." And under
"Publication of Results": "After the solutions generated by AI systems are graded
by humans, the editorial board will publish each problem together with the name
of its author, the author's solution, and the author's descriptive statement. The
board will also publish the source code for all tested systems, the AI solutions,
the referee reports, and the editorial board's scores for each solution."

The call names no license. Each submission therefore remains its authors'
copyright, published under these submission terms. Where a team's code carries
its own license file, that license governs it; otherwise no permissions should be
assumed from its presence in this repository, and anyone wanting to reuse it
should approach its authors. No API keys are published.

## Future material

Any later contribution that originates with another author or submitter is **not**
swept under the grants above. It is published only with permission, licensed
CC-BY-SA-4.0 where First Proof holds the rights, and otherwise marked
"© respective authors, published with permission." Where the rights status of any
material is unclear, it is flagged and withheld rather than published.

## Relationship to First Proof's DARPA agreement

Batch 3 was carried out under DARPA Agreement HR0011263E126, in effect from 21 July
2026. The U.S. Government holds Unlimited Rights in data generated under it; the
licenses above are First Proof's own grants to the public and do not limit those
rights. As Article VIII.B of the agreement requires, this data carries the legend:
*"Use, duplication, or disclosure is subject to the restrictions as stated in
Agreement HR0011263E126 between the Government and the Performer."*
