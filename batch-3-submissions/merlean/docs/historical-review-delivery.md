# Historical review delivery and supervised reentry

Original-main and contextual proof-review calls receive an immutable historical-review index. It identifies complete saved independent proof-review responses, their exact transport provenance, and existing public-source packets. Complete reports and verified UTF-8 source members are read through the scoped artifact tool, including offline reviews. Each source member keeps its native receipt and content-hash provenance; binary originals are not presented as text. The existing verified public-source reader remains available when advertised. Historical favorable verdicts do not approve the current candidate. Blind original-question scope reviews do not receive this catalog or prior verdicts.

The host verifies report metadata, capability, prompt, raw answer, operation-receipt hashes, parsed campaign copy, independent fresh reviewer identity, and completed required delivery. Public packets use the native receipt/content verifier. Missing or changed material fails closed; no report or source certificate is manufactured.

An older segment stopped at an authenticated `assessment_handoff` may be eligible for an explicit `delivery_repair` resolution when this new delivery format supplies previously unregistered historical reports. The external proposal is created with `pilot_assessment_delivery_resolution.make_request(source, target, problem_id, authorization_evidence)` and passed to native continuation using `--assessment-delivery-resolution PATH`. It binds the fixed successor, exact parent manifest, original main, current candidate, saved handoff, report/source census, delivery format and implementation bytes, and external supervisor authorization.

Native preparation validates the proposal and preserves it in the immutable continuation checkpoint. Only the original main may reenter first. Findings, candidate, execution evidence, assessment keys, attempts and consumed budgets remain unchanged. The original handoff and every raw response remain intact. A failed first resumed main call does not reset this authority; later native continuations carry the same resolution lineage. A later handoff is a distinct event and is not covered by the old resolution. Reapplying the same delivery format as another repair is rejected.

This route repairs access to existing evidence. It does not renew an identical assessment, infer mathematical correctness, certify a source/use-site audit, or guarantee scientific progress. Any new scientific assessment must satisfy the ordinary main-owned action and evidence rules. Research clocks and model/account choices remain governed by the original continuation contract.

When native continuation reconstructs execution records in a different presentation, resolution still requires the exact old history digest. It obtains that ordered list only from an eligible completed review’s authenticated execution artifact, verifies its bytes and old digest, and compares canonical producer identities with native reconstruction. Missing history, changed artifacts or different execution evidence fail closed. The original handoff receipt is never rewritten.
