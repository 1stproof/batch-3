# MerLean — First Proof Batch 3

An autonomous mathematical research and paper-writing harness.

See [Docker commands, runtime API-key configuration, and output contract](deployment/batch3/README.md).

The exam runs online for up to 24 hours, switches unfinished research to honest partial-result writing at 22.75 hours, and uses event-driven Astra operations supervision. Original-question scope checks remain part of research acceptance and final paper review.

This repository contains source, tests, prompts, and the container definition. API keys are supplied only at runtime.
