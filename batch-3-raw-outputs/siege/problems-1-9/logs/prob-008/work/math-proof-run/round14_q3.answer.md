## 1. Check of the use of (SC): the telescoping distributions (proved; no GH used)

Notation: P phi = X phi + d phi, d = div_nu X, so d/dt [e^{J_t(z)} phi(g_t z)] = e^{J_t(z)} (P phi)(g_t z). L := Lip(d).

**Lemma 1.1 (u-leg).** Let a, b satisfy d(g_t a, g_t b) <= C e^{-theta|t|} d(a,b) for t <= 0 and J_t(a) <= C' + eta|t| for t <= 0, with 0 <= eta < theta. Then beta := lim_{t -> -inf} (J_t(b) - J_t(a)) exists, |beta| <= L C d(a,b)/theta, and
 U_{a,b}(phi) := int_{-inf}^0 [ e^{J_t(a)} phi(g_t a) - e^{-beta} e^{J_t(b)} phi(g_t b) ] dt
converges absolutely, |U_{a,b}(phi)| <= K ||phi||_{C^1} d(a,b) with K depending only on C, C', theta, eta, L (and an upper bound for d(a,b), e.g. diam M), and
 U_{a,b}(P phi) = phi(a) - e^{-beta} phi(b).
*Proof.* For t <= 0, J_t(b) - J_t(a) = -int_t^0 (d(g_s b) - d(g_s a)) ds and the integrand is bounded by L C e^{-theta|s|} d(a,b); so the limit exists, and r_t := J_t(b) - J_t(a) - beta satisfies |r_t| <= (LC/theta) e^{-theta|t|} d(a,b) =: R e^{-theta|t|} d(a,b). The integrand equals e^{J_t(a)} [ (phi(g_t a) - phi(g_t b)) + (1 - e^{r_t}) phi(g_t b) ], whose modulus is at most e^{C'+eta|t|} [ ||phi||_{C^1} C e^{-theta|t|} d(a,b) + R d(a,b) e^{R diam M} e^{-theta|t|} ||phi||_inf ] (using |1 - e^r| <= |r| e^{|r|}). This is <= K' ||phi||_{C^1} d(a,b) e^{-(theta - eta)|t|}, integrable on (-inf, 0], giving the bound. The same bound applied to the function t -> c_phi(t) (the integrand) shows c_phi(t) -> 0 as t -> -inf; c_phi is C^1 with c_phi' = c_{P phi}, and c_{P phi} is integrable by the same bound with P phi in place of phi. Hence U_{a,b}(P phi) = int_{-inf}^0 c_phi'(t) dt = c_phi(0) - 0 = phi(a) - e^{-beta} phi(b). ∎

**Lemma 1.2 (s-leg).** Let a, b satisfy d(g_t a, g_t b) <= C e^{-theta t} d(a,b) for t >= 0 and J_t(a) <= C' + eta t for t >= 0, eta < theta. Then beta := lim_{t -> +inf} (J_t(b) - J_t(a)) exists, |beta| <= LC d(a,b)/theta,
 V_{a,b}(phi) := int_0^{inf} [ e^{J_t(a)} phi(g_t a) - e^{-beta} e^{J_t(b)} phi(g_t b) ] dt
satisfies |V_{a,b}(phi)| <= K ||phi||_{C^1} d(a,b) and V_{a,b}(P phi) = -(phi(a) - e^{-beta} phi(b)).
*Proof.* Identical, with t >= 0 and the boundary term at t = 0 entering with the opposite sign. ∎

**Proposition 1.3 (one chain gives a solution of the transposed equation with a point-mass right-hand side).** Let (x_i) be one chain of (SC) (conditions (L1)-(L4), (E)), with limit p and shift tau. Then there are a distribution density Sigma of order <= 1 and a real number Omega > 0 with
 Sigma(P phi) = (1 - Omega) phi(x_0) for every smooth phi.
*Proof.* Let beta_i be the constant of the leg (x_i, x_{i+1}) given by Lemma 1.1 (i even; hypotheses (L1) and the first part of (L4)) or Lemma 1.2 (i odd; (L2) and the second part of (L4)); for legs of length 0 put beta_i = 0 and the leg distribution = 0. Put w_0 = 1, w_{i+1} = w_i e^{-beta_i}. Since |beta_i| <= K'' d(x_i, x_{i+1}) and (L3), W := lim w_i = exp(-sum beta_i) exists, and 0 < inf w_i <= sup w_i < inf. Define
 Sigma_0 := sum_{i even} w_i U_{x_i, x_{i+1}} - sum_{i odd} w_i V_{x_i, x_{i+1}}.
The series converges absolutely in (C^1)' by the bounds of 1.1/1.2 and (L3). Term by term, Sigma_0(P phi) = sum_i (w_i phi(x_i) - w_{i+1} phi(x_{i+1})) = phi(x_0) - W phi(p), using x_i -> p and continuity of phi.
Close up with (E): put q := g_tau x_0. The pair (p, q) satisfies d(g_t p, g_t q) <= C e^{-theta t} for t >= 0; and J_t(q) = J_{t+tau}(x_0) - J_tau(x_0) <= C'' + eta t for t >= 0 by the last clause of (L4); since |J_t(p) - J_t(q)| <= LC/theta, also J_t(p) <= C''' + eta t. So Lemma 1.2 applies to (p, q) (its proof uses d(a,b) only as a multiplicative constant; here use C e^{-theta t} directly), with a constant gamma: V_{p,q}(P phi) = -(phi(p) - e^{-gamma} phi(q)). Finally the orbit segment: F(phi) := int_0^tau e^{J_t(x_0)} phi(g_t x_0) dt (oriented integral; for tau < 0 it is minus the integral over [tau, 0]) satisfies F(P phi) = e^{J_tau(x_0)} phi(q) - phi(x_0). Put
 Sigma := Sigma_0 - W V_{p,q} + W e^{-gamma} e^{-J_tau(x_0)} F.
Then Sigma(P phi) = phi(x_0) - W phi(p) + W phi(p) - W e^{-gamma} phi(q) + W e^{-gamma} phi(q) - W e^{-gamma - J_tau(x_0)} phi(x_0) = (1 - Omega) phi(x_0), with Omega := W e^{-gamma - J_tau(x_0)} > 0. ∎

**Corollary 1.4 (how GH enters).** Under GH, let Sigma_A, Sigma_B, Omega_A, Omega_B come from the two chains of (SC). Then T := (1 - Omega_B) Sigma_A - (1 - Omega_A) Sigma_B satisfies T(P phi) = 0 for all phi, so T = c nu for a constant c (fact (F1): u = T/nu has Xu = 0, hence u is constant by L1). If both Omega's equal 1, already Sigma_A = c_A nu and Sigma_B = c_B nu.

## 2. (SC) for hyperbolic measures (sub-class result; proved modulo cited classical theorems)

**Cited (from memory).**
[KLY] Katok's horseshoe theorem with approximation of exponents and of measures (Katok 1980 for diffeomorphisms/3-dim flows; Lian-Young for C^2 flows in any dimension): if mu is an ergodic invariant probability of a C^2 flow, mu(Zero X) = 0, h_mu(g_1) > 0 and all exponents of mu other than the flow exponent are nonzero, then for every eps > 0 there is a compact invariant (uniformly) hyperbolic set Lambda_eps, on which the flow is topologically conjugate to the suspension of a transitive subshift of finite type with positive entropy, such that every invariant probability carried by Lambda_eps lies in the eps-weak* neighbourhood of mu (for a fixed finite set of test functions containing d) and the hyperbolic splitting on Lambda_eps has contraction/expansion rates within eps of the exponents of mu (so at least chi_min - eps, where chi_min = min |nonzero exponent of mu|).
[SM] Strong stable/unstable manifolds of a hyperbolic set: for every theta < chi_min - eps there are C_0 and local manifolds W^{ss}_loc(z), W^{uu}_loc(z), z in Lambda_eps, with d(g_t z, g_t y) <= C_0 e^{-theta t} d(z, y) for t >= 0, y in W^{ss}_loc(z) (and the time-reversed statement for W^{uu}_loc). A point whose forward orbit is exponentially asymptotic to the orbit of z lies in W^{ss}(g_s z) for some s (asymptotic phase).

**Proposition 2.1.** Let mu be as in (SC) and assume in addition that mu is hyperbolic (all exponents except the flow direction nonzero). Then the conclusion of (SC) holds. (By the remark below we may and do replace mu by the flow-invariant, flow-ergodic measure mu-bar.)

Remark on the reduction to a flow-invariant ergodic measure. mu-bar := int_0^1 (g_s)_* mu ds is flow-invariant; h_{mu-bar}(g_1) = h_mu(g_1) > 0; mu-bar(d) = int J_1 dmu = 0. Its flow-ergodic components need not all have zero d-integral. This is a genuine point: (SC) only assumes int J_1 dmu = 0 for the g_1-ergodic mu. But mu-bar is flow-ergodic: if A is flow-invariant, mu(A) is 0 or 1 by g_1-ergodicity, and then mu-bar(A) = mu(A). So mu-bar itself is flow-ergodic with mu-bar(d) = 0, h > 0, and it has the same exponents as mu (Oseledets spaces are carried by Dg_s). So we may assume mu flow-invariant and flow-ergodic. (mu(Zero X) = 0: on Zero X, g_1 = id, so a measure giving it positive mass would by ergodicity be carried by it and have entropy 0.)

*Proof of 2.1.* Let chi_min > 0 be the smallest modulus of a nonzero exponent. Fix eps with 0 < eps < chi_min/10, and Lambda := Lambda_eps from [KLY]; put theta := chi_min - 2 eps and eta := 2 eps (so eta < theta). Let gamma be a periodic orbit in Lambda (exists: periodic points are dense in a suspended SFT), q in gamma, period Pp, I := J_Pp(q). The periodic measure on gamma is eps-close to mu on the test function d, so |I/Pp| = |mu_gamma(d)| < eps. Then J_t(q) = (t/Pp) I + O(1) uniformly in t in R (cocycle identity), so |J_t(q)| <= C_1 + eps|t| for all t, and the same for every point of gamma (with a uniform constant).
Homoclinic orbits. In the symbolic model choose two bi-infinite admissible sequences that agree with the periodic sequence of gamma in the far past and the far future but differ from it somewhere, and lie on different shift-orbits and different from shifts of the periodic sequence (possible: the SFT is transitive with positive entropy, so the periodic block can be left and re-entered along infinitely many distinct words). The corresponding points of Lambda have orbits forward and backward exponentially asymptotic to gamma (uniform hyperbolicity), hence by [SM] (asymptotic phase) after flowing along their orbits we get points h, h' with h, h' in W^{uu}(q) \ {q} and h in W^{ss}(g_sigma q), h' in W^{ss}(g_{sigma'} q) for some reals sigma, sigma'; the orbits O(h), O(h'), gamma are pairwise distinct.
Chains. Chain A: a_0 = q, a_1 = h, a_i = g_sigma q for all i >= 2. Chain B: b_0 = q, b_1 = h', b_i = g_{sigma'} q for i >= 2. Limits p_A = g_sigma q, p_B = g_{sigma'} q.
(L1): d(g_t q, g_t h) <= C_h e^{-theta|t|} for t <= 0 (h in W^{uu}(q)); for t <= 0 large negative this is [SM] after the backward orbit has entered the local manifold, and finitely many compact time intervals are absorbed into the constant. Legs of length 0 satisfy (L1)/(L2) trivially. (L2): d(g_t h, g_t g_sigma q) <= C_h' e^{-theta t} for t >= 0. Since there are finitely many nontrivial legs (two per chain) and d(x_i, x_{i+1}) > 0 on them, a single C makes (L1), (L2) hold in the normalised form C e^{-theta|t|} d(x_i, x_{i+1}).
(L3): finitely many nonzero legs.
(L4): every vertex other than h, h' lies on gamma, where |J_t| <= C_1 + eps|t| <= C_1 + eta|t| for all t. For h and t >= 0: |J_t(h) - J_t(g_sigma q)| <= L C_h'/theta, so J_t(h) <= C' + eta t; likewise h'. (The conditions of (L4) at h, h' as odd vertices are exactly this forward condition; h, h' are not even vertices.)
(E): p_A = g_sigma q, so d(g_t p_A, g_{t + sigma} x_0) = 0 with tau = sigma; likewise for B with tau = sigma'.
Orbit-isolated vertices: in chain A take v = h. It is != x_0, occurs once in the combined list (h != h', and the other vertices lie on gamma, which does not contain h), is not a zero of X and not periodic (its orbit is asymptotic to gamma but not equal to it), and its orbit contains no other vertex and no limit point (the others lie on gamma or on O(h') != O(h)). ## 3. The non-hyperbolic case: what the proof of 2.1 really uses, and where it stops

**Proposition 3.1 (a sufficient criterion, proved modulo the strong unstable/stable manifold theorem for a fixed point with a pseudo-hyperbolic splitting).** Let gamma be a periodic orbit of period Pp, q in gamma, I = J_Pp(q). Suppose the linearised return map at q has an invariant splitting of the normal space E^{uu} + E^c + E^{ss} with E^{uu}, E^{ss} nonzero, spectrum on E^{uu} of modulus > e^{theta' Pp}, on E^{ss} of modulus < e^{-theta' Pp}, and on E^c in [e^{-theta'' Pp}, e^{theta'' Pp}] with theta'' < theta' (E^c may be nonzero: no hyperbolicity is assumed). Suppose |I|/Pp < theta', and there are two points h, h' not on gamma, on distinct orbits, each lying in W^{uu}(q) (strong unstable manifold for the rate theta') and in W^{ss}(g_s q) for some s. Then (SC) holds (with x_0 = q).
*Proof.* Choose eta, theta with |I|/Pp < eta < theta < theta'. The strong manifolds give (L1), (L2) at rate theta; the rest is the proof of Proposition 2.1 verbatim (only properties of gamma, h, h' were used there; the measure mu entered only to produce them). ∎

So (SC) would follow from the existence of a periodic orbit with "strong-homoclinic" orbits (W^{uu}(q) meeting the strong stable manifolds of the orbit of q) and small |I|/Pp. For a measure with c >= 1 zero exponents transverse to X this is exactly what is non-generic: dim W^{uu}(q) = u and dim of the union over s of W^{ss}(g_s q) = s + 1 in an n = u + s + 1 + c dimensional manifold, so the expected dimension of the intersection is -c < 0 even with transversality; Katok-type horseshoes with this structure do not exist in general for non-hyperbolic measures (e.g. a horseshoe times a rotation has no such orbits at all when the rotation is irrational, see below). This is why (SC) allows infinite summable chains whose limit p only reaches the weak-stable set W^{ss}(g_tau x_0): the c "missing dimensions" (centre) plus nothing else must be corrected by an infinite sequence of su-moves, i.e. by steering in the centre directions (planner's sketch (1)), and the closing up to a flow shift tau absorbs the flow direction.

**Example 3.2 (what (E) demands in a product; not a counterexample; the claims about temporal distances below are a sketch, not proved).** Let N carry a flow phi_t with a horseshoe and M = N x T^c with g_t(a, theta) = (phi_t a, theta + t alpha), alpha in R^c with 1, alpha_1, ..., alpha_c rationally independent... (any alpha with some ratio alpha_i/alpha_j irrational). Strong stable/unstable sets of (a, theta) are W^{ss/uu}(a) x {theta} (the T^c-factor is isometric), so every su-chain from x_0 = (a, theta_0) stays in N x {theta_0}, with limit p = (p_N, theta_0). Condition (E) requires d(phi_t p_N, phi_{t+tau} a) -> 0 AND tau alpha = 0 mod Z^c; with an irrational ratio this forces tau = 0. Hence in such products (SC) holds iff (for some base point) the base flow has su-chains returning EXACTLY to the strong stable manifold W^{ss}(a) of the base point (zero temporal displacement), not merely to W^{ss}(phi_tau a). For the base point a on a periodic orbit of period Pp, the homoclinic chain of 2.1 has temporal displacement sigma, and one needs sigma in Pp Z; in a suspended horseshoe whose roof function is not cohomologous to a locally constant one the temporal-distance function takes a continuum of values near 0 and (by continuity and a sign change) the value 0 at non-trivial points, so (SC) holds; for constant roof, chains close with sigma in Pp Z directly. So products do not refute (SC); they show that (E) with the flow shift tau is a codimension-one condition in addition to the centre condition, which steering must also handle (tau is free in (SC), but in products with an irrational rotation it is effectively pinned to 0).

**Where I stop (the gap, as I see it).** For a non-hyperbolic positive-entropy mu with mu(d) = 0, a proof of (SC) needs, on a Pesin-Egorov block K (Block R13-c Lemma 1.2), a steering statement: from points near W^{cs}_loc(x_0) one can, by su-moves of controlled length inside K, decrease the centre distance by a fixed factor. Both available mechanisms fail in general:
(i) a first-order "bracket" expansion of the centre defect of small su-quadrilaterals requires C^1 dependence of the local stable/unstable plaques on the base point, while Pesin plaques are only Hölder in the base point on a block (and K is typically a Cantor-like set, so intermediate-value arguments are unavailable; Lebesgue density on leaves helps only if the defect map is differentiable in leaf coordinates);
(ii) the "integrable" alternative (all defects vanish) would need an invariance principle for centre conditionals (Ledrappier / Avila-Viana type), which is formulated for fibred systems or for a continuous centre foliation; for a general Pesin-theoretic mu there is no centre foliation.
I could not overcome either, and I have no counterexample: any smooth flow which possesses a hyperbolic source-sink connection, or a periodic orbit as in Proposition 3.1, satisfies (SC) for trivial reasons (vertices are not required to lie in supp mu), so a counterexample must exclude all such structures on the whole of M while carrying a positive-entropy non-hyperbolic measure with mu(d) = 0 — I do not know such an example, nor a proof that none exists.

Not proved / open:
