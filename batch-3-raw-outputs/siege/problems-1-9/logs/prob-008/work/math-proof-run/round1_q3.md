Open question attempted: the dynamical core of the headline claim — showing that the structural consequences of global hypoellipticity (GH) force zero topological entropy, including the hard case of zero Lyapunov exponents transverse to the flow.

You may ASSUME the following structural facts (they are being proved separately; take them as hypotheses H1-H4 for a C^infinity vector field X on a compact connected manifold M of dimension n >= 2; GH as in the problem statement below also remains available):
H1. X has no zeros and preserves a smooth volume omega (normalized to total mass 1); the flow g_t is uniquely ergodic (omega is its only invariant probability measure), hence minimal, and has no periodic orbits.
H2. Every smooth f with integral 0 equals X u for a smooth u; for each r there are k, C with ||u - mean(u)||_{C^r} <= C ||f||_{C^k}.
H3 (dual estimate). For each s there are k, C such that every distribution w (generalized function, paired with smooth functions via omega) with <w,1> = 0 satisfies ||w||_{(C^k)'} <= C ||X w||_{(C^s)'}, where X w is defined by <X w, f> = -<w, X f>.
H4. The only X-invariant distributions (X w = 0) are constant multiples of omega.

Task: prove that h_top(g_t) = 0, rigorously. Known reductions: by the variational principle and H1, h_top(g_1) = h_omega(g_1); by Pesin's entropy formula, h_omega = integral of the sum of positive Lyapunov exponents. So it suffices to show the volume has no positive Lyapunov exponent. If omega is hyperbolic (the only zero exponent is the flow direction), Katok's closing lemma for flows gives periodic orbits, contradicting H1 — check and state this carefully. The difficulty is the case with extra zero exponents, where periodic orbits need not exist; there are minimal positive-entropy smooth systems, so H1 alone is not enough and H2-H4 must be used.

A candidate idea from the planner (unverified; use, repair or discard): for x a Pesin-regular point and y in the global unstable manifold W^u(x), define the distribution w = integral_{-infinity}^0 (delta_{g_t x} - delta_{g_t y}) dt, i.e. <w,f> = integral_{-inf}^0 (f(g_t x) - f(g_t y)) dt, which converges since d(g_t x, g_t y) decays exponentially as t -> -infinity, and is a distribution of order 1. Then X w = +-(delta_x - delta_y) (check the sign), whose (C^1)'-norm is <= d(x,y). If the unstable manifold of x returns very close to x (y in W^u(x), d(x,y) tiny, but y far from x inside the leaf), then by H3 ||w||_{(C^k)'} <= C d(x,y). On the other hand testing w against a bump f of size eps (C^k norm ~ eps^{-k}) placed on a "free" stretch of the backward orbit of y (where g_t y is far from g_t x and from other passes of the two orbits) should give |<w,f>| >~ eps, contradiction when d(x,y) << eps^{k+1}. Similarly homoclinic-type configurations (y in W^u(x) and in W^s(z) with z close to x: w = int_{-inf}^0 (delta_{g_t x}-delta_{g_t y}) dt - int_0^inf (delta_{g_t y} - delta_{g_t z}) dt has X w = +-(delta_z - delta_x)) could be used. The open problems are: existence of such configurations with the required quantitative control from positive entropy (Pesin theory, Ledrappier–Young, recurrence), and the lower bound on <w,f>.

Alternative routes are welcome (e.g. using H2 for functions built from the dynamics, or using that GH is invariant under time changes hX with h>0 smooth). Give a complete proof if you can; otherwise prove as much as possible and state precisely the missing lemma. If you find the hypotheses H1-H4 compatible with positive entropy, say how GH itself must enter.
