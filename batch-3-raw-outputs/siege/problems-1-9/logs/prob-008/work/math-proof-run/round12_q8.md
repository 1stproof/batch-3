### The statement (PE0)
**Missing statement (PE0) (no positive-entropy ergodic measure with zero mean divergence).** Let M be a compact connected smooth manifold and X a smooth vector field on M with flow g_t, such that every distribution u in D'(M) with Xu in C^inf(M) lies in C^inf(M) (global hypoellipticity, GH). Fix a smooth positive density nu on M, put d = div_nu X and J_1(x) = int_0^1 d(g_s x) ds (the log nu-Jacobian of the time-one map g_1 at x). Then there is NO Borel probability measure mu on M that is invariant and ergodic under the time-one map g_1 and satisfies both h_mu(g_1) > 0 and int_M J_1 dmu = 0.
(Remarks. The statement does not depend on nu: replacing nu by e^a nu changes J_1 by a o g_1 - a, whose mu-integral is 0. If mu is moreover flow-invariant, int J_1 dmu = int d dmu. Known constraints on a hypothetical such mu, all proved under GH: it is non-hyperbolic, i.e. besides the flow direction it has a zero Lyapunov exponent (entry 60, citing Katok/Lian-Young); its flow-average mu-bar = int_0^1 (g_s)_* mu ds is flow-invariant with mu-bar(d) = 0, hence has full support (entry 25, Corollary D1); dim M >= 4 (entry 61). In the volume-preserving case (nu invariant, d = 0, the flow uniquely ergodic and cohomology-free) (PE0) says exactly that the flow has zero topological entropy.)

### Results you may use (statements only; proved earlier in this attempt)
(R1) Variational step (classical). If h_top(g_1) > 0, then there is a Borel probability on M, invariant and ergodic for the homeomorphism g_1, with positive entropy (variational principle, ergodic decomposition and Jacobs' formula).
(R2) Under global hypoellipticity, every Borel probability mu invariant and ergodic for g_1 with h_mu(g_1) > 0 satisfies int J_1 dmu = 0 (proved via Dirac combinations with vanishing moments in non-stationary normal-form charts on a Pesin unstable leaf, whose weighted transport decays exponentially in both time directions when int J_1 dmu < 0, contradicting the result (R3); the case > 0 by X -> -X; modulo Pesin theory, Ledrappier-Strelcyn and the Kalinin-Sadovskaya/Melnick normal forms).
(R3) (Used inside R2; available to you.) Under global hypoellipticity, no nonzero distribution density S satisfies |S(e^{J_t} (phi o g_t))| <= C e^{-eps|t|} ||phi||_{C^k} for all real t and all smooth phi (some C, eps > 0, k), where J_t(x) = int_0^t d(g_s x) ds. Proof idea: the moments int t^j S(e^{J_t} phi o g_t) dt form a Jordan chain at 0 of the transpose of X + d, killed by ker X = constants and the absence of distribution solutions of Xu = 1; then quasi-analyticity of the Fourier transform. The same holds for two-sided quasi-analytic decay rates such as e^{-|t|/log(e+|t|)}.
(R4) Further facts proved under global hypoellipticity: every distribution u with Xu = 0 is constant; for every r there are k, C with ||u - mean(u)||_{H^r} <= C ||Xu||_{H^k} for smooth u (so X has closed range, equal to the annihilator of the invariant distribution densities); every invariant Borel set is nu-null or conull; a positive-entropy ergodic measure is non-hyperbolic (has a zero Lyapunov exponent transverse to the flow; cites Katok/Lian-Young); dim M <= 3 implies zero entropy; if X preserves a smooth volume, then the flow is uniquely ergodic and minimal and every volume-mean-zero smooth function is Xu with u smooth (tame bounds); in that case no nonzero smooth mean-zero observable has exponentially (or quasi-analytically) decaying autocorrelation.
