# Commit query (independent second commit of the same route): the volume-preserving case, in every dimension

Route: an occupation-measure / pigeonhole argument that uses the tame inverse of X. The steps are: (A) the tame inverse R; (B) a polynomial no-near-return lemma; (C) Hausdorff closeness of orbit segments whose endpoints are close; (D) time-shadowing from Hausdorff closeness; (E) a pigeonhole count giving polynomially many (T, ε)-separated points. **Write the full rigorous proof.**

## Target theorem

**Theorem V.** Let M be compact and connected with n = dim M ≥ 2. Let X be a smooth vector field with the problem's hypothesis (GH: for every distribution u, if Xu is smooth then u is smooth). Suppose X preserves a smooth positive density ω, normalised so that ω(M) = 1. Then h_top(g_1) = 0.

(For n = 1, M is a circle and g_1 is a circle homeomorphism, so the entropy is 0.)

Prove Theorem V in full, following the route below. Check every step. If a step fails, say exactly where and why, repair it if you can, and state precisely what you did prove. A clearly marked gap is worth more than a hidden one. Use only GH and standard facts (closed graph theorem, Sobolev embedding, Rellich, Hahn–Banach, the definition of topological entropy via separated sets). No Pesin theory or ergodic theory beyond that is needed.

## Background already established (proofs included so that you can check them; you may reuse them)

Notation and conventions used in these proofs:

* M is compact, connected and smooth, with n = dim M. X is a smooth vector field with flow g_t. We fix a Riemannian distance d(·,·) on M.
* ν is a fixed smooth positive density (not assumed invariant). We write d := div_ν X, so that L_X(φν) = (Xφ + dφ)ν, and put Pφ := Xφ + dφ.
* J_t(x) := ∫_0^t d(g_s x) ds. This is the logarithm of the ν-Jacobian of g_t at x. It satisfies the cocycle identity J_{t+s}(x) = J_s(x) + J_t(g_s x), and d/dt [e^{J_t(x)} φ(g_t x)] = e^{J_t(x)} (Pφ)(g_t x).
* We write Γ_t φ := e^{J_t}·(φ∘g_t).
* A **distribution density** is a continuous linear functional S on C^∞(M). A distribution (generalised function) u is identified with the distribution density S = uν, S(φ) = ⟨u, φν⟩. Then

  ⟨Xu, φν⟩ = −⟨u, L_X(φν)⟩ = −S(Pφ).   (0.1)

  So Xu = f means −S(Pφ) = ∫ fφ dν for all φ.
* **GH** is the hypothesis of the problem: if u is a distribution and Xu is smooth, then u is smooth. If X is GH then so is −X, since (−X)u = f ⇔ Xu = −f. The flow of −X is g_{−t}, its ν-divergence is −d, and its log-Jacobian at time t is J_{−t}.
* ‖φ‖_{C^k} denotes a fixed C^k norm, with ‖φ‖_{C^1} := max(‖φ‖_∞, ‖dφ‖_∞). Then |φ(a) − φ(b)| ≤ ‖φ‖_{C^1} d(a,b), because M is connected.
* h_top(g_1) is the topological entropy of the time-one map. Since h_top(g_t) = |t| h_top(g_1), "the flow has zero entropy" means h_top(g_1) = 0.

**Lemma 1.1 (kernel).** Assume GH. If u is a distribution with Xu = 0, then u is constant.

*Proof.* By GH u is smooth. Suppose u is not constant, and choose c with min u < c < max u. Let H_ε be smooth and nondecreasing with H_ε = 0 on (−∞, −ε] and H_ε = 1 on [0, ∞). Then v_ε := H_ε(u − c) is smooth and Xv_ε = H_ε′(u − c)·Xu = 0. As ε → 0, v_ε → 1_{\{u≥c\}} =: v boundedly and pointwise (on {u ≥ c} every v_ε equals 1; at a point with u − c < 0, v_ε = 0 as soon as ε ≤ c − u), hence in L^1 and in D′. So Xv = 0, and by GH v agrees a.e. with a continuous function w. Then w ∈ {0,1} a.e., hence everywhere, so w is constant because M is connected. But w = 1 a.e. on the nonempty open set {u > c} and w = 0 a.e. on the nonempty open set {u < c}. Contradiction. (Complex-valued u: apply this to the real and imaginary parts.) ∎

**Lemma 1.4 (tame estimate and closed range; used only in §7).** Assume GH. Then X(C^∞(M)) is closed in C^∞(M).

*Proof.* Fix a smooth density ω₀ and Sobolev spaces H^s(M), and fix s ≥ 0. Let F_s := {u ∈ H^{−s} : Xu ∈ C^∞}, with the seminorms ‖u‖_{H^{−s}} and ‖Xu‖_{H^j}, j ∈ ℕ. This is a Fréchet space. By GH, F_s ⊂ C^∞, and the inclusion has closed graph since both spaces embed continuously in H^{−s}. By the closed graph theorem it is continuous: for every r there are j and C with ‖u‖_{H^r} ≤ C(‖u‖_{H^{−s}} + ‖Xu‖_{H^j}).

Now let c(u) := ∫u ω₀/∫ω₀. We claim ‖u − c(u)‖_{H^r} ≤ C′‖Xu‖_{H^j} for smooth u, with j chosen so that the previous estimate holds at levels r and r+1. If not, there are smooth u_m with c(u_m) = 0, ‖u_m‖_{H^r} = 1 and ‖Xu_m‖_{H^j} → 0. The previous estimate at level r+1 bounds u_m in H^{r+1}. By Rellich a subsequence converges in H^r to some u with ‖u‖_{H^r} = 1, c(u) = 0 and Xu = 0. By Lemma 1.1 u is constant, hence u = 0. Contradiction.

So if Xu_m → f in C^∞, then (u_m − c(u_m)) is Cauchy in every H^r and converges in C^∞ to some u with Xu = f. ∎

In this section ω is a smooth positive density with L_Xω = 0, normalised so that ω(M) = 1. We take ν = ω, so d = 0 and J ≡ 0. Call X **cohomology-free (CF)** if every smooth f can be written f = c + Xu with c a constant and u smooth.

**Proposition 7.1.** Suppose X preserves a smooth positive density ω.
(a) X is GH if and only if X is CF.
(b) If X is GH, the flow is uniquely ergodic with invariant measure ω, and it is minimal.

*Proof.*
* **GH ⇒ CF.** By Lemma 1.4, X(C^∞) is closed. By Hahn–Banach it is the annihilator of the distribution densities T with T(Xφ) = 0 for all φ. For such T, u := T/ω satisfies Xu = 0 by (0.1) (P = X here), so u is constant (Lemma 1.1) and T = cω. Hence X(C^∞) = {f : ∫f dω = 0}, which gives CF.
* **CF ⇒ GH.** No smooth u has Xu = 1 (look at a maximum of u). So c(f) is well defined, and it is a linear functional whose kernel is X(C^∞). If T is an invariant distribution density, T annihilates X(C^∞) = ker ω; so T = T(1)ω. Now let u ∈ D′ with Xu = f smooth. Then ∫f dω = −⟨u, L_Xω⟩ = 0, so f = Xv with v smooth. Then X(u − v) = 0, so (u − v)ω is an invariant density, equal to cω. Hence u = v + c is smooth.
* **(b).** For any invariant probability m, m(Xu) = 0, so m(f) = ∫f dω for all f. This is unique ergodicity. Every orbit closure carries an invariant measure, which must be ω, whose support is M. Hence the flow is minimal. ∎

## The route (planner's sketch: verify every step and write it out in full)

Throughout, assume GH, n ≥ 2, L_Xω = 0, ω(M) = 1. Fix a Riemannian distance d(·,·), and put V := max|X|.

**Step 0 (no zeros, flow box).** With ν = ω we have div_ω X = 0. A zero p of X would make δ_p/ω a non-smooth distribution u with Xu = 0 (check: ⟨Xu, φω⟩ = −⟨u, L_X(φω)⟩ = −(Xφ)(p) = 0). This contradicts GH, so X has no zeros and V > 0. By compactness there are τ_0 > 0 and c_0 > 0 with d(z, g_s z) ≥ c_0|s| for all z ∈ M and |s| ≤ τ_0. There is also h_0 ∈ (0,1] with Lip(g_h) ≤ 2 for 0 ≤ h ≤ h_0.

**Step A (tame inverse).** By Proposition 7.1, every smooth f with ω(f) = 0 equals Xu for a smooth u, unique up to an additive constant. By Lemma 1.4 and Sobolev embedding, there are m ∈ ℕ and C_1 such that this u can be chosen with ‖u‖_{C^1} ≤ C_1‖f‖_{C^m}. (Check that the normalisation of u and the passage from H^r/H^j norms to C^1/C^m norms are correct.) Write u = R f.

Consequence used repeatedly: for every x ∈ M, T ≥ 0 and smooth f, with γ_x^T(f) := ∫_0^T f(g_s x) ds,

  γ_x^T(f) − T ω(f) = u(g_T x) − u(x),  u := R(f − ω(f)),

since ∫_0^T (Xu)(g_s x) ds = u(g_T x) − u(x). In particular, for any x, y ∈ M,

  |γ_x^T(f) − γ_y^T(f)| ≤ 2C_1‖f‖_{C^m}·(d(x,y) + d(g_T x, g_T y)),   (A1)

using |u(a) − u(b)| ≤ ‖u‖_{C^1} d(a,b) and ‖f − ω(f)‖_{C^m} ≤ 2‖f‖_{C^m}.

**Step B (polynomial no-near-return lemma).** Claim: there are c_B > 0 and K ≥ 1 such that for every z ∈ M and every r ∈ [τ_0, ∞),

  d(z, g_r z) ≥ c_B (1 + r)^{−K}.

Sketch. Suppose d(z, g_r z) ≤ δ. Build a smooth ψ with 0 ≤ ψ ≤ 1, ψ = 1 on the orbit segment g_{[0,r]}z, ω(ψ) ≤ 1/2, and ‖ψ‖_{C^m} ≤ C(1 + r)^{a} ρ^{−b}, at a scale ρ ≈ c(1 + r)^{−1/(n−1)}. For example, take points p_i := g_{iρ/(2V)}z, 0 ≤ i ≤ N := ⌈2Vr/ρ⌉, so that the segment lies in ∪B(p_i, ρ/4). Take bumps b_i with b_i = 1 on B(p_i, ρ/2), supp b_i ⊂ B(p_i, ρ) and ‖b_i‖_{C^m} ≤ Cρ^{−m}. Put F := Σ b_i and ψ := Φ∘F, with Φ smooth, Φ = 0 near 0, Φ = 1 on [1, ∞) and 0 ≤ Φ ≤ 1. Then ω(ψ) ≤ (N+1) C_ω ρ^n ≤ 1/2 for ρ = c(1 + r)^{−1/(n−1)} (this is where n ≥ 2 is used), and Faà di Bruno gives the polynomial C^m bound. Let f := 1 − ψ. Then γ_z^r(f) = 0 and ω(f) ≥ 1/2, so by Step A

  r/2 ≤ |γ_z^r(f) − rω(f)| = |u(g_r z) − u(z)| ≤ 2C_1‖ψ‖_{C^m} δ.

Hence δ ≥ c(1 + r)^{−K}. Check the details, in particular the C^m bound for Φ∘F when many bumps overlap. A crude bound polynomial in r and 1/ρ suffices.

**Step C (Hausdorff closeness).** Claim: there is C_C such that if x, y ∈ M, T ≥ 1 and d(x,y) + d(g_T x, g_T y) ≤ η, then every point g_t y (0 ≤ t ≤ T) lies within distance ρ := (C_C η)^{1/(m+1)} of the segment g_{[0,T]}x, provided ρ ≤ min(r_*, V) (r_* a fixed small radius).

Sketch. Let q := g_t y, and suppose d(q, g_{[0,T]}x) > ρ. Take a bump ψ_q with 0 ≤ ψ_q ≤ 1, ψ_q = 1 on B(q, ρ/2), supp ψ_q ⊂ B(q, ρ) and ‖ψ_q‖_{C^m} ≤ C_χ ρ^{−m}. Then γ_x^T(ψ_q) = 0. Also γ_y^T(ψ_q) ≥ ρ/(2V), because g_s y ∈ B(q, ρ/2) for |s − t| ≤ ρ/(2V), and at least half of that window lies in [0, T]. Then (A1) gives ρ/(2V) ≤ 2C_1C_χρ^{−m}η, which is false for C_C := 8VC_1C_χ, say.

**Step D (shadowing in time).** Fix ε > 0. Claim: for all large T, if d(x,y) + d(g_T x, g_T y) ≤ η_T := T^{−B} (B a large constant depending only on m, K, n), then d(g_t x, g_t y) < ε for all t ∈ [0, T].

Sketch. Let ρ = (C_C η_T)^{1/(m+1)}, and take T so large that 4ρ < c_B (T + 3)^{−K}. By Step B and Step 0: if s_1, s_2 ∈ [−1, T+1] and d(g_{s_1}x, g_{s_2}x) ≤ 4ρ, then |s_1 − s_2| < τ_0 (otherwise Step B at z = g_{min(s_1,s_2)}x with r = |s_1 − s_2| ∈ [τ_0, T+2] is violated), and hence |s_1 − s_2| ≤ 4ρ/c_0. Fix h ∈ (0, h_0] with T/h =: k_max an integer. For k = 0, …, k_max choose σ_k ∈ [0, T] with d(g_{kh}y, g_{σ_k}x) ≤ ρ (Step C); take σ_0 := 0, which is allowed since d(x,y) ≤ η_T ≤ ρ. Then d(g_{(k+1)h}y, g_{σ_k + h}x) ≤ 2ρ, and d(g_{(k+1)h}y, g_{σ_{k+1}}x) ≤ ρ. So d(g_{σ_k+h}x, g_{σ_{k+1}}x) ≤ 3ρ, and therefore |σ_{k+1} − σ_k − h| ≤ 4ρ/c_0 (both times lie in [−1, T+1]). By induction |σ_k − kh| ≤ 4kρ/c_0 ≤ 4Tρ/(c_0 h). For t ∈ [kh, (k+1)h],

  d(g_t x, g_t y) ≤ 2 d(g_{kh}x, g_{kh}y) ≤ 2(ρ + V|σ_k − kh|) ≤ 2ρ + 8VTρ/(c_0 h),

which is < ε once B is large and T is large, because ρ ≈ T^{−B/(m+1)}.

**Step E (counting).** Let E be a (T, ε)-separated set for the flow: for x ≠ y in E, max_{t∈[0,T]} d(g_t x, g_t y) ≥ ε. Partition M into N(η) ≤ C_M η^{−n} Borel sets of diameter ≤ η/2. If x ≠ y in E had x, y in one cell and g_T x, g_T y in one cell, Step D would be contradicted. So |E| ≤ N(η_T)^2 ≤ C T^{2nB}. A (T, ε)-separated set for the time-one map, using integer times 0, …, T, is also (T, ε)-separated in this sense. Hence h_top(g_1) = lim_{ε→0} limsup_{T→∞} (1/T) log s(T, ε) ≤ limsup (2nB log T + C)/T = 0.
