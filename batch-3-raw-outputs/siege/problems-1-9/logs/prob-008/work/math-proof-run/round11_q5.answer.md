## 1. Check of the chain

Then dist(g_t x, g_{t+s} x) -> 0 as t -> -inf. Take t_n -> -inf with g_{t_n} x -> x, which is possible because x is in alpha(x). Continuity of g_s gives g_s x = x, hence y = x, a contradiction. ## 2. Proposition 1 (new; proved): absolutely continuous eigen-measures vanish

Conventions as in the brief: P phi = X phi + d phi, and L_t phi = e^{J_t} (phi o g_t). Then d/dt L_t phi = L_t P phi = P L_t phi, since L is the semigroup generated by P (cocycle identity). Also (g_t)^* nu = e^{J_t} nu.

**Lemma 1.0 (ergodicity).** Assume GH. If A is a Borel set with nu(g_t A Δ A) = 0 for every t, then nu(A) = 0 or nu(M \ A) = 0. Every measurable f with f o g_t = f nu-a.e. (for each t) is a.e. constant (real-valued, or with values in a standard Borel space).
*Proof.* For smooth phi, ∫_A L_X(phi nu) = d/dt|_{t=0} ∫_A g_t^*(phi nu) = d/dt|_{t=0} ∫_{g_t A} phi nu = 0. So u = 1_A satisfies <Xu, phi nu> = -∫_A (X phi + d phi) nu = 0, i.e. Xu = 0 in D'. By L1, 1_A equals a constant a.e. For f, apply this to the sets {f > c} (for real f), or to preimages of a countable generating family (standard Borel range). ∎

**Lemma 1.1 (no measurable time function).** Assume GH and dim M >= 2. There is no Borel A with nu(A) > 0 and Borel ell: A -> R, kappa real != 0, such that for each t, ell(g_t x) = ell(x) - kappa t for nu-a.e. x in A (in particular g_t A = A mod nu).
*Proof.* A is invariant mod nu, so it is conull by Lemma 1.0. Put pi(x) := g_{ell(x)/kappa}(x). This is Borel, since (s, x) -> g_s x is continuous. For fixed t and a.e. x, pi(g_t x) = g_{(ell(x) - kappa t)/kappa}(g_t x) = g_{ell(x)/kappa} x = pi(x). By Lemma 1.0 (M is standard Borel), pi = p is a.e. constant. Then a.e. x equals g_{-ell(x)/kappa} p, i.e. lies on the orbit of p. The orbit of p is the image of R under the smooth map s -> g_s p, which is nu-null when dim M >= 2 (a countable union of images of compact intervals under C^1 maps into a manifold of dimension >= 2). This contradicts nu(A) > 0. ∎

**Proposition 1.** Assume GH and dim M >= 2. Let T be a finite complex Borel measure and kappa a complex number with Re kappa != 0, and suppose T(P phi) = kappa T(phi) for all smooth phi. Then T is singular with respect to nu. Equivalently: if u in L^1(nu) and Xu = -kappa u in D' with Re kappa != 0, then u = 0.
*Proof.*
1. F(t) := T(L_t phi) satisfies F' = T(P L_t phi) = kappa F, so T(L_t phi) = e^{kappa t} T(phi). Hence L_t^* T = e^{kappa t} T as measures, where L_t^* m := (g_t)_*(e^{J_t} m) (smooth functions determine finite measures).
2. L_t^* maps nu-absolutely continuous measures to absolutely continuous ones and nu-singular measures to singular ones, because g_t is a diffeomorphism. Also L_t^*(rho nu) = (rho o g_{-t}) nu, by the change of variables y = g_t x and (g_t)^* nu = e^{J_t} nu.
3. Write T = rho nu + T_s (Lebesgue decomposition). By uniqueness of the decomposition and step 2, rho o g_{-t} = e^{kappa t} rho nu-a.e., for each t. Hence |rho| o g_{-t} = e^{a t} |rho| with a = Re kappa != 0.
4. A = {|rho| > 0} is invariant mod nu. If nu(A) > 0, ell := log|rho| on A satisfies ell(g_{-t} x) = ell(x) + a t a.e., i.e. ell(g_t x) = ell(x) - a t. Lemma 1.1 forbids this. So rho = 0 a.e.
The equivalent form: u in L^1 with Xu = -kappa u means T = u nu satisfies T(P phi) = -<Xu, phi nu> = kappa T(phi) (Observation 0), and T is absolutely continuous; so T = 0. ∎

*Remarks.* (i) For kappa = 0 the same proof gives rho o g_{-t} = rho, so rho is constant (Lemma 1.0) and T_ac = c nu. (ii) This is (E1) for absolutely continuous solutions. The eigen-distributions produced from positive entropy (R5-a: order-0 tilted conformal measures in Case A, order-1 pair families in Case B) are singular, respectively not measures. So Proposition 1 does not close any case. It does show that any counterexample to (E1) must be singular.

## 3. Proposition 2 (new; proved): infinite-order vanishing of the pair family at z = 0 in the volume case

**Setting.** GH, with nu a smooth positive invariant density (d = 0). By (O2) the flow is uniquely ergodic. Every invariant distribution density is c nu, so X(C^inf) = {phi : ∫ phi dnu = 0} (duality consequence of Text A). By Corollary 3 of Text B, X: C^inf_0 -> C^inf_0 has a continuous inverse R: for each k there are m(k), C_k with ||R f||_{C^k} <= C_k ||f||_{C^{m(k)}}.
Let x != y with dist(g_t x, g_t y) <= C e^{-theta|t|} for t <= 0. This is the content of (AP) in the volume case; lambda = 0 and b = 0 automatically, since J ≡ 0. Put F_phi(t) = phi(g_t x) - phi(g_t y) and, for 0 < Re z < theta,
 T_z(phi) := ∫_R e^{-zt} F_phi(t) dt.

**Proposition 2.** For every smooth phi, every k >= 1 and every z with 0 < Re z < theta,
 |T_z(phi)| <= |z|^k (2/Re z + C/(theta - Re z)) ||R^k phi_0||_{C^1},  phi_0 := phi - ∫phi dnu/nu(M).
In particular, on each sector {|Im z| <= A Re z, 0 < Re z < theta/2}, T_z(phi) = O(|z|^{k-1}) for every k. Yet z -> T_z(phi_0') is not identically 0 for phi_0' smooth with phi_0'(x) = 1, phi_0'(y) = 0.
*Proof.*
1. Bound. |F_psi(t)| <= 2||psi||_inf for t >= 0, and |F_psi(t)| <= C e^{-theta|t|}||psi||_{C^1} for t <= 0. Hence |T_z(psi)| <= (2/Re z + C/(theta - Re z))||psi||_{C^1}.
2. Eigen-relation. F_{X psi} = (F_psi)'. Integrate by parts on [-R, R]. The boundary terms are bounded by 2e^{-Re z R}||psi||_inf and C e^{(Re z - theta)R}||psi||_{C^1}, both of which tend to 0. So T_z(X psi) = z T_z(psi).
3. T_z(1) = 0, since F_1 ≡ 0. So T_z(phi) = T_z(phi_0) = T_z(X R phi_0) = z T_z(R phi_0). R phi_0 again has mean 0, so by induction T_z(phi) = z^k T_z(R^k phi_0). Step 1 finishes the bound.
4. Non-vanishing: G(t) := e^{-theta t/2} F_{phi_0'}(t) is continuous, in L^1, and G(0) = 1. Its Fourier transform omega -> T_{theta/2 + i omega}(phi_0') cannot vanish identically (Fourier uniqueness). So T_z(phi_0') is not ≡ 0 on the strip. ∎

**Why this does not close (AP) in the volume case (exact stopping point).** To reach a contradiction one would need: a function E holomorphic on 0 < Re z < theta with |E(z)| <= C/Re z near Re z = 0, and with E(z) = O(|z|^k) in sectors for every k, must vanish identically. This implication is **false**. E(z) = e^{-1/z} is holomorphic and bounded by 1 on Re z > 0. On |arg z| <= pi/4, Re(1/z) >= 1/(sqrt2 |z|), so |E(z)| <= e^{-1/(sqrt2|z|)}, which is O(|z|^k) for every k. So a further quantitative input is needed. One option is decay faster than e^{-A/|z|} for every A in a sector; I expect, but have not checked a reference, that this forces E = 0 under the growth bound C/Re z (Phragmén-Lindelöf / boundary uniqueness for functions of moderate growth). By Proposition 2 that would need constants c_k := ||R^k phi_0||_{C^1} with inf_k c_k s^{k-1} = O(e^{-A/s}) for every A, i.e. essentially c_k^{1/k}/k -> 0. GH gives no control of the constants C_k in ||R f||_{C^k} <= C_k ||f||_{C^{m(k)}}. Even for Diophantine flows, where ||R f||_{C^j} <= C_j ||f||_{C^{j+tau}}, iterating gives c_k growing at least like (k tau)!^s for Gevrey-s data. That is much too large. So iterating the tame inverse at 0 is intrinsically limited to infinite-order vanishing at a single boundary point. This is the formal Taylor-expansion-zero phenomenon already noted in R6-a §7, now with an explicit proof in sectors and an explicit model showing it is insufficient.
Without a smooth invariant volume the iteration is not available: R inverts X, not the weighted P, so step 3 fails. This is consistent with the ledger's remark that the tame inverse acts on the weighted problem only under (V).

## 4. The case lambda <= -theta: what the pair alone cannot give, and what a leaf needs
(a) *Pair alone.* For S = delta_x - e^b delta_y with lambda <= -theta, the bounds are as follows. Forward, |F_phi(t)| <= C e^{(lambda + eps)t}. Backward, |F_phi(t)| <= C e^{(|lambda| - theta + eps)|t|}. So the natural Laplace strip is lambda < Re z < lambda + theta, contained in {Re z < 0}. Every tool that uses GH (Theorem J, J*, Lemma M) needs the point 0 inside, or at least at a holomorphic or meromorphic point, of the family. Excluding the pair therefore needs either more points (cancellation), or an (E1)-type statement for eigenvalues with Re z < 0, which is open. Proposition 1 gives (E1) only for absolutely continuous solutions, while T_z has order 1.
(b) *Leaf available (as in the chain, where the conditional on xi(x) is non-atomic and full on G ∩ Rec).* Take points y_j = exp_x(v_j) on W^u_loc(x) and weights with sum_j w_j p(v_j) = 0 for all polynomials of degree < N in a fixed smooth chart. Let H_t be the backward map in charts along the orbit, with ||DH_t|| <= C e^{-theta t}. For any smooth Psi, Faa di Bruno gives D^N(Psi o H_t) = DPsi·D^N H_t + (terms with at least two factors of derivatives of H_t). Here ||D^N H_t|| is in general only O(e^{-theta t}): for a uniform contraction F with ||DF|| <= a, D^N(F^n) = O(a^n) and in general no better. So sum_j w_j Psi(H_t(v_j)) = O(e^{-theta t} r^N), and the backward rate does not improve with N. This shows rigorously that vanishing moments in a fixed chart do not beat e^{-theta|t|}. One needs charts in which H_t is a polynomial of bounded degree, i.e. non-stationary normal forms (Kalinin-Sadovskaya, "Normal forms for non-uniform contractions", J. Mod. Dyn. 2017, cited from memory; tempered C^N bounds on the charts are not verified). Alternatively, one needs a 1-dimensional leaf with an affine parameter (Prop 6.2 of R6-a). This confirms the status in the ledger. I have nothing better for this sub-case.

Together with a boundary-uniqueness theorem for functions with |E| <= C/Re z, which I believe is true but have not checked, this would prove (AP) in the volume case.
