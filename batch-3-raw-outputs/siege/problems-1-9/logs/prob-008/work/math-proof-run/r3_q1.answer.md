# Answer to r3_q1: Theorem V (the volume-preserving case) via the occupation-measure / pigeonhole route

**Status.** I checked every step of the route. It works, with only cosmetic repairs:
(i) I use a crude bump bound ‖b‖_{C^m} ≤ C_b ρ^{-2m}, which is easy to prove uniformly, in place of ρ^{-m}. This changes the exponent in Step C from 1/(m+1) to 1/(2m+1) and nothing else.
(ii) In Step D the step error is 3ρ, so the drift per step is 3ρ/c_0. The extra fact h ≥ h_0/2 is needed to bound T/h.
(iii) The admissible range of times in Step D is [0, T+1], and the no-return bound is needed for r ≤ T+1.
None of these is a gap. The full proof is below.

Conventions: real-valued functions throughout. A complex u is handled by taking real and imaginary parts.

## 0. Preliminaries (standard facts, fixed constants)

Fix a Riemannian metric on M with distance d. M is connected, so d is the length metric, and:

* (L) If φ ∈ C^1, then |φ(a) − φ(b)| ≤ ‖dφ‖_∞ d(a,b). Here ‖dφ‖_∞ is the sup of the Riemannian norm of dφ.
* If G : M → M is C^1, then Lip(G) ≤ sup_x ‖DG(x)‖.
* d(g_s z, g_{s'} z) ≤ V|s − s'|, where V := max|X|. (The orbit arc is a curve of length ≤ V|s − s'|.)

**C^m norms.** Fix a finite atlas κ_α : U_α → ℝ^n and compact sets K_α ⊂ U_α whose interiors cover M. Put
‖φ‖_{C^m} := max_α max_{|β|≤m} sup_{K_α} |∂^β(φ∘κ_α^{-1})|.
Then ‖φ‖_∞ ≤ ‖φ‖_{C^m}, ‖1‖_{C^m} = 1, and ‖dφ‖_∞ ≤ A_0‖φ‖_{C^1} for a constant A_0.

**Radius r_*.** Fix r_* ∈ (0, 1] such that:
* 2r_* is less than the injectivity radius, so (p,x) ↦ d(p,x)^2 is smooth on the open set {d(p,x) < 2r_*};
* there are constants 0 < c_ω ≤ C_ω with c_ω ρ^n ≤ ω(B(p,ρ)) ≤ C_ω ρ^n for all p ∈ M and 0 < ρ ≤ r_*.

These are standard consequences of compactness, for instance via normal coordinates. They hold for any smooth positive density ω.

**Lemma 0.1 (bumps).** There is C_b ≥ 1 with the following property. For every p ∈ M and 0 < ρ ≤ r_* there is b = b_{p,ρ} ∈ C^∞(M) such that:
* 0 ≤ b ≤ 1;
* b = 1 on the closed ball B̄(p, ρ/2);
* supp b ⊂ B̄(p, 3ρ/4) ⊂ B(p, ρ);
* ‖b‖_{C^m} ≤ C_b ρ^{-2m}.

*Proof.* Fix χ ∈ C^∞(ℝ), nonincreasing, with χ = 1 on (−∞, 1/4] and χ = 0 on [9/16, ∞). Put b(x) := χ(d(p,x)^2/ρ^2) when d(p,x) < 2r_*, and b(x) := 0 otherwise.

*Smoothness.* On the open set {d(p,·) < 2r_*}, b is a composition of smooth maps. On the open set {d(p,·) > 3ρ/4}, b vanishes. These two open sets cover M. The properties 0 ≤ b ≤ 1, b = 1 on B̄(p, ρ/2) and supp b ⊂ B̄(p, 3ρ/4) are immediate.

*Derivative bound.* Fix α, a multi-index β with |β| ≤ m, and y = κ_α(x) with x ∈ K_α. If d(p,x) > 3ρ/4, the derivative vanishes. Otherwise d(p,x) ≤ r_*. The set Q_α := {(p,x) : x ∈ K_α, d(p,x) ≤ r_*} is compact and lies inside the open set where d^2 is smooth. So all y-derivatives of order ≤ m of D_p(y) := d(p, κ_α^{-1}y)^2 are bounded on Q_α by a constant A.

By the chain rule (Faà di Bruno), ∂^β [χ(D_p/ρ^2)] is a sum of at most Bell(m) terms of the form χ^{(k)}(D_p/ρ^2) ρ^{-2k} ∏_{i=1}^k ∂^{β_i} D_p, with 1 ≤ k ≤ |β|. Each term is bounded by ‖χ‖_{C^m} ρ^{-2m} max(1,A)^m, because ρ ≤ 1. ∎

**Lemma 0.2 (composition).** For Φ ∈ C^∞(ℝ) and F ∈ C^∞(M),
‖Φ∘F‖_{C^m} ≤ Bell(m) ‖Φ‖_{C^m(ℝ)} (1 + ‖F‖_{C^m})^m, where ‖Φ‖_{C^m(ℝ)} := max_{k≤m} sup|Φ^{(k)}|.

*Proof.* In a chart, Faà di Bruno gives ∂^β(Φ∘F) = Σ_π Φ^{(|π|)}(F) ∏_{B∈π} ∂^{β_B}F. The sum runs over the set partitions π of the |β| differentiations, so there are at most Bell(m) terms. Each term is bounded by ‖Φ‖_{C^m}‖F‖_{C^m}^{|π|} ≤ ‖Φ‖_{C^m}(1+‖F‖_{C^m})^m. ∎

This settles the worry about overlapping bumps: the bound only needs ‖F‖_{C^m}, and that is controlled crudely by the triangle inequality, with no assumption on how much the bumps overlap.

## Step 0. No zeros; flow-box constants

**Lemma 0.3.** Under GH and L_Xω = 0, X has no zeros.

*Proof.* Let X(p) = 0 and let u be the distribution with uω = δ_p. By (0.1) with ν = ω (so P = X), ⟨Xu, φω⟩ = −(Xφ)(p) = 0 for all φ. Hence Xu = 0. GH then makes u smooth, which is impossible, because δ_p is not of the form vω with v smooth. (Lemma 1.1 gives the same contradiction.) ∎

So V = max|X| > 0 and a := min|X| > 0.

**Lemma 0.4.**
(a) There are τ_0 ∈ (0,1] and c_0 > 0 such that d(z, g_s z) ≥ c_0|s| for all z ∈ M and |s| ≤ τ_0.
(b) There is h_0 ∈ (0,1] such that Lip(g_h) ≤ 2 for 0 ≤ h ≤ h_0.

*Proof of (a).* Suppose not. Then there are z_k ∈ M and s_k ≠ 0 with s_k → 0 and d(z_k, g_{s_k}z_k) < |s_k|/k. Pass to a subsequence with z_k → z.

Take a chart κ around z and a compact neighbourhood W of z inside it. On W the Riemannian and chart distances are comparable: |κa − κb| ≤ λ d(a,b) for a, b ∈ W. Let Y := κ_*X. Then Y is continuous and Y(κz) ≠ 0.

For k large and |σ| ≤ |s_k|, the point g_σ z_k lies in W and |Y(κ g_σ z_k) − Y(κz)| ≤ |Y(κz)|/2. Therefore
|κ(g_{s_k}z_k) − κ(z_k)| = |∫_0^{s_k} Y(κ g_σ z_k) dσ| ≥ |s_k||Y(κz)|/2.
Combined with the comparability, this gives d(z_k, g_{s_k}z_k) ≥ |s_k||Y(κz)|/(2λ), which contradicts d(z_k, g_{s_k}z_k) < |s_k|/k for k large.

*Proof of (b).* The map (h,x) ↦ ‖Dg_h(x)‖ is continuous on [0,1] × M. Hence h ↦ sup_x ‖Dg_h(x)‖ is continuous, and it equals 1 at h = 0. Choose h_0 so that this sup is ≤ 2 on [0, h_0], and use Lip ≤ sup‖D·‖. ∎

## Step A. Tame inverse

**Lemma A.1.** Assume GH and L_Xω = 0, ω(M) = 1. There are m ∈ ℕ and C_1 such that every f ∈ C^∞ with ω(f) = 0 can be written f = Xu with u ∈ C^∞ and ‖du‖_∞ ≤ C_1‖f‖_{C^m}. (Equivalently ‖u‖_{C^1} ≤ C_1‖f‖_{C^m} after normalising u, but only du matters below.) The constants m and C_1 depend only on (M, X, ω) and the fixed norms.

*Proof.*

*(1) Tame a-priori estimate.* Use Sobolev spaces H^s built with ω. Fix an integer r > n/2 + 1, so that H^r ⊂ C^1 continuously.

The space F := {u ∈ L^2 : Xu ∈ C^∞}, with the seminorms ‖u‖_{L^2} and ‖Xu‖_{H^j} (j ∈ ℕ), is Fréchet. It is metrizable because the seminorms are countable. It is complete: if (u_k) is Cauchy, then u_k → u in L^2 and Xu_k → f in C^∞; also Xu_k → Xu in H^{-1}; so Xu = f.

By GH, F ⊂ C^∞. The inclusion F → C^∞ has closed graph, because both topologies are finer than L^2. By the closed graph theorem it is continuous. So for each level ℓ there are J and C with
‖u‖_{H^ℓ} ≤ C(‖u‖_{L^2} + ‖Xu‖_{H^J}).
Take J so that this holds for ℓ = r and ℓ = r+1.

*(2) Removing the L^2 term.* Let c(u) := ω(u). We claim ‖u − c(u)‖_{H^r} ≤ C′‖Xu‖_{H^J} for all u ∈ C^∞.

If not, there are smooth u_k with c(u_k) = 0, ‖u_k‖_{H^r} = 1 and ‖Xu_k‖_{H^J} → 0. Since r ≥ 0, the estimate at level r+1 bounds u_k in H^{r+1}. By Rellich, a subsequence converges in H^r to some u with:
* ‖u‖_{H^r} = 1;
* c(u) = 0, because c is L^2-continuous;
* Xu = 0, because Xu_k → Xu in H^{r−1} and Xu_k → 0 in H^J.

By Lemma 1.1 u is constant, so u = c(u) = 0. This contradicts ‖u‖_{H^r} = 1.

*(3) Surjectivity onto ker ω.* First, X(C^∞) ⊂ ker ω, since ω(Xu) = −∫u L_Xω = 0.

Next, X(C^∞) is closed. If Xu_k → f in C^∞, then by (2) the sequence (u_k − c(u_k)) is Cauchy in every H^ℓ. (Apply (2) at every level ℓ in place of r; the same proof works.) So it converges in C^∞ to some u with Xu = f.

Finally, suppose f ∈ ker ω but f ∉ X(C^∞). By Hahn–Banach in the locally convex space C^∞ there is a continuous functional T with T(X(C^∞)) = 0 and T(f) ≠ 0. Let u := T/ω. By (0.1), Xu = 0. By Lemma 1.1, T = cω. Then T(f) = cω(f) = 0, a contradiction.

*(4) Norm conversion.* Let f ∈ ker ω, choose u with Xu = f, and normalise c(u) = 0. Then
‖du‖_∞ ≤ A_0‖u‖_{C^1} ≤ A_0 C_S‖u‖_{H^r} ≤ A_0 C_S C′‖f‖_{H^J} ≤ A_0 C_S C′ C_J‖f‖_{C^J}.
Here C_S is the Sobolev embedding constant, and ‖·‖_{H^J} ≤ C_J‖·‖_{C^J} for integer J. Put m := max(J, 1) and C_1 := A_0 C_S C′ C_J. ∎

**Corollary A.2 (occupation identity and (A1)).** For f ∈ C^∞, x ∈ M and T ≥ 0, put γ_x^T(f) := ∫_0^T f(g_s x) ds, and let u be as in A.1 for f − ω(f). Then
γ_x^T(f) − Tω(f) = u(g_T x) − u(x).
Consequently, for all x, y ∈ M,
|γ_x^T(f) − γ_y^T(f)| ≤ 2C_1‖f‖_{C^m}(d(x,y) + d(g_T x, g_T y)).   (A1)

*Proof.* The identity holds because (d/ds) u(g_s x) = (Xu)(g_s x) = f(g_s x) − ω(f).

For (A1), subtract the identities for x and y; the terms Tω(f) cancel. Then use (L) together with
‖f − ω(f)‖_{C^m} ≤ ‖f‖_{C^m} + |ω(f)| ≤ 2‖f‖_{C^m}. ∎

Both are checked: the C^1/C^m form of the estimate, and the fact that the normalisation of u does not matter.

## Step B. Polynomial no-near-return lemma (uses n ≥ 2)

**Lemma B.1.** There are c_B > 0 and K ≥ 1, depending only on (M, X, ω, the norms, m, C_1), such that
d(z, g_r z) ≥ c_B(1+r)^{−K}  for all z ∈ M and all r ≥ τ_0.

*Proof.*

*Choice of scale.* Fix Φ ∈ C^∞(ℝ, [0,1]) with Φ = 0 on (−∞, 1/4] and Φ = 1 on [1, ∞). Since n ≥ 2, we can fix c ∈ (0, r_*] with C_ω(2Vc^{n−1} + 2c^n) ≤ 1/2.

Given z and r ≥ τ_0, put:
* ρ := c(1+r)^{−1/(n−1)} ≤ r_* ≤ 1;
* Δ := ρ/(2V) and N := ⌈r/Δ⌉;
* p_i := g_{iΔ}z for 0 ≤ i ≤ N;
* b_i := b_{p_i,ρ} (Lemma 0.1), F := Σ_{i=0}^N b_i and ψ := Φ∘F.

*ψ = 1 on the orbit segment.* For s ∈ [0, r], let i := ⌊s/Δ⌋ ≤ N. Then d(g_s z, p_i) ≤ V(s − iΔ) ≤ VΔ = ρ/2. So b_i(g_s z) = 1, hence F(g_s z) ≥ 1 and ψ(g_s z) = 1.

*Mass.* We have 0 ≤ ψ ≤ 1, and ψ vanishes wherever F < 1/4, in particular off ∪_i B(p_i, ρ). Using N + 1 ≤ 2Vr/ρ + 2,
ω(ψ) ≤ (N+1)C_ωρ^n ≤ C_ω(2Vrρ^{n−1} + 2ρ^n) ≤ C_ω(2Vc^{n−1}·r/(1+r) + 2c^n) ≤ 1/2.
This is the only place where n ≥ 2 is used: for n = 1 the scale ρ ~ (1+r)^{−1/(n−1)} does not exist, and indeed a circle has periodic orbits returning exactly.

*C^m bound.* Since ρ ≤ 1, N + 1 ≤ (2V+2)(1+r)/ρ, so
‖F‖_{C^m} ≤ (N+1)C_bρ^{−2m} ≤ C_b(2V+2)c^{−(2m+1)}(1+r)^e,  where e := 1 + (2m+1)/(n−1).
By Lemma 0.2, ‖ψ‖_{C^m} ≤ A_3(1+r)^{me}, where A_3 := Bell(m)‖Φ‖_{C^m}(1 + C_b(2V+2)c^{−(2m+1)})^m. (This used 1 + A(1+r)^e ≤ (1+A)(1+r)^e.)

*Applying Step A.* Let f := 1 − ψ. Then γ_z^r(f) = 0 and ω(f) = 1 − ω(ψ) ≥ 1/2. Also f − ω(f) = ω(ψ) − ψ, whose C^m norm is ≤ 2‖ψ‖_{C^m}. By Corollary A.2 with u := R(f − ω(f)),
r/2 ≤ rω(f) = |γ_z^r(f) − rω(f)| = |u(g_r z) − u(z)| ≤ 2C_1‖ψ‖_{C^m} d(z, g_r z).

*Conclusion.* Since r ≥ τ_0 implies r ≥ (τ_0/(1+τ_0))(1+r),
d(z, g_r z) ≥ r/(4C_1A_3(1+r)^{me}) ≥ c_B(1+r)^{−(me−1)},  where c_B := τ_0/(4C_1A_3(1+τ_0)).
Put K := max(me − 1, 1). Since (1+r)^{−(me−1)} ≥ (1+r)^{−K}, the claim follows. ∎

## Step C. Hausdorff closeness

Put C_C := 8VC_1C_b and ρ(η) := (C_C η)^{1/(2m+1)}.

**Lemma C.1.** Let x, y ∈ M, T ≥ 1 and η > 0 with d(x,y) + d(g_T x, g_T y) ≤ η. Suppose ρ := ρ(η) ≤ min(r_*, 2V). Then for every t ∈ [0, T] there is σ ∈ [0, T] with d(g_t y, g_σ x) ≤ ρ.

*Proof.* Let q := g_t y and suppose dist(q, g_{[0,T]}x) > ρ. Since the segment is compact and the distance function is continuous, it suffices to derive a contradiction from this.

*The test function.* Let ψ := b_{q,ρ} (Lemma 0.1). Its support lies in B̄(q, 3ρ/4), which is disjoint from the segment, so γ_x^T(ψ) = 0.

*The window around t.* Put w := ρ/(2V) ≤ 1 ≤ T. For s in I := [t−w, t+w] ∩ [0, T] we have d(g_s y, q) ≤ V|s − t| ≤ ρ/2, so ψ(g_s y) = 1.

*Endpoint bookkeeping.* The length of I is min(t+w, T) − max(t−w, 0). We check that it is ≥ w in all cases:
* if t + w ≤ T, the length is ≥ (t+w) − t = w;
* if t + w > T and t ≥ w, the length is T − t + w ≥ w;
* if t + w > T and t < w, the length is T ≥ w.

Hence γ_y^T(ψ) ≥ w = ρ/(2V).

*Contradiction.* By (A1),
ρ/(2V) ≤ |γ_y^T(ψ) − γ_x^T(ψ)| ≤ 2C_1C_bρ^{−2m}η,
that is, ρ^{2m+1} ≤ 4VC_1C_bη = C_Cη/2. But ρ^{2m+1} = C_Cη by definition, and C_Cη > C_Cη/2 since η > 0. Contradiction. ∎

## Step D. Shadowing in time

Put B := (2m+1)(K+2), η_T := T^{−B} and ρ_T := ρ(η_T) = C_C^{1/(2m+1)} T^{−(K+2)}. Then B depends only on m and K.

**Lemma D.1.** For every ε > 0 there is T_0(ε) ≥ 1 with the following property. If T ≥ T_0(ε), x, y ∈ M and d(x,y) + d(g_T x, g_T y) ≤ η_T, then d(g_t x, g_t y) < ε for all t ∈ [0, T].

*Proof.*

*Choice of T_0.* Write ρ := ρ_T. Choose T_0(ε) so that for all T ≥ T_0(ε):
1. ρ ≤ min(r_*, 2V);
2. η_T ≤ ρ;
3. 3ρ < c_B(T+2)^{−K};
4. 2ρ + 12VTρ/(c_0h_0) < ε.

All four are possible:
* ρ → 0, which gives (1);
* η_T/ρ = C_C^{−1/(2m+1)} T^{−(B − K − 2)} → 0, which gives (2);
* ρ(T+2)^K ≤ C_C^{1/(2m+1)} 3^K T^{−2} → 0, which gives (3);
* Tρ = C_C^{1/(2m+1)} T^{−K−1} → 0, which gives (4).

*(i) Separation of times.* Let s_1, s_2 ∈ [0, T+1] with d(g_{s_1}x, g_{s_2}x) ≤ 3ρ. We claim |s_1 − s_2| ≤ 3ρ/c_0.

Suppose instead that r := |s_1 − s_2| ≥ τ_0. Then r ≤ T+1. Applying Lemma B.1 to z := g_{min(s_1,s_2)}x gives d ≥ c_B(2+T)^{−K} > 3ρ by (3), a contradiction. So r < τ_0, and Lemma 0.4(a) gives c_0 r ≤ 3ρ.

*(ii) The time grid.* Let k_max := ⌈T/h_0⌉ and h := T/k_max. Then h ≤ h_0. Since T ≥ 1 ≥ h_0, we have k_max ≤ T/h_0 + 1 ≤ 2T/h_0.

For each k = 0, …, k_max, Lemma C.1 (applicable by (1)) gives σ_k ∈ [0, T] with d(g_{kh}y, g_{σ_k}x) ≤ ρ. Take σ_0 := 0, which is allowed because d(y, x) ≤ η_T ≤ ρ by (2).

*(iii) Induction.* Let 0 ≤ k < k_max. By Lemma 0.4(b),
d(g_{(k+1)h}y, g_{σ_k+h}x) ≤ 2d(g_{kh}y, g_{σ_k}x) ≤ 2ρ.
Together with d(g_{(k+1)h}y, g_{σ_{k+1}}x) ≤ ρ, this gives d(g_{σ_k+h}x, g_{σ_{k+1}}x) ≤ 3ρ.

Both times lie in [0, T+1]: σ_k + h ∈ [h, T+h] with h ≤ 1, and σ_{k+1} ∈ [0, T]. So (i) applies, and |σ_{k+1} − σ_k − h| ≤ 3ρ/c_0. Since σ_0 = 0, induction gives
|σ_k − kh| ≤ 3kρ/c_0 ≤ 6Tρ/(c_0h_0)  for all k ≤ k_max.

*(iv) Conclusion.* Let t ∈ [0, T]. Choose k ≤ k_max − 1 with t ∈ [kh, (k+1)h]. Then t − kh ∈ [0, h_0], and by Lemma 0.4(b)
d(g_t x, g_t y) ≤ 2d(g_{kh}x, g_{kh}y) ≤ 2(d(g_{kh}x, g_{σ_k}x) + d(g_{σ_k}x, g_{kh}y)) ≤ 2(V|kh − σ_k| + ρ) ≤ 2ρ + 12VTρ/(c_0h_0) < ε,
by (4). ∎

Both are checked: σ_k + h may exceed T, which is why (i) is stated on [0, T+1] and Lemma B.1 is used with r ≤ T+1; and the starting point σ_0 = 0 is legitimate.

## Step E. Counting and entropy

**Definition (Bowen).** For a continuous map G of a compact metric space (M, d), a set E ⊂ M is (k, ε)-separated if for all x ≠ y in E, max_{0≤i≤k−1} d(G^i x, G^i y) > ε. Let s(k, ε) be the maximal cardinality of a (k, ε)-separated set. Then
h_top(G) = lim_{ε→0} limsup_{k→∞} (1/k) log s(k, ε).
(Cited from memory: Bowen's definition, which agrees with the Adler–Konheim–McAndrew definition on compact metric spaces and does not depend on the choice of compatible metric.) The entropy of the flow is h_top(g_1) by definition, and h_top(g_t) = |t|h_top(g_1).

**Partitions.** For 0 < η ≤ r_* there is a partition of M into at most N(η) ≤ C_Mη^{−n} Borel sets, each of diameter ≤ η/2.

*Proof.* Let {p_j} be a maximal η/4-separated set. The balls B(p_j, η/8) are disjoint, so there are at most 1/(c_ω(η/8)^n) =: C_Mη^{−n} points. The balls B(p_j, η/4) cover M by maximality. Take A_j := B(p_j, η/4) \ ∪_{i<j} B(p_i, η/4). Each A_j has diameter ≤ η/2. ∎

**Theorem V.** h_top(g_1) = 0.

*Proof.* Fix ε > 0 and an integer T ≥ T_0(ε) with η_T ≤ r_*. Let E be a (T+1, ε)-separated set for G = g_1.

Assign to x ∈ E the pair (cell of x, cell of g_T x), using the partition at scale η_T. This assignment is injective. Indeed, suppose x ≠ y share both cells. Then d(x,y) + d(g_T x, g_T y) ≤ η_T, so Lemma D.1 gives d(g_i x, g_i y) < ε for all integers 0 ≤ i ≤ T. This contradicts separation.

Hence s(T+1, ε) ≤ N(η_T)^2 ≤ C_M^2 T^{2nB}, and so
(1/(T+1)) log s(T+1, ε) ≤ (2 log C_M + 2nB log T)/(T+1) → 0.
Thus limsup_k (1/k) log s(k, ε) = 0 for each ε > 0, and h_top(g_1) = 0. ∎

In fact the proof gives more: the number of (T, ε)-distinguishable orbit segments grows at most polynomially, with s(T+1, ε) ≤ C T^{2nB} for T ≥ T_0(ε), and the exponent 2nB does not depend on ε.

## Dependency chain of the constants (no circularity)

1. Geometry: r_*, c_ω, C_ω, C_b, A_0 and C_M come from (M, metric, ω, the atlas, m).
   * The C^m norm's order m is fixed in step 2. C_b depends on m, but C_b is used only after m is fixed.
2. GH: m and C_1 (Lemma A.1). These depend only on X, ω and the Sobolev/C^m norms.
3. Flow: V, τ_0, c_0, h_0 (Step 0). These depend on X only.
4. Step B: c, A_3, c_B, K, from items 1–3.
5. Step C: C_C = 8VC_1C_b.
6. Step D: B = (2m+1)(K+2), and then T_0(ε) from conditions (1)–(4).
7. Step E: the exponent 2nB.

## Hypotheses actually used

The proof of h_top(g_1) = 0, together with the polynomial bound on separated sets, uses only:
* (H1) M is compact and connected, with n = dim M ≥ 2;
* (H2) X has no zeros (used for c_0 and τ_0 in Lemma 0.4(a), and for V > 0);
* (H3) there is a smooth positive probability density ω that is X-invariant;
* (H4) there are m, C_1 such that every smooth f with ω(f) = 0 equals Xu for some smooth u with ‖du‖_∞ ≤ C_1‖f‖_{C^m} ("tamely cohomology-free").

How these are used:
* Invariance of ω enters only through (H4) and through the identity γ − Tω(f) = u(g_T x) − u(x). The volume bounds for balls need only smoothness and positivity of ω.
* GH together with (H3) implies (H2) (Lemma 0.3) and (H4) (Lemma A.1).
* Lemma 1.1 (the kernel lemma) is used only inside Lemma A.1.

So Theorem V holds for every tamely cohomology-free nonsingular flow preserving a smooth volume on a manifold of dimension ≥ 2. For n = 1, M is a circle and g_1 is a circle homeomorphism, so the entropy is 0 anyway.

## What is proved and what is open
