# Commit query: the general case directly, by extending the volume-case occupation-measure argument (without first proving a smooth invariant volume)

Route: run the occupation-measure / pigeonhole argument of Theorem V (sketched at the end) on a positive-entropy ergodic measure μ instead of on a smooth invariant volume. Use Katok's entropy formula to obtain e^{(h−δ)T} separated μ-good points, pigeonhole them on (x, g_Tx) plus finitely many extra coordinates, and control the obstruction coming from invariant distributions. **Write the full rigorous proof of the problem** (zero topological entropy for every GH field), or, if the route fails, prove the strongest partial statement and isolate the exact missing lemma.

## Context

The volume-preserving case is now handled (Theorem V below; its route is reproduced at the end of this query). The remaining case is a GH field X with no smooth invariant density. Earlier work proved the problem in dimension ≤ 3. In higher dimensions it showed that a positive-entropy ergodic measure must be non-hyperbolic, with (modulo a cited normal-form theorem) zero mean divergence and full support.

## Facts already established under GH (you may use them; the short proofs are indicated, so check them if you rely on them)

Notation: ν is a smooth positive density, d = div_ν X, J_t(x) = ∫_0^t d(g_s x) ds (log ν-Jacobian of g_t, cocycle J_{t+s}(x) = J_s(x) + J_t(g_s x)), Pφ = Xφ + dφ (so L_X(φν) = (Pφ)ν), and Γ_tφ = e^{J_t}·φ∘g_t, with (d/dt)Γ_tφ = Γ_t(Pφ). An invariant distribution density is a continuous linear functional T on C^∞(M) with T(Xφ) = 0 for all φ; their space is I.

1. (Kernel) If u ∈ D′ and Xu = 0, then u is constant. (By GH u is smooth. If it is not constant, smooth level-set truncations give a non-continuous L^∞ solution 1_{u ≥ c} of Xv = 0, which contradicts GH.)
2. (F1) If S is a distribution density with S(Pφ) = 0 for all φ, then S = cν. (F2) If S(Pφ) = c′∫φ dν for all φ, then c′ = 0. (Apply 1 to u = S/ν; for (F2), Xu = −c′ is smooth, so u is smooth, and u has a maximum.)
3. (Tame closed range) X(C^∞) is closed in C^∞ and equals I^⊥. There are m and C with ‖u − c(u)‖_{C^1} ≤ C‖Xu‖_{C^m} for all smooth u, where c(u) is a fixed normalised mean. (Closed graph theorem plus Rellich plus fact 1.)
4. (Dual solvability) For every distribution density T of order ≤ 1 with T(1) = 0, there is S of order ≤ m with S(Xφ) = T(φ) for all φ and ‖S‖_{(C^m)′} ≤ C‖T‖_{(C^1)′}. (Define S on X(C^∞) via fact 3, then extend by Hahn–Banach.)
5. (Equivalent forms of (V), all proved earlier in this attempt.) Under GH, the following are equivalent:
   * (V);
   * dim I = 1;
   * every T ∈ I satisfies T(d) = 0;
   * there is a distribution u with Xu = −d + c for a constant c (then u is smooth by GH, and e^{u}ν is invariant; integrating the divergence shows c = 0);
   * P = X + d has closed range in C^∞;
   * X(D′) is weak-*-closed, i.e. every smooth f equals c + Xu with c constant and u ∈ D′;
   * sup_{t∈ℝ, x∈M} |J_t(x)| < ∞;
   * some x has sup_{t≥0}|J_t(x)| < ∞;
   * some absolutely continuous invariant probability hν has log h ∈ L^1(ν) (or has density bounded below by δ > 0 on a nonempty open set).
6. (Closed orbits) If g_P q = q with P > 0 (and n ≥ 2), then J_P(q) ≠ 0. In particular d(p) ≠ 0 at every zero p of X. (Apply (F1) to S(φ) := ∫_0^P e^{J_s(q)}φ(g_s q) ds, which satisfies S(Pφ) = (e^{J_P(q)} − 1)φ(q).)
7. (Theorem J) If a distribution density S satisfies |S(Γ_tφ)| ≤ Ce^{−ε|t|}‖φ‖_{C^k} for all real t and smooth φ, then S = 0. (Moments m_j(φ) = ∫t^j S(Γ_tφ) dt satisfy m_0(Pφ) = 0 and m_j(Pφ) = −j m_{j−1}(φ); by (F1)/(F2) all m_j vanish; then a Fourier–Laplace argument.)
8. Consequences of 7: no hyperbolic periodic orbit or hyperbolic zero has a homoclinic point. No hyperbolic attracting or repelling closed orbit exists. Every positive-entropy ergodic measure is non-hyperbolic. Modulo a cited normal-form theorem, every g_1-ergodic μ of positive entropy has ∫J_1 dμ = 0. Every g_1-ergodic μ with ∫J_1dμ = 0 has full support (Atkinson's recurrence theorem plus (F1)). The ν-class is ergodic: invariant Borel sets are ν-null or ν-conull.
9. Unique ergodicity would imply μ(d) = 0 for the unique invariant μ, and minimality.


## The obstruction in the non-volume case (proved; you must get around it)

**Proposition E.** Under GH, with m, C as in fact 3, every finite combination Λ of orbit-segment measures (γ_x^T(φ) := ∫_0^T φ(g_sx) ds) and exponentially asymptotic leg functionals lies within C′‖∂Λ‖_W of I in (C^{m′})′. Here ∂Λ is its boundary measure and ‖·‖_W is the Kantorovich norm. For example, γ_x^T − γ_y^T = T_{xy} + E_{xy} with T_{xy} ∈ I, T_{xy}(1) = 0, and ‖E_{xy}‖_{(C^{m′})′} ≤ C′(d(x,y) + d(g_Tx, g_Ty)).
*Proof.* (γ_x^T − γ_y^T)(Xφ) = φ(g_Tx) − φ(x) − φ(g_Ty) + φ(y). By fact 3 this is a functional on X(C^∞) ⊕ ℝ1 (set it to 0 on 1) of size ≤ C(d(x,y) + d(g_Tx, g_Ty))‖Xφ‖_{C^m}. Extend it by Hahn–Banach to E_{xy}, and put T_{xy} := (γ_x^T − γ_y^T) − E_{xy}, which annihilates X(C^∞). ∎

In the volume case I = ℝω, so T_{xy} = 0, and the bump test of Step C works. In general the bump test gives only |T_{xy}(ψ_q)| ≳ ρ whenever y's orbit visits q and x's orbit does not. So what is needed is control of T_{xy} ∈ I_0 := {T ∈ I : T(1) = 0} on bumps at scale ρ = T^{−B′}, for suitably many μ-typical pairs.

## Suggested programme (verify or replace each step)

1. Take μ g_1-ergodic with h := h_μ(g_1) > 0 (variational principle). Katok's entropy formula: for every set G with μ(G) ≥ 1/2, a maximal (T, ε)-separated subset of G has at least e^{(h−δ)T} points for T large and ε small.
2. **No-near-return for μ-most points.** Show that μ{x : ∃ s_1, s_2 ∈ [−1, T+1], |s_1 − s_2| ≥ τ_0, d(g_{s_1}x, g_{s_2}x) ≤ T^{−K′}} → 0 as T → ∞, for K′ large. Possible tools: Lipschitz control (a δ-close pair stays ε-close for time ≈ log(ε/δ)/Λ, so near-returns are returns to Bowen balls); Ornstein–Weiss / Varandas-type lower bounds for return times to Bowen balls of positive-entropy measures (cite precisely, or prove the weak form needed); a Borel–Cantelli / Kac argument. Handle the real-time (flow) version, i.e. returns to a tube around the orbit, not only to the point. If this needs GH or μ(d) = 0, say so.
3. **Hausdorff step with weights or extra coordinates.** Either:
   (i) use Jacobian-weighted occupation measures γ̃_x^T(φ) := ∫_0^T e^{J_s(x)}φ(g_sx) ds, for which γ̃_x^T(Pφ) = e^{J_T(x)}φ(g_Tx) − φ(x), and whose dual obstruction space {T : T∘P = 0} is ℝν by (F1). The difficulty is that P need not have closed range. Find a quantitative approximate solvability of Pv = ψ − c·1 for bumps ψ, with polynomial bounds on ‖v‖_{C^1} and exponentially small sup-norm error, that suffices along μ-typical segments where J_s = o(s). Or:
   (ii) control T_{xy} ∈ I_0 on bumps by adding finitely many (polynomially many in T, with polynomially many cells each) coordinates to the pigeonhole, e.g. if I ∩ (C^{m′})′ is finite-dimensional, or if a polynomially-sized family of functionals controls the I_0-component on all bumps of scale ρ. Prove whatever finiteness you need from GH, or show it fails.
4. Shadowing and counting exactly as in Steps D–E of Theorem V, restricted to the good set of step 2. This gives fewer than e^{(h−δ)T} separated good points, contradicting step 1.

If you can instead prove that GH forces a smooth invariant density, that also finishes the problem (with Theorem V), and is equally welcome.

## What to deliver

A complete rigorous proof of the problem for general GH fields, or the strongest proved partial result together with a precise statement of the single missing lemma and why it is needed. Mark cited theorems clearly, with the exact form used. Do not overclaim.

## Reference: the route of Theorem V (volume case), as sketched by the planner

In this sketch, "Proposition 7.1" is the statement that, when X preserves ω, GH is equivalent to: every ω-mean-zero smooth f is Xu with u smooth (this follows from facts 1 and 3 above, since then I = ℝω). "Lemma 1.4" is fact 3.

## The route (planner's sketch: verify every step and write it out in full)

Throughout, assume GH, n ≥ 2, L_Xω = 0, ω(M) = 1. Fix a Riemannian distance d(·,·), and put V := max|X|.

**Step 0 (no zeros, flow box).** With ν = ω we have div_ω X = 0. A zero p of X would make δ_p/ω a non-smooth distribution u with Xu = 0 (check: ⟨Xu, φω⟩ = −⟨u, L_X(φω)⟩ = −(Xφ)(p) = 0). This contradicts GH, so X has no zeros and V > 0. By compactness there are τ_0 > 0 and c_0 > 0 with d(z, g_s z) ≥ c_0|s| for all z ∈ M and |s| ≤ τ_0. There is also h_0 ∈ (0,1] with Lip(g_h) ≤ 2 for 0 ≤ h ≤ h_0.

**Step A (tame inverse).** By Proposition 7.1, every smooth f with ω(f) = 0 equals Xu for a smooth u, unique up to an additive constant. By Lemma 1.4 and Sobolev embedding, there are m ∈ ℕ and C_1 such that this u can be chosen with ‖u‖_{C^1} ≤ C_1‖f‖_{C^m}. (Check that the normalisation of u and the passage from H^r/H^j norms to C^1/C^m norms are correct.) Write u = R f.

Consequence used repeatedly: for every x ∈ M, T ≥ 0 and smooth f, with γ_x^T(f) := ∫_0^T f(g_s x) ds,

  γ_x^T(f) − T ω(f) = u(g_T x) − u(x),  u := R(f − ω(f)),

since ∫_0^T (Xu)(g_s x) ds = u(g_T x) − u(x). In particular, for any x, y ∈ M,

  |γ_x^T(f) − γ_y^T(f)| ≤ 2C_1‖f‖_{C^m}·(d(x,y) + d(g_T x, g_T y)),   (A1)

using |u(a) − u(b)| ≤ ‖u‖_{C^1} d(a,b) and ‖f − ω(f)‖_{C^m} ≤ 2‖f‖_{C^m}.

**Step B (polynomial no-near-return lemma).** Claim: there are c_B > 0 and K ≥ 1 such that for every z ∈ M and every r ∈ [τ_0, ∞),

  d(z, g_r z) ≥ c_B (1 + r)^{−K}.

Sketch. Suppose d(z, g_r z) ≤ δ. Build a smooth ψ with 0 ≤ ψ ≤ 1, ψ = 1 on the orbit segment g_{[0,r]}z, ω(ψ) ≤ 1/2, and ‖ψ‖_{C^m} ≤ C(1 + r)^{a} ρ^{−b}, at a scale ρ ≈ c(1 + r)^{−1/(n−1)}. For example, take points p_i := g_{iρ/(2V)}z, 0 ≤ i ≤ N := ⌈2Vr/ρ⌉, so that the segment lies in ∪B(p_i, ρ/4). Take bumps b_i with b_i = 1 on B(p_i, ρ/2), supp b_i ⊂ B(p_i, ρ) and ‖b_i‖_{C^m} ≤ Cρ^{−m}. Put F := Σ b_i and ψ := Φ∘F, with Φ smooth, Φ = 0 near 0, Φ = 1 on [1, ∞) and 0 ≤ Φ ≤ 1. Then ω(ψ) ≤ (N+1) C_ω ρ^n ≤ 1/2 for ρ = c(1 + r)^{−1/(n−1)} (this is where n ≥ 2 is used), and Faà di Bruno gives the polynomial C^m bound. Let f := 1 − ψ. Then γ_z^r(f) = 0 and ω(f) ≥ 1/2, so by Step A

  r/2 ≤ |γ_z^r(f) − rω(f)| = |u(g_r z) − u(z)| ≤ 2C_1‖ψ‖_{C^m} δ.

Hence δ ≥ c(1 + r)^{−K}. Check the details, in particular the C^m bound for Φ∘F when many bumps overlap. A crude bound polynomial in r and 1/ρ suffices.

**Step C (Hausdorff closeness).** Claim: there is C_C such that if x, y ∈ M, T ≥ 1 and d(x,y) + d(g_T x, g_T y) ≤ η, then every point g_t y (0 ≤ t ≤ T) lies within distance ρ := (C_C η)^{1/(m+1)} of the segment g_{[0,T]}x, provided ρ ≤ min(r_*, V) (r_* a fixed small radius).

Sketch. Let q := g_t y, and suppose d(q, g_{[0,T]}x) > ρ. Take a bump ψ_q with 0 ≤ ψ_q ≤ 1, ψ_q = 1 on B(q, ρ/2), supp ψ_q ⊂ B(q, ρ) and ‖ψ_q‖_{C^m} ≤ C_χ ρ^{−m}. Then γ_x^T(ψ_q) = 0. Also γ_y^T(ψ_q) ≥ ρ/(2V), because g_s y ∈ B(q, ρ/2) for |s − t| ≤ ρ/(2V), and at least half of that window lies in [0, T]. Then (A1) gives ρ/(2V) ≤ 2C_1C_χρ^{−m}η, which is false for C_C := 8VC_1C_χ, say.

**Step D (shadowing in time).** Fix ε > 0. Claim: for all large T, if d(x,y) + d(g_T x, g_T y) ≤ η_T := T^{−B} (B a large constant depending only on m, K, n), then d(g_t x, g_t y) < ε for all t ∈ [0, T].

Sketch. Let ρ = (C_C η_T)^{1/(m+1)}, and take T so large that 4ρ < c_B (T + 3)^{−K}. By Step B and Step 0: if s_1, s_2 ∈ [−1, T+1] and d(g_{s_1}x, g_{s_2}x) ≤ 4ρ, then |s_1 − s_2| < τ_0 (otherwise Step B at z = g_{min(s_1,s_2)}x with r = |s_1 − s_2| ∈ [τ_0, T+2] is violated), and hence |s_1 − s_2| ≤ 4ρ/c_0. Fix h ∈ (0, h_0] with T/h =: k_max an integer. For k = 0, …, k_max choose σ_k ∈ [0, T] with d(g_{kh}y, g_{σ_k}x) ≤ ρ (Step C); take σ_0 := 0, which is allowed since d(x,y) ≤ η_T ≤ ρ. Then d(g_{(k+1)h}y, g_{σ_k + h}x) ≤ 2ρ, and d(g_{(k+1)h}y, g_{σ_{k+1}}x) ≤ ρ. So d(g_{σ_k+h}x, g_{σ_{k+1}}x) ≤ 3ρ, and therefore |σ_{k+1} − σ_k − h| ≤ 4ρ/c_0 (both times lie in [−1, T+1]). By induction |σ_k − kh| ≤ 4kρ/c_0 ≤ 4Tρ/(c_0 h). For t ∈ [kh, (k+1)h],

  d(g_t x, g_t y) ≤ 2 d(g_{kh}x, g_{kh}y) ≤ 2(ρ + V|σ_k − kh|) ≤ 2ρ + 8VTρ/(c_0 h),

which is < ε once B is large and T is large, because ρ ≈ T^{−B/(m+1)}.

**Step E (counting).** Let E be a (T, ε)-separated set for the flow: for x ≠ y in E, max_{t∈[0,T]} d(g_t x, g_t y) ≥ ε. Partition M into N(η) ≤ C_M η^{−n} Borel sets of diameter ≤ η/2. If x ≠ y in E had x, y in one cell and g_T x, g_T y in one cell, Step D would be contradicted. So |E| ≤ N(η_T)^2 ≤ C T^{2nB}. A (T, ε)-separated set for the time-one map, using integer times 0, …, T, is also (T, ε)-separated in this sense. Hence h_top(g_1) = lim_{ε→0} limsup_{T→∞} (1/T) log s(T, ε) ≤ limsup (2nB log T + C)/T = 0.
