# r3_q2 — Proof of Theorem V (volume-preserving case), route A–E

**Verdict.** The route is correct, and Theorem V is proved below in full. I changed two details of the sketch, and both changes make the proof simpler.
(i) In Step B I test against F = Σ b_i itself rather than Φ∘F. Only linearity and positivity are needed, so no Faà di Bruno estimate is required.
(ii) In Step D, h := T/⌈T/h_0⌉.
There is no circularity in the constants; the dependency chain is in §6. Standard facts are cited from memory and named as such.

## 0. Conventions and standard facts

M is compact and connected, n = dim M ≥ 2, and d is a Riemannian distance. ‖φ‖_{C^k} := max_{j≤k} sup|∇^jφ|, so ‖φ‖_∞ ≤ ‖φ‖_{C^k}. Since M is connected and d is the length metric, |φ(a) − φ(b)| ≤ ‖dφ‖_∞ d(a,b) ≤ ‖φ‖_{C^1} d(a,b).

Standard facts used:

(F1) **Uniform bumps.** There are ρ_* ∈ (0,1] and C_χ such that for every p ∈ M and ρ ∈ (0, ρ_*] there is a smooth b with 0 ≤ b ≤ 1, b = 1 on the closed ball B̄(p, ρ/2), b = 0 off {d(p,·) < ρ}, and ‖b‖_{C^m} ≤ C_χ ρ^{−m}.
*Proof sketch.* Take b = χ(d(p,·)²/ρ²), with χ = 1 on [0,1/4] and χ = 0 on [1,∞). Take ρ_* less than half the injectivity radius, so that d(p,·)² is smooth on the support with derivatives bounded uniformly in p, and |∇d²| ≤ 2d ≤ 2ρ there. Expanding ∇^k by the chain rule gives terms χ^{(a)}ρ^{−2a}∏_{i=1}^a ∇^{j_i}d² with Σj_i = k. Say p of the j_i equal 1. Then k ≥ p + 2(a−p), so p ≥ 2a − k. Each first-order factor is O(ρ), so the term is O(ρ^{−2a+max(0,2a−k)}) = O(ρ^{−k}) ⊂ O(ρ^{−m}), since ρ ≤ 1.

(F2) **Ball volumes.** There are constants with c_ω s^n ≤ ω(B(p,s)) ≤ C_ω s^n for all p and all s ≤ ρ_*. This follows from compactness and bi-Lipschitz charts. (Shrink ρ_* if necessary.)

(F3) **Lipschitz bound.** Let L := sup‖∇X‖. Then Lip(g_t) ≤ e^{L|t|}, because d/dt|Dg_t v| ≤ L|Dg_t v| and d is a length metric. Fix h_0 ∈ (0,1] with e^{Lh_0} ≤ 2.

(F4) **Entropy (Bowen's definition, which agrees with the Adler–Konheim–McAndrew definition on compact metric spaces; cited from memory).** For a homeomorphism f, let s_N(ε) be the maximal cardinality of a set E such that for x ≠ y in E, max_{0≤j≤N−1} d(f^jx, f^jy) > ε. Then h_top(f) = lim_{ε→0} limsup_{N→∞} (1/N) log s_N(ε). Moreover h_top(g_t) = |t|·h_top(g_1) (standard, cited), and the entropy of the flow is h_top(g_1).

## 1. Step 0: no zeros and flow-box constants

Suppose X(p) = 0, and put u := δ_p/ω. Then ⟨Xu, φω⟩ = −⟨u, L_X(φω)⟩ = −⟨u, (Xφ)ω⟩ = −(Xφ)(p) = 0, because div_ω X = 0 and X(p) = 0. So Xu = 0 with u not smooth, which contradicts GH. Hence v_0 := min|X| > 0 and V := max|X| > 0.

**Short-time displacement.** Let F(s,z) := d(z, g_s z)². Since d² is smooth near the diagonal, F is smooth for |s| ≤ s_1, with F(0,z) = 0 and ∂_sF(0,z) = 0. Also ∂_s²F(0,z) = 2|X(z)|², because the Hessian of d(z,·)² at z is 2g. Third derivatives are bounded uniformly in z by compactness. So by Taylor's theorem, F(s,z) ≥ s²v_0² − C|s|³ ≥ s²v_0²/4 for |s| ≤ τ_0, for a small τ_0 > 0. Hence

  d(z, g_s z) ≥ c_0|s| for |s| ≤ τ_0, with c_0 := v_0/2.  (0.2)

Also, trivially, d(z, g_s z) ≤ V|s|.

## 2. Step A: tame inverse in C^1/C^m form

By Proposition 7.1 (GH ⇒ CF; I checked its proof): X(C^∞) = {f : ω(f) = 0}. The kernel of X on C^∞ is the constants (Lemma 1.1).

**Lemma A.** There are m ∈ ℕ and C_1 such that for every smooth f with ω(f) = 0 there is a unique smooth u with Xu = f and ω(u) = 0, and ‖u‖_{C^1} ≤ C_1‖f‖_{C^m}. Write u = Rf. The map R is linear.

*Proof.* Existence comes from CF, and uniqueness from Lemma 1.1. Apply Lemma 1.4 with ω₀ := ω. Its proof gives: for each r there are j and C′ with ‖u − c(u)‖_{H^r} ≤ C′‖Xu‖_{H^j} for all smooth u.

I checked the details of that proof. The closed-graph estimate at levels r and r+1 holds with a common j (take the larger of the two). This bounds a normalised sequence in H^{r+1}. By Rellich it has a limit in H^r with Xu = 0, since Xu_m → Xu in H^{r−1} and Xu_m → 0 in H^j. By Lemma 1.1 that limit is constant, and the constant is 0 because c(u) = 0. This contradicts ‖u‖_{H^r} = 1.

Now choose r > n/2 + 1. Sobolev embedding gives ‖v‖_{C^1} ≤ C_S‖v‖_{H^r}. On a compact manifold ‖f‖_{H^j} ≤ C″‖f‖_{C^j}, since the H^j norm is an L² norm of derivatives up to order j in finitely many charts. Put m := j and C_1 := C_S C′ C″. For u = Rf we have c(u) = ω(u) = 0, so ‖u‖_{C^1} ≤ C_1‖f‖_{C^m}. ∎

**Consequence (A0), (A1).** For smooth f, x ∈ M and T ≥ 0, put u := R(f − ω(f)). Then

  γ_x^T(f) − Tω(f) = ∫_0^T (Xu)(g_s x) ds = u(g_T x) − u(x).  (A0)

Since ‖f − ω(f)‖_{C^m} ≤ ‖f‖_{C^m} + ‖f‖_∞ ≤ 2‖f‖_{C^m} (ω is a probability), we get for all x, y:

  |γ_x^T(f) − γ_y^T(f)| ≤ 2C_1‖f‖_{C^m}(d(x,y) + d(g_Tx, g_Ty)).  (A1)

## 3. Step B: polynomial no-near-return

**Lemma B.** Put K := (m+1)/(n−1). There is c_B > 0 such that d(z, g_r z) ≥ c_B(1+r)^{−K} for all z ∈ M and all r ≥ τ_0.

*Proof.* Fix c ∈ (0, ρ_*] with C_ω(2Vc^{n−1} + 2c^n) ≤ 1/2, and set ρ := c(1+r)^{−1/(n−1)} ≤ ρ_*. Here n ≥ 2 is used.

Let N := ⌈2Vr/ρ⌉, p_i := g_{iρ/(2V)}z for 0 ≤ i ≤ N, let b_i be the bump of (F1) at (p_i, ρ), and put F := Σ_{i=0}^N b_i ≥ 0.

*Covering.* For s ∈ [0,r], let i := ⌊2Vs/ρ⌋ ≤ N. Then 0 ≤ s − iρ/(2V) < ρ/(2V), so d(g_s z, p_i) ≤ ρ/2 and b_i(g_s z) = 1. Hence F ≥ 1 on g_{[0,r]}z, and γ_z^r(F) ≥ r.

*Mass.* By (F2), ω(F) ≤ (N+1)C_ωρ^n ≤ C_ω(2Vrρ^{n−1} + 2ρ^n). Now rρ^{n−1} = c^{n−1}r/(1+r) ≤ c^{n−1} and ρ ≤ c, so ω(F) ≤ 1/2.

*Norm.* By (F1), ‖F‖_{C^m} ≤ (N+1)C_χρ^{−m} ≤ (2Vr/ρ + 2)C_χρ^{−m} ≤ C_2(1+r)ρ^{−m−1} = C_3(1+r)^{1+K}. Here C_2 := (2V+2)C_χ uses ρ ≤ 1, and C_3 := C_2c^{−m−1}.

The triangle inequality and the overlaps of the bumps play no role, because only linearity and F ≥ 0 are used.

By (A0) with u := R(F − ω(F)):

  r/2 ≤ γ_z^r(F) − rω(F) = u(g_r z) − u(z) ≤ ‖u‖_{C^1} d(z, g_r z) ≤ 2C_1C_3(1+r)^{1+K} d(z, g_r z).

Since r/(1+r) ≥ τ_0/(1+τ_0) for r ≥ τ_0, the claim holds with c_B := τ_0/(4C_1C_3(1+τ_0)). ∎

## 4. Step C: Hausdorff closeness

Put C_C := 8VC_1C_χ and ρ_1 := min(ρ_*, V).

**Lemma C.** Let x, y ∈ M, T ≥ 1 and η := d(x,y) + d(g_Tx, g_Ty). Let ρ ∈ (0, ρ_1] satisfy ρ^{m+1} > 4VC_1C_χη. Then for every t ∈ [0,T] there is σ ∈ [0,T] with d(g_t y, g_σ x) ≤ ρ.

*Proof.* Put q := g_t y and suppose d(q, g_{[0,T]}x) > ρ. Let ψ be the bump of (F1) at (q, ρ). Then ψ vanishes on the compact segment g_{[0,T]}x, so γ_x^T(ψ) = 0.

*Window bookkeeping.* Let W := [t − ρ/(2V), t + ρ/(2V)] ∩ [0,T]. If t ≤ T/2, then W ⊃ [t, t + min(ρ/(2V), T/2)]; if t ≥ T/2, then W ⊃ [t − min(ρ/(2V), T/2), t]. Since ρ ≤ V and T ≥ 1, we have ρ/(2V) ≤ 1/2 ≤ T/2, so |W| ≥ ρ/(2V). This covers t = 0 and t = T. For s ∈ W, d(g_s y, q) ≤ V|s − t| ≤ ρ/2, so ψ(g_s y) = 1. Hence γ_y^T(ψ) ≥ ρ/(2V).

Then (A1) gives ρ/(2V) ≤ 2C_1C_χρ^{−m}η, that is, ρ^{m+1} ≤ 4VC_1C_χη. This contradicts the hypothesis on ρ. The infimum over the segment is attained, which gives σ. ∎

## 5. Step D: shadowing in time

Fix B with B/(m+1) > max(K, 1), say B := (m+1)(K+2). For T ≥ 1 put η_T := T^{−B} and ρ_T := (C_Cη_T)^{1/(m+1)} = C_C^{1/(m+1)} T^{−B/(m+1)}.

Let T_1 be such that for all T ≥ T_1:
(a) ρ_T ≤ ρ_1;
(b) η_T ≤ ρ_T (equivalently η_T^m ≤ C_C);
(c) 4ρ_T < c_B(T+2)^{−K};
(d) T ≥ h_0.
All four hold for T large because B/(m+1) > K and η_T → 0.

**Lemma D1 (near-returns of the x-orbit are short).** Let T ≥ T_1, and let s_1, s_2 ∈ [0, T+1] with d(g_{s_1}x, g_{s_2}x) ≤ 4ρ_T. Then |s_1 − s_2| ≤ 4ρ_T/c_0.

*Proof.* Without loss of generality s_1 ≤ s_2. Put r := s_2 − s_1 ≤ T+1 and z := g_{s_1}x, so g_r z = g_{s_2}x. If r ≥ τ_0, Lemma B gives d(z, g_r z) ≥ c_B(2+T)^{−K} > 4ρ_T by (c), a contradiction. So r < τ_0, and (0.2) gives c_0 r ≤ 4ρ_T. ∎

**Lemma D.** Let ε > 0. There is T_0(ε) ≥ T_1 such that for all T ≥ T_0(ε) and all x, y with d(x,y) + d(g_Tx, g_Ty) ≤ η_T, we have d(g_t x, g_t y) < ε for all t ∈ [0,T].

*Proof.* Let k_* := ⌈T/h_0⌉ and h := T/k_*. Then h ∈ [h_0/2, h_0], using (d), and k_* ≤ 2T/h_0.

Since η := d(x,y) + d(g_Tx, g_Ty) ≤ η_T and ρ_T^{m+1} = 8VC_1C_χη_T > 4VC_1C_χη, Lemma C applies with ρ = ρ_T by (a). Choose σ_0 := 0; this is allowed because d(y,x) ≤ η_T ≤ ρ_T by (b). For 1 ≤ k ≤ k_*, Lemma C gives σ_k ∈ [0,T] with d(g_{kh}y, g_{σ_k}x) ≤ ρ_T.

By (F3), d(g_{(k+1)h}y, g_{σ_k+h}x) ≤ 2ρ_T, hence d(g_{σ_k+h}x, g_{σ_{k+1}}x) ≤ 3ρ_T. Both times lie in [0, T+1], because σ_k + h ≤ T + h_0 ≤ T + 1. This is the range checked in Lemma D1, which gives |σ_{k+1} − σ_k − h| ≤ 4ρ_T/c_0.

By induction |σ_k − kh| ≤ 4kρ_T/c_0 ≤ 8Tρ_T/(c_0h_0). For t ∈ [kh, (k+1)h] with k < k_*:

  d(g_tx, g_ty) ≤ 2 d(g_{kh}x, g_{kh}y) ≤ 2(V|σ_k − kh| + ρ_T) ≤ ρ_T(2 + 16VT/(c_0h_0)).

The right side is O(T^{1 − B/(m+1)}) → 0, so it is < ε for T ≥ T_0(ε). ∎

## 6. Step E: counting, and the conclusion

**Partition.** Fix η ≤ ρ_*. Take a maximal (η/4)-separated set {x_i}. The balls B(x_i, η/8) are disjoint, so by (F2) the number of points is at most N(η) := C_M η^{−n}. The balls B(x_i, η/4) cover M, and the sets A_i := B(x_i, η/4) \ ∪_{j<i} B(x_j, η/4) form a Borel partition into sets of diameter ≤ η/2.

**Counting.** Let ε > 0 and T ≥ T_0(ε) with η_T ≤ ρ_*. Let E be a set such that max_{t∈[0,T]} d(g_tx, g_ty) ≥ ε for x ≠ y in E. Consider the map x ↦ (cell of x, cell of g_Tx), with cells taken from the partition at η = η_T.

This map is injective on E. If x ≠ y had the same image, then d(x,y) + d(g_Tx, g_Ty) ≤ η_T, and Lemma D would give d(g_tx, g_ty) < ε on [0,T], which is impossible. Hence |E| ≤ N(η_T)² = C_M² T^{2nB}.

A set that is (N, ε)-separated for g_1 in the sense of (F4) is separated in this sense with T = N − 1, because integer times are a subset of [0, N−1]. So s_N(ε) ≤ C_M²(N−1)^{2nB} for large N, and (1/N) log s_N(ε) → 0 for each ε. Hence h_top(g_1) = 0, and by (F4) h_top(g_t) = 0 for every t. ∎ **Theorem V is proved.**

**Constants (no circularity).**
1. Geometric constants: ρ_*, C_χ, C_ω, c_ω, L, h_0, v_0, V, τ_0, c_0, which depend on (M, d, X).
2. m and C_1, which come from GH alone (Lemma A).
3. K = (m+1)/(n−1) and c_B (Lemma B; ρ there is chosen in terms of r alone, and Lemma B holds for all r ≥ τ_0).
4. C_C and then B.
5. T_1, which depends on the above only.
6. T_0(ε).

ρ_T is defined from η_T, which is defined from T. Lemma B is then invoked with r ≤ T+1, and its conclusion c_B(2+T)^{−K} is compared with ρ_T. This comparison is condition (c), a condition on T only. It is satisfiable because B/(m+1) > K, and K does not depend on B. So nothing is circular.

## 7. Hypotheses actually used, and what the proof gives

The proof uses only the following:
1. n ≥ 2.
2. X has no zeros (v_0 > 0).
3. A smooth positive probability density ω (used for the ball-mass bound (F2)) such that every smooth f satisfies f − ω(f) = Xu for some smooth u with ‖u‖_{C^1} ≤ C_1‖f‖_{C^m}.

Invariance of ω is used only to derive item 3 from GH (Proposition 7.1). Item 2 also follows from item 3: if X(p) = 0, then f(p) = ω(f) for every f, which is absurd.

**Conclusion.** For such "tamely cohomology-free" flows, the maximal number of (T, ε)-separated orbit segments is at most C T^{2nB}, which is polynomial in T, with B = (m+1)(K+2) and K = (m+1)/(n−1).

## 8. Can Step B be dropped? (only a remark; not established)

Without Step B, Step C still gives that each of the two segments lies in the ρ-neighbourhood of the other: apply Step C with x and y swapped. What fails is Step D. The point g_{kh}y may be close to g_{σ}x for a σ far from kh, if the x-segment returns close to itself.

A "re-ordering count" would record which passage of the x-segment the y-orbit is following at each of the ~T/h times. Without any bound on near-returns, the number of such itineraries is not obviously subexponential: a priori there are (number of passages)^{T/h} of them.

So I do not see how to drop Step B cheaply. Under GH, Step B costs only one application of (A0), so there is no reason to drop it. Whether Steps C–E alone (with a smarter count) suffice is left open.
