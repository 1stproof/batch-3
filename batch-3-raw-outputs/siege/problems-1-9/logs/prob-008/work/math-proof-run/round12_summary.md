## Problem and conventions
X smooth vector field on compact connected M, globally hypoelliptic (GH): every distribution u with L_X u smooth is smooth. Show the flow g_t has zero topological entropy. Goal = ledger entry 1 ([GOAL], OPEN). No complete proof exists. The claim is PROVED for dim M <= 3 (entry 61), for all hyperbolic measures in every dimension (entry 60), for volume-preserving GH flows with b_1(M) >= dim M - 2 (entry 85), and excluded for uniformly partially hyperbolic flows with small |m(d)| (entry 86). NEW (round 11, entry 113): every positive-entropy measure has lambda = mu(d) = 0 (modulo a cited normal-form theorem), so the goal is now equivalent to (PE0): no g_1-ergodic mu with h_mu(g_1) > 0 and mu(J_1) = 0.

Conventions: nu a smooth positive density, d = div_nu X, J_t(x) = int_0^t d(g_s x) ds = log nu-Jacobian of g_t; P = X + d acting on functions (L_X(phi nu) = (P phi) nu); Gamma_t phi = e^{J_t} phi o g_t (so S(Gamma_t phi) is the weighted transport of a density S); N_S(t) = sup_{||phi||_{C^1} <= 1} |S(Gamma_t phi)|; I = space of X-invariant distribution densities; (V) = "X preserves a smooth positive density" (entry 19); H = smooth invariant volume + unique ergodicity + every mean-zero smooth f is Xu with u smooth (= cohomology-free, CF, which under a smooth volume is equivalent to GH). For an ergodic mu, lambda = mu(d) = sum of all Lyapunov exponents; chi^+_min smallest positive exponent. (K0) ker X on D' = constants; (K1) no u in D' with Xu = 1; (F1)/(F2) their transposed forms for P. "Order-k Jordan chain at c": densities A, B of order <= k with B != 0, B o (P - c) = 0, A o (P - c) = B. "Tilted-decaying S (at c, rate eps)": N_S(t) <= C e^{ct - eps|t|} for all real t.

Exact grids need local product structure, destroyed by the centre (zero-exponent) directions; but on a Pesin block the su-quadrilateral defect is a centre displacement delta that grows only subexponentially.
