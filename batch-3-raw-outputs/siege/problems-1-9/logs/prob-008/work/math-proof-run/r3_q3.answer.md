# r3_q3 answer: towards (V) — GH implies a smooth invariant density

## Plan / status (written first, updated at the end)

Target: (V) Under GH there is a smooth positive density ω with L_Xω = 0.

Approach in this file: prove rigorous reductions of (V) to statements about the
log-Jacobian cocycle J_t, plus new unconditional consequences of GH (nonwandering,
no Lyapunov functions). Final status is given in Section 9.

## 1. Conventions

M compact connected, n = dim M. GH = the hypothesis of the problem. ν a fixed smooth
positive density, d = div_ν X, J_t(x) = ∫_0^t d(g_s x) ds, so that
(g_t)^*ν = e^{J_t} ν, i.e. ∫ ψ(g_t x) e^{J_t(x)} dν(x) = ∫ ψ dν for ψ ∈ L^1(ν). (1.1)
Cocycle: J_{t+s}(x) = J_s(x) + J_t(g_s x). Γ_tφ := e^{J_t} φ∘g_t, P := X + d, and
d/dt Γ_tφ = Γ_t Pφ. By (1.1), ∫ b·Γ_tφ dν = ∫ (b∘g_{-t}) φ dν for b ∈ L^1(ν). (1.2)
Distributions u ∈ D'(M) are paired with smooth densities φν; for smooth u,
∫ (Xu) φ dν = −∫ u (Pφ) dν, so for u ∈ D' we define ⟨Xu, φν⟩ := −⟨u, (Pφ)ν⟩.
If X ≡ 0 GH fails (any u ∈ D' has Xu = 0), so X ≢ 0. Note also that −X is GH
whenever X is, and that the ν-divergence of −X is −d, with J^{(−X)}_t(x) = J_{−t}(x).

## 2. Basic lemmas (proved here; they re-prove facts 1 and parts of 8 of the query)

**Lemma 2.1 (invariant L^1 functions have Xu = 0).** If b ∈ L^1(ν) and, for every
s ∈ ℝ, b∘g_s = b ν-a.e., then Xb = 0 in D'.
More generally, if b ∈ L^1(ν) and for every s, b∘g_s − b = J_s ν-a.e., then Xb = d in D'.

Proof. By (1.2), ∫ b Γ_tφ dν = ∫ (b∘g_{−t})φ dν = ∫ bφ dν + ∫ J_{−t} φ dν.
Γ_tφ = φ + tPφ + O(t^2) uniformly on M (smooth dependence on t), so the left side is
differentiable at t = 0 with derivative ∫ b Pφ dν. Since J_{−t} = −t d + O(t^2)
uniformly, the right side has derivative −∫ dφ dν. Hence −⟨b,(Pφ)ν⟩ = ∫ dφ dν,
i.e. Xb = d. The first statement is the case where J is replaced by 0 (same proof). ∎

**Lemma 2.2 (kernel).** Under GH, if u ∈ D' and Xu = 0 then u is constant. If b is a
bounded Borel function with b∘g_s = b a.e. for every s, then b is a.e. constant.
In particular, a Borel set A with ν(A Δ g_s A) = 0 for all s is ν-null or ν-conull.

Proof. By GH u is smooth, and Xu = 0 classically, so u is invariant under the flow
pointwise. If u is not constant, pick c with min u < c < max u. The function
v = 1_{u ≥ c} is bounded, Borel, and exactly flow-invariant, so Xv = 0 by Lemma 2.1,
so by GH v agrees a.e. with a smooth function v'. Since v' ∈ {0,1} a.e. and
v'^{-1}(ℝ∖{0,1}) is open and null, hence empty, v' takes values in {0,1}; M connected
forces v' constant. But v' = 1 a.e. on the nonempty open set {u > c} and v' = 0 a.e.
on the nonempty open set {u < c} (nonempty open sets have positive ν-measure),
contradiction. The second and third
statements follow from Lemma 2.1 and the first. ∎

**Lemma 2.3 (coboundary criterion).** Under GH, (V) holds iff there is b ∈ L^1(ν)
with b∘g_s − b = J_s ν-a.e. for every s. In that case b is smooth (after modification
on a null set) and ω = e^{−b}ν is invariant. Conversely, (V) gives a smooth a with
J_t = a∘g_t − a everywhere, so |J_t| ≤ 2‖a‖_∞ for all t, x.

Proof. If such b exists, Xb = d in D' (Lemma 2.1), so b is smooth by GH, and
h = e^{−b} satisfies Xh + dh = 0, i.e. L_X(hν) = (Ph)ν = 0. Conversely if ω = hν,
h > 0 smooth, is invariant, then a := −log h satisfies Xa = −Xh/h = d, hence
J_t(x) = ∫_0^t (Xa)(g_s x) ds = a(g_t x) − a(x). ∎

## 3. Theorem A: (V) iff forward volume expansion is uniformly bounded

**Theorem A.** Assume GH. The following are equivalent:
(i) (V);
(ii) K := sup_{t ≥ 0, x ∈ M} J_t(x) < ∞ (one-sided bound, forward time only);
(iii) inf_{t ≥ 0, x ∈ M} J_t(x) > −∞.

Proof. (i)⇒(ii),(iii): Lemma 2.3.

(ii)⇒(i). Step 1 (a bounded invariant density). Put E_R := (1/R)∫_0^R e^{J_t} dt, so
0 < E_R ≤ e^K and ∫E_R dν = ν(M) by (1.1). By the cocycle identity
Γ_s e^{J_t} = e^{J_s} e^{J_t∘g_s} = e^{J_{t+s}}, hence
Γ_s E_R − E_R = (1/R)(∫_R^{R+s} − ∫_0^s) e^{J_t} dt, of sup-norm ≤ 2|s|e^{K'}/R
(K' := K + ‖d‖_∞|s|) → 0. Take a weak-* limit point h ∈ L^∞(ν) of E_R (R → ∞).
Γ_s is weak-* continuous on L^∞(ν) (by (1.2) its predual action is ψ ↦ ψ∘g_{−s} on
L^1(ν)), so Γ_s h = h a.e. for each s, i.e.
  h(g_s x) e^{J_s(x)} = h(x) for ν-a.e. x, every s.   (3.1)
Also 0 ≤ h ≤ e^K and ∫h dν = ν(M) > 0. By (3.1) the set A = {h > 0} satisfies
1_A∘g_s = 1_A a.e., so by Lemma 2.2 A is conull. By (3.1), hν is g_s-invariant for all s.

Step 2 (the transfer function is bounded). b := −log h is finite a.e., b ≥ −K, and by
(3.1) b∘g_s − b = J_s a.e. for each s. Let F(x) := sup_{t ≥ 0} J_t(x) ∈ [0, K]
(F ≥ J_0 = 0). From the cocycle identity, F(g_s x) + J_s(x) = sup_{t ≥ s} J_t(x)
for s ≥ 0. Put b̃ := b + F. Then for each s ≥ 0, a.e.,
  b̃∘g_s = b + J_s + F∘g_s = b + sup_{t≥s} J_t ≤ b + F = b̃.
Let β := arctan b̃ (bounded, Borel). Then β − β∘g_s ≥ 0 a.e. and, since hν is
invariant, ∫(β − β∘g_s) h dν = 0. As h > 0 a.e., β∘g_s = β a.e. for every s ≥ 0, hence
for every s ∈ ℝ. By Lemma 2.2 β is a.e. constant, so b̃ = c a.e. and
b = c − F ∈ [c − K, c] is bounded. By Lemma 2.3, (V) holds.

(iii)⇒(i). Apply (ii)⇒(i) to −X, which is GH, has ν-divergence −d, and
J^{(−X)}_t(x) = J_{−t}(x) = −J_t(g_{−t}x); thus
sup_{t≥0,x} J^{(−X)}_t(x) = −inf_{t≥0,y} J_t(y) < ∞. A smooth density invariant under
−X is invariant under X. ∎

Remark. So (V) is equivalent to the uniform boundedness, in t ≥ 0, of the
ν-Jacobians det_ν Dg_t (equivalently ‖Γ_t‖_{C^0→C^0} = sup e^{J_t}). Fact 5 of the query
has the two-sided version sup_{t∈ℝ}|J_t|; Theorem A needs only one side, one direction.

## 4. Theorem B: (V) iff an explicit candidate transfer function is integrable

Let L(x) := limsup_{t→+∞} J_t(x) ∈ [−∞, +∞] and ℓ(x) := liminf_{t→+∞} J_t(x).

**Theorem B.** Under GH, (V) ⇔ L ∈ L^1(ν) ⇔ ℓ ∈ L^1(ν). When they hold, L and ℓ
agree a.e. with smooth functions, and e^{L}ν is the invariant density.

Proof. (V) ⇒ by Lemma 2.3 J_t = a∘g_t − a with a smooth, so |L|, |ℓ| ≤ 2‖a‖_∞.
Conversely, by the cocycle identity, for every s and x,
J_t(x) = J_s(x) + J_{t−s}(g_s x), so taking limsup (resp. liminf) as t → ∞,
L(x) = J_s(x) + L(g_s x), ℓ(x) = J_s(x) + ℓ(g_s x), whenever one side is finite
(J_s(x) is a finite number). If L ∈ L^1(ν), L is finite a.e., and b := −L satisfies
b∘g_s − b = L − L∘g_s = J_s a.e., for every s. Lemma 2.3 gives (V). Same for ℓ. ∎

Remark. Theorem B needs no conservativity or ergodic theorem: the candidate transfer
function is explicit, and GH upgrades mere integrability of it to smoothness. So the
whole gap in (V) is: show that the limsup of the log-ν-Jacobian along forward orbits is
finite a.e. and ν-integrable (or, by Theorem A, uniformly bounded above).

## 5. New unconditional consequences of GH: nonwandering, no Lyapunov functions

**Proposition 5.1.** Under GH and n ≥ 2, every point of M is nonwandering for the flow:
for every x, every neighbourhood U of x and every T_0 there is t ≥ T_0 with
g_t U ∩ U ≠ ∅.

Proof. Zeros and periodic points are nonwandering, so let x be neither, and suppose
U ∋ x open and T_0 > 0 satisfy g_t U ∩ U = ∅ for t ≥ T_0 (then also for t ≤ −T_0,
since g_{−t}U ∩ U = g_{−t}(U ∩ g_t U)).
Flow box: since X(x) ≠ 0 there are a small embedded transverse (n−1)-disc D_0 ∋ x and
τ_0 > 0 such that Φ(ξ, s) = g_s ξ is a diffeomorphism of D_0 × (−τ_0, τ_0) onto an open
set. As x is not periodic and not fixed, δ := min_{t ∈ [τ_0/2, T_0]} d(g_t x, x) > 0.
By uniform continuity of (t, y) ↦ g_t y on [−1, T_0+1] × M, choose a smaller box
B = Φ(D × (−τ, τ)), x ∈ D ⊂ D_0, τ ≤ τ_0/4, with B ⊂ U, diam B < δ/3 and
d(g_t y, g_t x) < δ/3 for y ∈ B, t ∈ [0, T_0]. Then for y ∈ B: g_t y ∉ B for
t ∈ [τ_0/2, T_0] (it is within δ/3 of g_t x, which is ≥ δ from x); for t ∈ [2τ, τ_0/2]
and y = Φ(ξ,s), g_t y = Φ(ξ, s+t) with s + t ∈ (τ, τ_0), so g_t y ∉ B by injectivity of
Φ; for t ≥ T_0, g_t y ∉ U ⊃ B. Hence every orbit meets B in a single time interval of
length ≤ 2τ, in points Φ(ξ, s) with one common ξ =: ξ(y).
Choose θ ∈ C^∞(D) nonconstant and define Ψ(y) := θ(ξ(y)) if the orbit of y meets B,
Ψ(y) := 0 otherwise. Ψ is bounded, exactly flow-invariant, and Borel: on the open set
Sat(B) = ∪_t g_t B it is smooth (near y_0 with g_{t_0}y_0 ∈ B, ξ(y) = pr_D Φ^{−1}(g_{t_0}y)),
and it vanishes off Sat(B). By Lemma 2.2 Ψ is a.e. constant; but on the open set B it
equals θ∘pr_D Φ^{−1}, a smooth nonconstant function, contradiction. ∎

**Corollary 5.2 (no Lyapunov functions).** Under GH (n ≥ 2): if u ∈ D' and Xu = f with
f smooth and f ≥ 0, then f ≡ 0.

Proof. By GH u is smooth. Suppose f(y_0) > 0. Pick r > 0 with f > f(y_0)/2 on
B(y_0, 2r) and σ ∈ (0,1] with g_s B(y_0, r) ⊂ B(y_0, 2r) for s ∈ [0, σ]; put
c := σ f(y_0)/2. Pick a neighbourhood U ⊂ B(y_0, r) of y_0 with Lip(u)·diam U < c.
By Proposition 5.1 there are y ∈ U and t ≥ 1 with g_t y ∈ U. Then
u(g_t y) − u(y) = ∫_0^t f(g_s y) ds ≥ ∫_0^σ f(g_s y) ds ≥ c, while
|u(g_t y) − u(y)| ≤ Lip(u) diam U < c. Contradiction. ∎

Remark 5.3. By Conley's fundamental theorem (cited from memory: a flow on a compact
metric space whose chain recurrent set is not the whole connected space has an attractor
A with ∅ ≠ A ≠ M, and points of its basin outside A are wandering), Proposition 5.1
implies that the flow of a GH field is chain transitive. Also Corollary 5.2 shows:
if (V) fails then no smooth u satisfies Xu = d − c − f with c constant and f ≥ 0,
f ≢ 0, f ∈ X(D') — but this is weaker than what is needed, because f must lie in X(D').

## 6. Asymptotics of J (proved, partly using fact 7 of the query)

**6.1 (weak-* ergodic theorem).** Under GH, for every bounded Borel ρ, every weak-*
limit point in L^∞(ν) of A_Rρ := (1/R)∫_0^R ρ∘g_r dr (R → ∞) is an a.e. constant.
Proof: A_Rρ∘g_s − A_Rρ has sup-norm ≤ 2|s|‖ρ‖_∞/R; composition with g_s is weak-*
continuous on L^∞(ν) (predual map ψ ↦ e^{J_{−s}}ψ∘g_{−s}); so a limit w satisfies
w∘g_s = w a.e. for all s, and Lemma 2.2 applies. ∎
Consequently, if R_j → ∞ and μ_{R_j} := (1/R_j)∫_0^{R_j}(g_r)_*ν̄ dr → μ weak-*
(ν̄ = ν/ν(M)), then A_{R_j}ρ → μ(ρ) weak-* in L^∞(ν) for every continuous ρ
(the constant is identified by integrating against ν̄).

**6.2 (sign of the divergence on SRB-type limits).** μ_R(d) = (1/R)∫J_R dν̄ ≤ 0, because
−∫J_R dν̄ is the relative entropy of (g_R)_*ν̄ with respect to ν̄ (the density of
(g_R)_*ν̄ at g_R x is e^{−J_R(x)}). Hence forward limits μ have μ(d) ≤ 0 and (applying
this to −X) backward limits have μ(d) ≥ 0. In particular max_μ μ(d) ≥ 0 ≥ min_μ μ(d)
over invariant probability measures.

**6.3 (ν-typical orbits).** By (1.1), ∫e^{J_t}dν = ν(M), so ν{J_k ≥ εk} ≤ e^{−εk}ν(M);
Borel–Cantelli and |J_t − J_k| ≤ ‖d‖_∞ for t ∈ [k, k+1] give, for ν-a.e. x,
limsup_{t→+∞} J_t(x)/t ≤ 0 and (for −X) limsup_{t→+∞} J_{−t}(x)/t ≤ 0.
Using Theorem J (fact 7 of the query; I did not re-prove it): no x satisfies
J_t(x) ≤ C − ε|t| for all t ∈ ℝ (apply Theorem J to S = δ_x, for which
|S(Γ_tφ)| = e^{J_t(x)}|φ(g_t x)| ≤ e^{C−ε|t|}‖φ‖_{C^0}; it would give δ_x = 0).
Hence for every x, limsup_{t→+∞} J_t(x)/t ≥ 0 or limsup_{t→+∞} J_{−t}(x)/t ≥ 0, so
ν-a.e. one of the two limsups in the previous display equals 0.

## 7. Splitting the gap: existence of a finite acim, and log-integrability

U_tf := e^{J_t/2} f∘g_t is a strongly continuous unitary group on L^2(ν) (by (1.1)).

**Proposition 7.1.** (a) A finite invariant measure hν ≪ ν exists iff U has a nonzero
invariant vector iff c_∞ := lim_{T→∞} (1/T)∫_0^T ∫e^{J_t/2}dν dt > 0 (the limit exists).
(b) Under GH such h is unique up to a factor and h > 0 a.e.; and (V) holds iff, in
addition, log h ∈ L^1(ν).

Proof. (a) If U_tv = v for all t then e^{J_t}|v∘g_t|^2 = |v|^2 a.e., i.e. |v|^2ν is
invariant; conversely √h is U-invariant if
hν is invariant. By von Neumann's mean ergodic theorem (1/T)∫_0^T U_t1 dt → Q1, Q the
projection on the invariant vectors, and ⟨Q1, 1⟩ = c_∞. If an invariant √h ≠ 0 exists,
⟨1, √h⟩ > 0, so Q1 ≠ 0 and c_∞ = ‖Q1‖^2 > 0; conversely c_∞ > 0 gives Q1 ≠ 0.
(b) {h > 0} is invariant mod ν, hence conull (Lemma 2.2). If h, h' are two such
densities, arctan(log h − log h') is a bounded invariant function, so constant. If
log h ∈ L^1, b := −log h satisfies b∘g_s − b = J_s a.e. and Lemma 2.3 gives (V);
conversely (V) gives h smooth positive. ∎

So (V) = (G1) + (G2), with
(G1) c_∞ > 0, i.e. the Hellinger affinities ∫ e^{J_t/2} dν do not tend to 0 in Cesàro mean;
(G2) the density of the (then unique) finite acim is log-integrable.
I could prove neither from GH. Theorem A shows that a uniform one-sided bound on J_t
gives both at once (h is then bounded above and below).

## 8. Deduction of the problem from (V) and Theorem V

Assume (V) and Theorem V (the latter is from the parallel attempt; not re-proved here).
If n ≥ 2, Theorem V applies directly and h_top(g_1) = 0; the entropy of the flow is by
definition h_top(g_1) (and h_top(g_t) = |t| h_top(g_1)). If n = 1, M = S^1 and g_1 is a
circle homeomorphism, which has zero topological entropy (standard: the number of
(n, ε)-separated orbit segments of a circle homeomorphism grows at most linearly in n).
So the problem follows from (V) + Theorem V; the case n = 1 needs neither.

## 9. Final status

Proved here (all under GH, with complete proofs above; only fact 7 = Theorem J is
used without proof, and only in 6.3):
* Lemma 2.2 (re-proof of facts 1 and the ergodicity part of fact 8) and the coboundary
  criterion Lemma 2.3: (V) ⇔ J is a ν-a.e. coboundary with an L^1 transfer function.
* Theorem A: (V) ⇔ sup_{t≥0,x} J_t(x) < ∞ ⇔ inf_{t≥0,x} J_t(x) > −∞
  (one-sided, one time direction).
* Theorem B: (V) ⇔ limsup_{t→∞} J_t ∈ L^1(ν) ⇔ liminf_{t→∞} J_t ∈ L^1(ν).
* Proposition 5.1 / Corollary 5.2: every point is nonwandering; no distribution u has
  Xu = f with f smooth, f ≥ 0, f ≢ 0 (hence, via Conley, the flow is chain transitive).
* 6.1–6.3: weak-* ergodic theorem; sign of μ(d) on forward/backward SRB-type limits;
  ν-typical growth of J is subexponential in at least one time direction.
* Proposition 7.1: (V) ⇔ (G1) + (G2).

NOT proved: (V) itself, hence not the problem in general. The precise remaining gap
(any one of these suffices, by the results above):
(Q1) sup_{t ≥ 0, x ∈ M} J_t(x) < ∞ (forward ν-Jacobians uniformly bounded);
(Q2) limsup_{t→∞} J_t ∈ L^1(ν);
(Q3) (G1) and (G2) of Section 7.
I found no route from GH to any of these. In particular I could not exclude, using only
facts 1–9 and the results above, the scenario "ν is of type III or II_∞ for the flow"
(no finite acim), nor "finite acim with non-log-integrable density".
