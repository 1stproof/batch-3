**Plan.** I prove: *assuming Results B and D (taken as given), for every monoid P and every presheaf of abelian groups F on B_P^op, the derived unit F -> R pi_* pi^{-1} F is a quasi-isomorphism.* The sections are:
- §0 conventions;

- §2 the injectives I_{tau,A};

## §0 Conventions

- **Monoids.** "Monoid" means integral, saturated, sharp, commutative monoid. **Mon** is the category of these. For a map f : P -> Q, write Phi_Q := f^{-1}(0).
- **Faces.** For x in P, face(x) := {y in P : y <= nx for some n >= 1} is the smallest face containing x. A face is *principal* if it has this form.
- **Universes.** Fix universes U ∈ V with P ∈ U.
  - A_P is the category of maps P -> Q in Mon with Q ∈ U. It is V-small.
  - Presheaves and sheaves take values in V-small abelian groups. Every U-small group is one of these.
  - Then (A_P^op, birhizomic topology) is a V-small site. The usual theory applies inside V: sheafification by the plus construction, enough injectives in Ab(A_P^op), and derived functors.
  - B_P is essentially U-small, since its objects are indexed by the elements of P.
  - Nothing in the answer depends on the choice of U and V.
- **Filtered colimits in Mon.** These are computed on underlying sets. A filtered colimit of integral, saturated, sharp monoids is again integral, saturated and sharp: any equation x + y = 0, nz = w, or x + z = y + z already holds at some stage. Connected colimits in an under-category P/Mon are computed in Mon.
- **f.p.** A map f : P -> Q is f.p. if Hom_{P/Mon}(Q, -) commutes with filtered colimits in P/Mon.
- **Pushouts.** Pushouts exist in Mon: form the pushout of commutative monoids, then take the integral image, saturate it, and divide by units. Fibre products in A_P^op are pushouts under P.

**Lemma 0.1.**
- (a) If P -> Q and Q -> Q' are f.p., so is P -> Q'.
- (b) If Q -> Q' is f.p. and Q -> R is arbitrary, then R -> Q' ⊔_Q R is f.p.
- (c) Each P -> P[-x]^♯ is f.p.

*Proof.*

(b) Let X be an object under R. Then Hom_R(Q' ⊔_Q R, X) = Hom_Q(Q', X), and a filtered colimit under R is also a filtered colimit under Q.

(a) Let X = colim X_k be a filtered colimit under P. A map Q' -> X under P is a pair (a, c): a map a : Q -> X under P, and a map c : Q' -> X under Q, where X is viewed under Q via a.
- Since Q is f.p., a factors through some a_k : Q -> X_k, and two such factorizations agree further along.
- The X_{k'} for k' >= k, viewed under Q via a_k, form a filtered system with colimit (X, a). Since Q' is f.p. under Q, c factors through some X_{k'}, uniquely up to going further along.
- Hence colim_k Hom_P(Q', X_k) -> Hom_P(Q', X) is bijective.

(c) Hom_P(P[-x]^♯, X) is a point if x ↦ 0 in X, and empty otherwise. For X = colim X_k, x ↦ 0 in X iff x ↦ 0 in some X_k. ∎

Hence every finite iterated pushout over Q of f.p. maps Q -> Q_i, with Q f.p. under P, is f.p. under P.

## §1 The categories, the Kan extension, pi^{-1} and pi_*

**1.1 Kernel faces.** If f : P -> Q is in A_P, then Phi_Q is a face of P.
- It is a submonoid.
- If a + b ∈ Phi_Q, then f(a) + f(b) = 0, so f(a) = f(b) = 0 because Q is sharp.

So x ∈ Phi_Q iff face(x) ⊂ Phi_Q. If Q -> Q' is a map under P, then Phi_Q ⊂ Phi_{Q'}.

**1.2 The objects b_x := (P -> P[-x]^♯).**
- *Construction.* Let P[-x] = {p - nx} ⊂ P^gp. It is integral, and it is saturated: if m g + k x ∈ P, then m(g + kx) ∈ P, so g + kx ∈ P. Set P[-x]^♯ = P[-x]/P[-x]^*. Dividing a saturated integral monoid by its units keeps it saturated and integral, and makes it sharp.
- *Universal property.* For f : P -> Q in A_P, a map P[-x]^♯ -> Q under P exists iff f(x) = 0, and it is then unique.
  - If f(x) = 0, then f extends uniquely to P[-x], since P[-x] is generated by P and -x. The extension kills the units of P[-x], because Q is sharp.
  - Conversely, x becomes a unit in P[-x], so it maps to 0 in P[-x]^♯, and hence f(x) = 0.
  - Uniqueness holds because P -> P[-x]^♯ is surjective onto generators: every element is the class of p - nx.
- *Kernel.* Phi_{b_x} = face(x). Indeed, y ↦ 0 iff y is a unit of P[-x], iff -y = p - nx for some p, n, iff y + p = nx, iff y ∈ face(x).
- *Consequences.*
  - Hom_{A_P}(b_x, b_y) is a point if face(x) ⊂ face(y), and empty otherwise.
  - B_P is therefore a preorder, equivalent to the poset Pr(P) of principal faces under inclusion.
  - Pr(P) is directed, since face(x), face(y) ⊂ face(x + y). Its least element is face(0) = {0}, which corresponds to b_0 = P.
  - For tau ∈ Pr(P), let b_tau be any object of B_P with kernel face tau. For a functor F on B_P, write F(tau) := F(b_tau). Any two choices of b_tau are uniquely isomorphic.
  - Every b_x is f.p., by Lemma 0.1(c).

**1.3 Presheaves.** A presheaf on B_P^op (resp. A_P^op) is a functor B_P -> Ab (resp. A_P -> Ab). Write ι : B_P -> A_P for the inclusion.
- The trivial topology makes Sh(B_P^op) = PSh(B_P^op). In it, exactness is objectwise.
- Restriction is ι^* G = G∘ι.

**1.4 The left Kan extension.** The left adjoint of ι^* on presheaves (Stacks' u_p, SGA4 I.5) is
 (Lan F)(Q) = colim_{(b, b->Q) ∈ ι/Q} F(b),
where ι/Q is the comma category of pairs (b ∈ B_P, b -> Q in A_P).
- By 1.2, a pair (b_x, ·) exists iff x ∈ Phi_Q, and the map is then unique. Also b_x -> b_y over Q exists iff face(x) ⊂ face(y).
- Hence ι/Q is a preorder, equivalent to the poset Pr(P)_{⊂Phi_Q} = {face(x) : x ∈ Phi_Q}.
- This poset is nonempty, since it contains {0}, and directed, since x, y ∈ Phi_Q implies x + y ∈ Phi_Q.

So (Lan F)(Q) is a *filtered* colimit, for every Q. Filtered colimits in Ab are exact, and kernels and cokernels of presheaves are computed objectwise. **Therefore Lan is exact.**

**Lemma 1.5 (f.p. objects).** Let Q be f.p. under P. By Result B, Phi_Q = face(x_Q). Put b(Q) := b_{x_Q}.
- (b(Q), b(Q) -> Q) is terminal in ι/Q. So the canonical map F(b(Q)) = F(Phi_Q) -> (Lan F)(Q) is an isomorphism, natural in F.
- For a map Q -> Q' of f.p. objects, Phi_Q ⊂ Phi_{Q'}. Under these isomorphisms, Lan F(Q -> Q') becomes F(b(Q) -> b(Q')): both are the colimit map sending the summand of index b(Q) to the summand of index b(Q').
- For b ∈ B_P we have b(b) ≅ b. So the adjunction unit F(b) -> (Lan F)(b) is an isomorphism. (This is also the general fact that the unit is an isomorphism for fully faithful ι.)
- Consequently Lan commutes with arbitrary products *on f.p. objects*: (Lan ∏_j F_j)(Q) = ∏_j F_j(Phi_Q) = ∏_j (Lan F_j)(Q), naturally in Q f.p.

On non-f.p. objects this may fail, since filtered colimits do not commute with infinite products. It is never needed there.

**1.6 pi^{-1} and pi_*.**
- By definition pi^{-1} F = (Lan F)^#, where # denotes sheafification for the birhizomic topology J of §3.
- Lan and # are both exact, so **pi^{-1} is exact.**
- For a sheaf G: Hom_Sh((Lan F)^#, G) = Hom_PSh(Lan F, G) = Hom_{PSh(B)}(F, G∘ι). So **pi_* G = G∘ι = G|_B**, a left exact functor.
- The unit F -> pi_* pi^{-1} F is, at b ∈ B_P, the composite
  F(b) --(iso, 1.5)--> (Lan F)(b) --(sheafification map)--> (Lan F)^#(b).
  So it is an isomorphism as soon as the sheafification map is an isomorphism at f.p. objects. That is Corollary 5.3.

## §2 The injectives I_{tau,A}

Fix tau ∈ Pr(P) and an abelian group A.
- **Definition.** I_{tau,A}(b) = A if Phi_b ⊂ tau, and 0 otherwise. The map along b -> b' is id_A when both values are A, and 0 otherwise.
- **It is a functor.** Phi_b ⊂ Phi_{b'}, so the value A at b' forces the value A at b. The pattern 0 -> A never occurs, and composition is clearly respected.

**Lemma 2.1.** Hom_{PSh(B)}(F, I_{tau,A}) ≅ Hom_Ab(F(tau), A), via φ ↦ φ_{b_tau}. Hence I_{tau,A} is injective if A is.

*Proof.*
- *Uniqueness.* If Phi_b ⊂ tau, there is a unique map b -> b_tau. Naturality along it forces φ_b = φ_tau ∘ F(b -> b_tau).
- *Existence.* Given φ_tau, define φ_b by this formula when Phi_b ⊂ tau, and φ_b = 0 otherwise. Take a map b -> b'.
  - If both targets are A: φ_{b'} ∘ F(b -> b') = φ_tau ∘ F(b' -> b_tau) ∘ F(b -> b') = φ_b, by uniqueness of maps in B_P.
  - If the target at b' is 0: the square is trivially commutative.
- *Injectivity.* Hom(-, I_{tau,A}) = Hom(ev_{b_tau}(-), A). This is exact, because evaluation is exact and A is injective. ∎

**Lemma 2.2 (resolution).**
- Let E(-) denote an injective hull (or any injective embedding).
- The map F -> ∏_{tau ∈ Pr(P)} I_{tau, E(F(tau))}, whose tau-component corresponds via 2.1 to F(tau) ↪ E(F(tau)), is a monomorphism.
  - At b with Phi_b = sigma, its sigma-component is F(b) -> F(b_sigma) ≅ F(b) followed by F(b) ↪ E(F(b)).
  - The product is objectwise, and it is injective, as a product of injectives.
- Apply the same construction to the cokernel, and iterate. This gives an injective resolution
  0 -> F -> I^0 -> I^1 -> ...,  with each I^k = ∏_{tau ∈ Pr(P)} I_{tau, A_{k,tau}} for injective groups A_{k,tau}.
- The resolution is exact objectwise. The products may be infinite. ∎

## §3 Coverings and the cofinal system Cov

**3.1 Coverings of an object.** Let Q be an object of A_P. A *birhizomic cover of Q* is a family of maps {Q -> Q_i}_{i ∈ I} under P that is a birhizomic cover in the sense of the problem, with Q in the role of the base.
- Its *witness set* is I_0 = {i ∈ I : there are a valuative V and g : Q_i -> V such that Q -> Q_i is birhizomic at g}.
- By definition of "birhizomic at g", each Q -> Q_i with i ∈ I_0 is f.p.

**Lemma 3.2.** {Q -> Q_i}_{i ∈ I_0} is again a birhizomic cover of Q, and it refines {Q -> Q_i}_{i ∈ I}.

*Proof.*
- For a valuation v of Q, the cover property gives an i and a factorization Q -> Q_i -> V with Q -> Q_i birhizomic at Q_i -> V. That i lies in I_0 by definition, and the same factorization serves as the witness.
- Refinement holds because the new family is a subfamily (α = inclusion I_0 ⊂ I). ∎

**3.3 The topology; both readings.** Let J(Q) be the set of sieves on Q, in A_P^op, that contain the sieve generated by some birhizomic cover of Q.
- *Reading (a): the birhizomic covers form a pretopology.* They satisfy the isomorphism, base-change and composition axioms. The topology generated by a pretopology has exactly the sieves J(Q) as covering sieves, and the sheaves for the pretopology are the sheaves for J (SGA4 II.1.3–1.4; Stacks, Sites, section on sites and sieves, quoted from memory).
- *Reading (b): "the sieves generated by birhizomic covers form a Grothendieck topology."* Then this topology is J, again with covering sieves J(Q).
  - If one instead takes the *smallest* Grothendieck topology containing those sieves, it is again J. This uses the problem's assertion that J is already a topology.
  - **This assertion of the problem is used and not re-proved here.** The property actually used below is:

  (★) every covering sieve of every object Q contains the sieve generated by some birhizomic cover of Q.

So under both readings the site is (A_P^op, J), and (★) holds.

For uniformity, call a family {U_i -> U} a *covering family* if the sieve it generates lies in J. This is the class "Cov(C)" of the site in Stacks' sense (Stacks tag 00VH); it satisfies the site axioms since J is a topology and fibre products exist.

**3.4 The system Cov.** Let 𝔅 be the set of f.p. objects of A_P. Let **Cov** be the set of birhizomic covers {Q -> Q_i}_{i ∈ I} with Q ∈ 𝔅 and every Q -> Q_i f.p.

**Lemma 3.5.**
- (i) Every 𝒰 ∈ Cov is a covering family.
- (ii) For 𝒰 ∈ Cov, every member Q_i, and every iterated fibre product Q_{i_0...i_p} := Q_{i_0} ⊔_Q ... ⊔_Q Q_{i_p} (a pushout in Mon), lies in 𝔅.
- (iii) For Q ∈ 𝔅 and every covering sieve R of Q, there is 𝒰 ∈ Cov all of whose members lie in R. In particular, every covering family of Q is refined by a member of Cov.
- (iv) In 𝒰 ∈ Cov, every valuation of Q factors through some member.

*Proof.*
- (i) Immediate from the definition of J.
- (ii) Lemma 0.1(a)(b).
- (iii) By (★), R contains the sieve of a birhizomic cover 𝒰' of Q. By Lemma 3.2, its witness subfamily 𝒰 lies in Cov. Each member of 𝒰 is a member of 𝒰', so it lies in R. If R is generated by a covering family {V_j -> Q}, each member of 𝒰 factors through some V_j. Choosing such factorizations gives the refinement map.
- (iv) Each 𝒰 ∈ Cov is a birhizomic cover. ∎

So the coverings of f.p. objects with all members f.p. are cofinal among all coverings of f.p. objects, and their iterated fibre products are f.p.

## §4 Čech complexes on Cov

**Conventions.**
- For a presheaf G on A_P^op and 𝒰 = {Q -> Q_i}_{i ∈ I}, the Čech complex is that of Stacks, with *all* ordered tuples, repetitions allowed:
  Č^p(𝒰, G) = ∏_{t = (i_0..i_p) ∈ I^{p+1}} G(Q_t),  (ds)_{i_0..i_{p+1}} = Σ_j (-1)^j s_{i_0..î_j..i_{p+1}}|_{Q_{i_0..i_{p+1}}}.
- The *augmented* complex puts G(Q) in degree -1, with the restriction maps as augmentation.
- For a tuple t, write set(t) for its underlying set and Phi_t := ker(P -> Q_t).

**Lemma 4.1 (repeated indices).** Phi_t = Phi_{set(t)}, where for a finite set σ ⊂ I, Q_σ is the pushout over Q of the Q_i, i ∈ σ, as in Result D.

*Proof.* There are maps under P (indeed under Q) in both directions between Q_σ and Q_t:
- Q_σ -> Q_t sends the factor Q_i to the first slot of t equal to i.
- Q_t -> Q_σ sends the slot j to the coprojection of Q_{i_j}. Thus a repeated factor is mapped by the codiagonal.

By 1.1 the kernels are contained in each other. ∎

So for σ ⊂ σ' we have Phi_σ ⊂ Phi_{σ'}, and the sets N_tau = {σ : Phi_σ ⊂ tau} of Result D are simplicial complexes.

**Proposition 4.2.** Let Q ∈ 𝔅, 𝒰 ∈ Cov a covering of Q, tau ∈ Pr(P), A an abelian group, and G = Lan I_{tau,A}.
- (a) If Phi_Q ⊄ tau, the augmented Čech complex of G on 𝒰 is zero.
- (b) If Phi_Q ⊂ tau, it is isomorphic to the augmented ordered cochain complex of N_tau with coefficients A.

In both cases it is exact.

*Proof.* All the objects Q, Q_t lie in 𝔅 (Lemma 3.5(ii)). By Lemma 1.5, G(Q_t) ≅ I_{tau,A}(Phi_t). This is A if Phi_t ⊂ tau and 0 otherwise. Restriction maps between two nonzero terms are id_A.

(a) Each Q_t receives a map from Q under P, so Phi_Q ⊂ Phi_t ⊄ tau. Hence every term is 0.

(b) By Lemma 4.1, Č^p ≅ ∏_{t ∈ I^{p+1}, set(t) ∈ N_tau} A. With the differential above, this is exactly the ordered cochain complex C^p_ord(N_tau; A) = Hom(C^ord_p(N_tau), A). Here C^ord_p is free on the ordered (p+1)-tuples of vertices, repetitions allowed, spanning a simplex. The degree -1 term is G(Q) = A, and the augmentation is the diagonal A -> ∏_i A, i.e. the dual of the augmentation C^ord_0 -> Z.

*Exactness.* Result D applies:
- the members of 𝒰 are f.p. maps Q -> Q_i;
- every valuation of Q factors through one of them (Lemma 3.5(iv));
- tau ⊃ Phi_Q.

Result D's Q_σ and Phi_σ are ours. So the augmented ordered cochain complex of N_tau with coefficients A is exact.

*If "ordered" in Result D means tuples without repetition, or the oriented complex:* the ordered chain complex with repetitions and the oriented chain complex of a simplicial complex are naturally chain homotopy equivalent, compatibly with augmentations (Spanier, *Algebraic Topology*, Thm. 4.3.8, quoted from memory). So exactness of one augmented chain complex gives exactness of the other.
- An exact augmented chain complex of free abelian groups, bounded below, is split exact.
- Hence its Hom into A is exact.

So in every reading, (b) is exact. ∎

**Corollary 4.3.** Let 0 -> F -> I^0 -> I^1 -> ... be the resolution of Lemma 2.2. For Q ∈ 𝔅 and 𝒰 ∈ Cov over Q, the augmented Čech complex of each Lan I^k on 𝒰 is exact.

*Proof.* On 𝔅, Lan I^k ≅ ∏_tau Lan I_{tau,A_{k,tau}} naturally (Lemma 1.5), and only objects of 𝔅 occur in the complex. So the augmented Čech complex is the product of the complexes of Prop. 4.2, and a product of exact complexes of abelian groups is exact. ∎

## §5 Sheafification does not change values on f.p. objects

**5.0 Sieve facts.** These are standard (SGA4 II; Stacks, Sites), quoted from memory, and each is easily checked.
- Let R be the sieve on U generated by a family {U_i -> U} whose pairwise fibre products exist. Then Hom_PSh(R, G) is the equalizer of ∏_i G(U_i) ⇉ ∏_{(i,j)} G(U_i ×_U U_j). (A map R -> G is determined by its values on the generators. A compatible family defines one: given V -> U in R, factor it as V -> U_i -> U and take s_i|_V. Two factorizations yield a map V -> U_i ×_U U_j, so the value is well defined.)
- The plus construction is G^+(U) = colim_{R ∈ J(U)} Hom(R, G), over J(U) ordered by reverse inclusion.
- G^# = G^{++}, and G -> G^+ is natural.
- A sheaf satisfies the equalizer condition for every covering family.

**Lemma 5.1.** Let G be a presheaf on A_P^op such that, for every Q ∈ 𝔅 and every 𝒰 ∈ Cov over Q, the sequence
 0 -> G(Q) -> ∏_i G(Q_i) -> ∏_{(i,j)} G(Q_{ij})
is exact. Then:
- G(Q) -> G^+(Q) is an isomorphism for all Q ∈ 𝔅;
- G^+ satisfies the same hypothesis;
- hence G(Q) -> G^#(Q) is an isomorphism for all Q ∈ 𝔅.

*Proof.*
- By Lemma 3.5(iii), the sieves generated by members of Cov over Q are cofinal in J(Q). By 5.0 and the hypothesis, G(Q) -> Hom(R, G) is an isomorphism for each such R, compatibly with the transition maps (all are restrictions of the same element). So G(Q) -> G^+(Q) = colim Hom(R, G) is an isomorphism.
- For 𝒰 ∈ Cov over Q ∈ 𝔅, all the objects Q, Q_i, Q_{ij} lie in 𝔅 (Lemma 3.5(ii)). The natural map G -> G^+ is an isomorphism on all of them. So the sequence for G^+ is isomorphic to the one for G, and is exact.
- Apply the first point to G^+. ∎

**Corollary 5.2.** For every presheaf F on B_P^op, Lan F satisfies the hypothesis of Lemma 5.1.

*Proof.* Exactness of Lan gives an exact sequence 0 -> Lan F -> Lan I^0 -> Lan I^1 of presheaves.
- Lan I^0 and Lan I^1 satisfy the hypothesis of 5.1, by Cor. 4.3 in degrees -1, 0, 1.
- The functor G ↦ [the kernel of G(Q) -> ∏ G(Q_i) -> ∏ G(Q_ij), viewed as an equalizer] commutes with kernels of presheaves, since limits commute with limits.
- A diagram chase finishes the proof. Take s ∈ Lan F(Q) with all restrictions 0. Its image in Lan I^0(Q) has all restrictions 0, so it is 0, and hence s = 0. Next take a compatible family (s_i) for Lan F.
  - Its image in Lan I^0 glues to some t ∈ Lan I^0(Q).
  - The image of t in Lan I^1(Q) restricts to 0 on every Q_i, so it is 0.
  - Hence t comes from some s ∈ Lan F(Q), and s restricts to s_i by injectivity of Lan F(Q_i) -> Lan I^0(Q_i). ∎

**Corollary 5.3.**
- For Q ∈ 𝔅, F(Phi_Q) ≅ Lan F(Q) -> pi^{-1}F(Q) is an isomorphism, natural in F and in Q ∈ 𝔅.
- In particular the unit F -> pi_* pi^{-1} F is an isomorphism, since every b ∈ B_P is in 𝔅 (1.2, 1.6).
- For the same reason, pi^{-1}I^k(Q) ≅ Lan I^k(Q) ≅ I^k(Phi_Q) for Q ∈ 𝔅, naturally in k.
- Hence the Čech complexes of pi^{-1}I^k on members of Cov are those of Cor. 4.3. So **Ȟ^p(𝒰, pi^{-1} I^k) = 0 for p > 0 and every 𝒰 ∈ Cov.**

## §6 Cartan's criterion

**Statement.** This is Stacks Project, Cohomology on Sites, the lemma at tag 03F7, quoted from memory.
- *Setting.* Let C be a site with fibre products of the needed objects, 𝔅 a set of objects, and Cov a set of covering families such that:
  - (1) every 𝒰 = {U_i -> U} ∈ Cov has U, U_i and all U_{i_0} ×_U ... ×_U U_{i_p} in 𝔅;
  - (2) for each U ∈ 𝔅, the members of Cov covering U are cofinal: every covering of U is refined by one of them.
- *Conclusion.* If an abelian sheaf G has Ȟ^p(𝒰, G) = 0 for all p > 0 and all 𝒰 ∈ Cov, then H^p(U, G) = 0 for all p > 0 and all U ∈ 𝔅.

Here H^p(U, -) = R^pΓ(U, -) on Ab(C), with Γ(U, G) = G(U).

To be self-contained I prove it, using only the version (2') of (2) that I verified in Lemma 3.5(iii): every covering sieve of U ∈ 𝔅 contains all members of some 𝒰 ∈ Cov over U.

**Fact 6.1.** If I is an injective abelian sheaf and 𝒰 = {U_i -> U} is any family whose fibre products exist, then Ȟ^p(𝒰, I) = 0 for p > 0.

*Proof.*
- Let Z_V be the free abelian presheaf on h_V, and set K_p = ⊕_{t ∈ I^{p+1}} Z_{U_t}, with the alternating face differential. Then Hom_PSh(K_•, G) = Č^•(𝒰, G).
- Evaluate at W. Hom(W, U_t) is the set of tuples (φ_0..φ_p), φ_j : W -> U_{i_j}, with a common composite ψ : W -> U. So K_•(W) = ⊕_ψ Z[T_ψ^{•+1}], where T_ψ = {(i, φ) : φ : W -> U_i over ψ}.
- Each summand is the chain complex of the full simplex on T_ψ, with repetitions. It is acyclic in positive degrees: when T_ψ ≠ ∅, prepending a fixed element gives a contracting homotopy of the augmented complex. Its H_0 is Z if T_ψ ≠ ∅ and 0 otherwise.
- So K_• is a presheaf resolution of Z_R, where R is the sieve generated by 𝒰.
- Sheafification is exact, so K_•^# is a resolution of Z_R^#.
- Hence Č^•(𝒰, I) = Hom_PSh(K_•, I) = Hom_Sh(K_•^#, I) is exact in positive degrees, because Hom_Sh(-, I) is exact. ∎

**Proof of Cartan.** Let G satisfy the hypothesis. Choose an embedding G ↪ I with I an injective sheaf (Ab(C) is a Grothendieck category), and let Q = I/G be the sheaf quotient. Sections are left exact, so G(W) = ker(I(W) -> Q(W)) for every W.

*(a) I(V) -> Q(V) is onto for V ∈ 𝔅.*
- Take s ∈ Q(V). Since I -> Q is an epimorphism of sheaves, s lifts locally on some covering sieve R of V.
- By (2'), pick 𝒱 = {V_i -> V} ∈ Cov with members in R, and lifts t_i ∈ I(V_i) of s|_{V_i}.
- Put c_{ij} = t_j|_{V_ij} - t_i|_{V_ij}. It lies in G(V_ij), since it maps to s - s = 0 in Q. As c = dt in Č^•(𝒱, I), and Č^•(𝒱, G) ⊂ Č^•(𝒱, I), we get dc = 0 in Č^2(𝒱, G).
- Since Ȟ^1(𝒱, G) = 0, c = dg for some g ∈ Č^0(𝒱, G). Then (t_i - g_i) is compatible on all V_ij.
- I is a sheaf and 𝒱 is a covering family, so the family glues to t ∈ I(V). The image of t and s agree on every V_i, hence they are equal, because Q is a sheaf.

*(b) Q again satisfies the hypothesis.*
- For 𝒰 ∈ Cov, all the U_t lie in 𝔅 by (1). So 0 -> Č^•(𝒰, G) -> Č^•(𝒰, I) -> Č^•(𝒰, Q) -> 0 is exact, by (a) and since products are exact.
- By Fact 6.1, Ȟ^p(𝒰, Q) ≅ Ȟ^{p+1}(𝒰, G) = 0 for p >= 1.

*(c) Induction.*

- It also gives H^p(U, G) ≅ H^{p-1}(U, Q) for p >= 2.

## §7 Cohomology and the conclusion

**7.1 The sheaves pi^{-1}I^k are acyclic on 𝔅.** By Cor. 5.3, Ȟ^p(𝒰, pi^{-1}I^k) = 0 for p > 0 and 𝒰 ∈ Cov. By §6, H^p(U, pi^{-1}I^k) = 0 for p > 0 and U ∈ 𝔅.

**7.2 H^p(U, pi^{-1}F) for U ∈ 𝔅.**
- pi^{-1} is exact (1.6), so 0 -> pi^{-1}F -> pi^{-1}I^0 -> pi^{-1}I^1 -> ... is exact in Ab(A_P^op).
- Its terms are Γ(U, -)-acyclic for U ∈ 𝔅. By dimension shifting, H^p(U, pi^{-1}F) = H^p(pi^{-1}I^•(U)).
- By Cor. 5.3 this complex is I^•(Phi_U), naturally in k, and the augmented complex 0 -> F(Phi_U) -> I^0(Phi_U) -> ... is exact (Lemma 2.2).
- Hence **H^0(U, pi^{-1}F) = F(Phi_U), and H^p(U, pi^{-1}F) = 0 for p > 0, for all f.p. U.**

**7.3 R^p pi_*.**
- pi_* = restriction to B_P (1.6). It is left exact, and preserves injectives as the right adjoint of the exact functor pi^{-1}. (The latter is not even needed below.)
- Let G -> J^• be an injective resolution in Ab(A_P^op). Then R^p pi_* G = H^p(J^•|_B).
- Cohomology in PSh(B_P) is objectwise, so (R^p pi_* G)(b) = H^p(J^•(b)) = H^p(b, G).
- **Thus R^p pi_* G is the presheaf b ↦ H^p(b, G).**

**7.4 The derived unit.**
- Since pi^{-1} is exact, L pi^{-1} = pi^{-1}. The unit of the derived adjunction pi^{-1} ⊣ R pi_* on D^+ is, for a presheaf F in degree 0, the composite
 F --η--> pi_* pi^{-1} F --can--> R pi_* pi^{-1} F.
- Here η is the underived unit, and can is the canonical map. It is represented by pi_*(pi^{-1}F) -> pi_*(J^•), induced by the augmentation pi^{-1}F -> J^0 of an injective resolution J^•.
- The map can induces the identification pi_* = R^0 pi_* on H^0.
- Its source is concentrated in degree 0. Its target has H^0 = R^0 pi_* pi^{-1}F and H^p = R^p pi_* pi^{-1}F.
- On H^0 the composite is η, an isomorphism by Cor. 5.3.
- For p > 0 and b ∈ B_P, (R^p pi_* pi^{-1} F)(b) = H^p(b, pi^{-1}F) = 0 by 7.3 and 7.2, since b is f.p. (Lemma 0.1(c)).
- Hence the composite is an isomorphism on all cohomology presheaves, i.e. a quasi-isomorphism.
- The identification in 7.2–7.3 is that of the cohomology of the given map, not merely an abstract isomorphism R pi_* pi^{-1}F ≅ F. Concretely, H^0 of can∘η is the unit, which we showed is the composite of the two isomorphisms in 1.6.

**Theorem.** Let P be any monoid (integral, saturated, sharp, commutative), and assume Results B and D. Then for every presheaf of abelian groups F on B_P^op, F -> R pi_* pi^{-1} F is a quasi-isomorphism.

Moreover, H^p(U, pi^{-1}F) = 0 for p > 0 and pi^{-1}F(U) = F(Phi_U), for every f.p. object U of A_P.

*(Remark.* By the way-out lemma, the statement extends to bounded-below complexes of presheaves, since both sides are triangulated functors on D^+ and agree on objects in a single degree.)
