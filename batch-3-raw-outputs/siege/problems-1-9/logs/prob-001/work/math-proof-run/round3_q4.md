=== Background A: earlier results of this run (proofs included; re-check anything you use) ===

Notation. For a monoid P (integral, saturated, sharp, possibly not finitely generated) a "valuation" is a homomorphism v : P -> V with V valuative. For P fine, sigma = Hom(P, R_{>=0}) is the dual cone; a face of P is a submonoid F with a+b in F <=> a,b in F; P[-x]^sharp is P localized at x and then sharpened, i.e. the quotient of P[-x] by the subgroup generated by the face spanned by x.

R1 (proved). If y in M, p : M -> N is infinitesimal and p(y) = 0, then y = 0. Proof: put x = -y. Then p(x) = 0 in N, -y <= x <= 0*y so x prec y, and p(y) = 0 prec 0 = p(x). Infinitesimality gives -y in M; M sharp gives y = 0. Consequently, for M valuative, f : M -> N is infinitesimal iff f^{-1}(0) = {0} (iff f^gp injective): if the kernel is trivial and f(x) in N with x notin M, then -x in M, f(-x) = -f(x) in N, N sharp forces f(x)=0, so -x = 0, contradiction. So among valuative monoids "infinitesimal" = "injective"; the quotient Z^2_lex -> Z by the convex subgroup 0 x Z is NOT infinitesimal.

R2 (proved). For every finitely presented f : P -> Q and every V, f is birhizomic at the zero map Q -> V: in a factorization P -h-> M -p-> V of 0 with p infinitesimal, R1 gives h = 0, and any u : Q -> M with pu = 0 is 0 by R1; so u = 0 exists and is unique. Likewise, P -> P[-x]^sharp is birhizomic at every g : P[-x]^sharp -> V: p(h(x)) = g(0) = 0 forces h(x) = 0, so h factors uniquely through P[-x]^sharp by its universal property (and pu = g follows by uniqueness of maps out of P[-x]^sharp). In particular the zero valuation factors birhizomically through every object of A_P.

R3 (proved; corrects an earlier heuristic). Closed charts of a subdivision of the dual cone are NOT birhizomic at valuations lying on the walls. Example: P = N^2 (basis e1,e2), Q = <e2, e1-e2> subset Z^2 (the chart of the cone spanned by (1,0),(1,1) in the subdivision of R_{>=0}^2 by the ray (1,1)), g : Q -> N with g(e2) = 1, g(e1-e2) = 0 (so v(e1) = v(e2) = 1). Let M = {x in Z^2 : x1+x2 > 0} union {0} (integral, saturated, sharp, M^gp = Z^2), h : P -> M the inclusion, p : M -> N, p(x) = x1+x2. Then ph = gf. p is infinitesimal: if p(x) >= 0, x prec y, p(y) prec p(x): when p(x) > 0, x in M; when p(x) = 0, p(y) prec 0 forces p(y) = 0, so y = 0, and x prec 0 forces x = 0. But a u : Q -> M with uf = h must send e1-e2 to e1-e2 notin M. So P -> Q is not birhizomic at g. Hence birhizomic covers are NOT (refinements of) subdivision covers by closed charts.

R4 (proved). "Open-cone" neighbourhoods are birhizomic. Let v : P -> V be a valuation, a_1,...,a_k in P^gp with v(a_i) > 0, and suppose each a_i = b_i - c_i with b_i, c_i in P and v(b_i + c_i) prec v(a_i) in V (i.e. m v(a_i) <= v(b_i+c_i) <= n v(a_i); automatic if V is archimedean, e.g. V subset R_{>=0}). Let Q be the saturation in P^gp of the submonoid generated by P and the a_i, and g : Q -> V the extension of v. Then Q is sharp (if q, -q in Q then v(q) = 0, and nq = p + sum m_i a_i with v = 0 forces all m_i = 0, so nq, -nq in P, so q = 0), and P -> Q is birhizomic at g, provided it is of finite presentation (clear if P is finitely generated). Proof: given P -h-> M -p-> V infinitesimal, x = h^gp(a_i), y = h(b_i + c_i): y - x = 2h(c_i) >= 0 and y + x = 2h(b_i) >= 0, so x prec y; p(x) = v(a_i) in V; p(y) prec p(x) by hypothesis; so x in M. M saturated gives h^gp(Q) subset M; u = h^gp|_Q works, and is unique because Q^gp = P^gp (and M^gp is torsion-free). So for a rank-one valuation v with v^{-1}(0) = 0 on fine P, the birhizomic neighbourhoods include the monoids dual to rational polyhedral cones containing v in their INTERIOR.

Lemma A / Proposition B (proved in an earlier round; text verbatim):

**Setting.** P is fine. f : P -> Q has f^gp an isomorphism, so Q is a fine saturated monoid with P ⊂ Q ⊂ P^gp. g : Q -> V, V is valuative, and v := g^gp : P^gp -> V^gp. Assume v(x) ≠ 0 for every x ∈ P \ {0}.

**Lemma A (necessary condition).** If f is birhizomic at g, then g(q) > 0 for every q ∈ Q \ {0}.

*Proof.* Let M = {x ∈ P^gp : v(x) > 0} ∪ {0}.
- M is a sharp, integral submonoid of P^gp. It is saturated: V^gp is a totally ordered torsion-free group, so v(nx) > 0 implies v(x) > 0.
- P ⊂ M, by the hypothesis on v.
- Let h : P -> M be the inclusion and p = v|_M : M -> V. Then ph = gf.
- p is infinitesimal. Suppose x ∈ P^gp, y ∈ M, p(x) ∈ V, x ≺ y and p(y) ≺ p(x). If v(x) > 0 then x ∈ M. Otherwise v(x) = 0, so p(y) ≺ 0, so p(y) = 0, so y = 0. Then x ≺ 0 forces x = 0 ∈ M.

So there is a u : Q -> M with uf = h. Because Q^gp = P^gp, u must be the inclusion (u^gp agrees with h^gp, which is the identity). Hence Q ⊂ M, i.e. v > 0 on Q \ {0}. ∎

This generalises R3: there v(e1 − e2) = 0 with e1 − e2 ∈ Q.

**Proposition B (rank one).** Suppose in addition that V is archimedean (rank one). Then f is birhizomic at g if and only if g^{-1}(0) = {0}.

*Proof.*
- (⇒) This is Lemma A.
- (⇐) Q is finitely generated, so Q is the saturation of P + ⟨a_1, …, a_k⟩ with a_i ∈ Q \ {0}, and g(a_i) > 0. Write each a_i = b_i − c_i with b_i, c_i ∈ P. Since V is archimedean and v(a_i) > 0, we have v(b_i + c_i) ≺ v(a_i). R4 then applies; I re-checked its proof and it is correct. Finite presentation holds because P and Q are fine. ∎

In words: for a rank-one valuation that is injective on P, the birhizomic neighbourhoods with f^gp an isomorphism are exactly the charts whose dual cone contains v in its interior. These are open-cone neighbourhoods, not the closed charts of a subdivision.

=== Background B: a proof outline for finitely generated P (written by the director of this attempt; NOT yet checked by anyone — every step must be re-verified) ===

Conventions. "Monoid" = integral, saturated, sharp, commutative. Presheaves on A_P^op are covariant functors A_P -> Ab (Q |-> G(Q), with G(Q) -> G(Q') for each map Q -> Q' under P). The covering families of an object (P -> Q) of A_P^op are taken to be the families {Q -> Q_i} (maps under P) that are birhizomic covers of Q in the sense of the problem (with Q in the role of P). Fibre products in A_P^op are pushouts in A_P, computed in the category of integral saturated sharp monoids (pushout of monoids, then integralization, saturation, sharpening). A valuation of Q is a homomorphism Q -> V with V valuative; R_{>=0} is a valuative monoid. "f.p." = of finite presentation in the category of integral saturated sharp monoids under the source. For a monoid Q write Q^v_R = Hom(Q, R_{>=0}) (real valuations).

Step 0 (the comparison functor). Let P be fine. For an object f : P -> Q of A_P let Phi_Q = f^{-1}(0), a face of P; since P is finitely generated, Phi_Q is the face generated by one element x_Q (the sum of the generators of P lying in Phi_Q). A morphism P[-x]^sharp -> Q under P exists iff f(x) = 0, and is then unique; so B_P is a preorder equivalent to the finite poset of faces of P, and the comma category {(b in B_P, b -> Q)} has the terminal object b(Q) := P[-x_Q]^sharp. Hence the left Kan extension of F along B_P^op -> A_P^op is (Lan F)(Q) = F(Phi_Q) =: (F o b)(Q), the transition maps being those of F. pi^{-1}F is the sheafification of F o b.

Step 1 (kernel faces via real valuations). If Q is fine (f.p. objects over a fine P are finitely generated, hence fine), then for x in P, f(x) = 0 iff w(f(x)) = 0 for all w in Q^v_R (a fine saturated sharp monoid has a strictly positive real functional, which is positive on every nonzero element). So Phi_Q = { x in P : w(f(x)) = 0 for all w in Q^v_R }. For a covering {Q -> Q_i}_{i in I} of a fine object Q and a finite sigma subset I, let Q_sigma be the pushout over Q of the Q_i, i in sigma (repetitions allowed), and T_i = image of Q_i^v_R -> Q^v_R (a closed polyhedral convex cone). By the universal property of the pushout (R_{>=0} is a monoid of our kind), the image of Q_sigma^v_R in Q^v_R is the intersection T_sigma of the T_i, i in sigma. So Phi_{Q_sigma} = { x in P : w(x) = 0 for all w in T_sigma } (w(x) meaning w(f(x))).

Step 2 (covers are covers of the real dual cone; finite subfamilies). Every w in Q^v_R factors through some Q_i, so the union of the T_i is all of Q^v_R. Lemma K (claimed): there is a FINITE J_0 subset I with union over J_0 of T_i = Q^v_R. Sketch: let W = Q^gp (x) Q (rationals). Let Omega be the set of positive cones Pi of total preorders on the Q-vector space W compatible with addition and positive rational scaling, with Q subset Pi; Omega is closed in {0,1}^W, hence compact (Tychonoff; the "patch" topology). Each Pi gives an ordered Q-vector space V_Pi = W/(Pi cap -Pi) and a valuation v_Pi : Q -> V_Pi^{>=0}; every valuation v : Q -> V is equivalent to one of these (Pi = {x : v(x) >= 0}). Writing Q_i as a retract of (Q (+) N^k / finitely many relations)^{int,sat,sharp}, "v_Pi factors through Q_i" says that a finite system of linear equations and inequalities y_j >= 0 with integer coefficients and constants in v_Pi(Q^gp) has a solution in V_Pi; by Fourier–Motzkin elimination (quantifier elimination for ordered divisible abelian groups) this is a finite Boolean combination of sign conditions on finitely many elements of W, so E_i = {Pi : v_Pi factors through Q_i} is clopen. The E_i cover Omega (cover property applied to v_Pi), so finitely many do; for a real w, V_{Pi_w} embeds in R, giving the claim.

Step 3 (Cech complexes of injective-type presheaves are nerves). For a face tau of P and an abelian group A let I_{tau,A} be the presheaf on B_P^op with I_{tau,A}(b) = A if Phi_b subset Phi_tau and 0 otherwise (identity transition maps where both are A). Then Hom(F, I_{tau,A}) = Hom(F(tau), A), so I_{tau,A} is injective when A is, and every F embeds into the finite product over tau of I_{tau, E(F(tau))} (E = injective hull); so every F has an injective resolution by finite products of such. For G = I_{tau,A} o b and a covering {Q -> Q_i}_{i in I} of a fine object Q, G(Q_sigma) = A iff Phi_{Q_sigma} subset Phi_tau, else 0. Let C = { w in Q^v_R : w(x) > 0 for all x in P \ Phi_tau } (convex: it suffices to impose it on the finitely many generators of P outside Phi_tau). Then Phi_{Q_sigma} subset Phi_tau iff T_sigma meets C (take w = sum of generators of the polyhedral cone T_sigma, whose kernel on P is exactly Phi_{Q_sigma}). So the Cech complex of G for this covering is the ordered cochain complex, with coefficients A, of the simplicial complex N_tau = { finite sigma : T_sigma cap C nonempty } = nerve of the family {T_i cap C}.

Step 4 (the nerves are contractible). If C is empty, G(Q) = 0 and N_tau is empty. Otherwise: every finite subcomplex L of N_tau lies in the full subcomplex N_tau(J') on J' = vertices(L) union J_0. Choose one witness point of T_sigma cap C for each simplex sigma of N_tau(J') and let D be the convex hull of the witnesses: a compact convex subset of C. The sets T_i cap D (i in J') are compact convex, cover D (because the T_i, i in J_0, cover Q^v_R), and have nerve exactly N_tau(J'). By the nerve theorem for finite families of compact convex sets, N_tau(J') is homotopy equivalent to D, hence contractible. So |N_tau| is contractible, its cohomology is A in degree 0 and 0 above; thus the Cech cohomology of I_{tau,A} o b on every covering of every fine object is A (resp. 0) in degree 0 when C is nonempty (resp. empty) — equal to G(Q) — and 0 in positive degrees.

Step 5 (sheaf property). Degree 0 of Step 4 says I_{tau,A} o b satisfies the sheaf condition for all coverings of f.p. objects. For general F, embed F into an injective I^0 as in Step 3 and use left exactness of equalizers and exactness of F |-> F o b: F o b satisfies the sheaf condition for all coverings of f.p. objects. Since coverings and their fibre products of f.p. objects only involve f.p. objects, the sheafification of F o b agrees with F o b on f.p. objects: pi^{-1}F(Q) = F(Phi_Q) for all f.p. Q, in particular pi_* pi^{-1} F = F via the unit.

Step 6 (higher vanishing). Cartan's criterion (Stacks Project, Lemma 21.10.9 [tag 03F7]): let B be the set of f.p. objects of A_P^op and Cov the set of all coverings of objects of B (members and all fibre products are again in B). If a sheaf G has vanishing Cech cohomology in positive degrees on every covering in Cov, then H^p(U, G) = 0 for p > 0 and all U in B. Apply to G = (I_{tau,A} o b)^sheafified (Steps 4–5); then for general F use the resolution F o b -> I^. o b, which is exact objectwise, by sheaves that are acyclic on B: H^p(U, pi^{-1}F) = 0 for p > 0 and U in B. Finally R^p pi_* G is the (trivial-topology) sheaf b |-> H^p(b, G) on B_P^op (pi is induced by the continuous left exact inclusion of sites), and every b = P[-x]^sharp is f.p. So R pi_* pi^{-1} F = F, i.e. the answer is YES for every finitely generated P.

Remark. This outline uses about the birhizomic topology only that covering families consist of f.p. objects and that every valuation factors through some member. For non-finitely-generated P the outline breaks at Step 0 (are kernel faces principal?), at Step 1 (real valuations no longer detect kernel faces: e.g. for P = {x in Z^3 : x3 > 0, or x3 = 0 and x1, x2 >= 0} every real valuation kills e1 and e2), and at Step 4 (the analogous sets of higher-rank valuations, E_i cap C below, are convex in Hom(Q^gp, H) for a large Hahn group H but not closed, and the nerve theorem fails for non-closed convex sets: [0,1) and [1,2] have disconnected nerve). For general Q (f.p. over arbitrary P) one still has: N_tau = nerve of {E_i cap C_Omega} where E_i = valuations factoring through Q_i and C_Omega = valuations v with v(x) > 0 for all x in P \ Phi_tau (using that every monoid has an injective valuation by the order-extension theorem for torsion-free abelian groups, and that a valuation into V factors through Q_i into V iff it does so into the divisible hull, by model completeness of ordered divisible abelian groups); and Lemma K holds verbatim.
