# Answer to round4_q1: the nerve statement (#19) holds for every monoid P

**Plan, as executed.** I prove #19 exactly as stated: every P, every f.p. Q, every birhizomic cover, and every face tau ⊇ Phi_Q. The proof is a compactness and approximation reduction to finite-dimensional real convex geometry, after which the Borsuk nerve theorem finishes the argument, as in the fine case (#15). It uses only two properties of the cover:
- (L) every valuation of Q lifts to some Q_i;
- each Q -> Q_i is f.p.

Birhizomicity beyond (L) is not used, and neither is principality of tau. Section 6 explains why the director's Hahn-convexification sketch fails as stated. Section 7 re-checks the chain.

## 0. Conventions

- "Monoid" means integral, saturated, sharp and commutative. f : P -> Q is f.p., Phi_Q = f^{-1}(0), and {Q -> Q_i}_{i in I} satisfies (L).
- For finite nonempty sigma ⊂ I, Q_sigma is the pushout of the Q_i (i in sigma) over Q in our category, and Phi_sigma = ker(P -> Q_sigma).
- N_tau = {sigma : Phi_sigma ⊂ tau}.
- Q^gp is torsion-free: if nx = 0 then nx and n(-x) lie in Q, so x and -x lie in Q by saturation, so x = 0 by sharpness.

**The space Omega.** Let Omega be the set of subsets W ⊂ Q^gp with 0 ∈ W, W + W ⊂ W and W ∪ (-W) = Q^gp.
- Such a W is exactly the nonnegative cone w^{-1}(Gamma_{>=0}) of a group homomorphism w : Q^gp -> Gamma to a totally ordered abelian group. Take Gamma = Q^gp/(W ∩ -W), ordered by W.
- Omega is closed in 2^{Q^gp}, since each defining condition involves finitely many coordinates. So Omega is compact, by Tychonoff.
- For finite F ⊂ Q^gp, the set Omega_F = {W : F ⊂ W} is clopen. Also Omega_Q := {W : Q ⊂ W} is closed.
- Points of Omega_Q are valuations of Q up to equivalence: W gives Q -> Gamma_{>=0}, and Gamma_{>=0} is a valuative monoid (integral, saturated because ordered groups are torsion-free, sharp, totally ordered).

## 1. Lemma 1 (injective valuations; self-contained)

**Statement.** Let M be a monoid and X ⊂ M \ {0}. There is W ∈ Omega_M (on M^gp) with M ⊂ W and -m ∉ W for all m ∈ X. In other words, there is a valuation that is strictly positive on X.

**Proof.** By compactness of Omega(M^gp), it suffices to treat a finite F ⊂ M and a finite X_0 ⊂ X.
1. Let Λ be the free abelian group generated by F ∪ X_0 in M^gp.
2. Suppose the real cone spanned by the nonzero elements g_1, ..., g_s of F ∪ X_0 contains a line. Then sum c_j g_j = 0 with c_j >= 0 not all zero, and by rational linear algebra the c_j can be taken to be integers n_j >= 0.
3. Sharpness then forces n_j g_j = 0, so g_j = 0 for every j with n_j > 0, a contradiction. So the cone is pointed.
4. Hence some d ∈ Hom(Λ, R) is strictly positive on all g_j. Extend d to M^gp, which is possible because R is divisible.
5. Then W = {d >= 0} has F ⊂ W and -X_0 ∩ W = ∅. ∎

## 2. Lemma 2 (lifting loci are cut out by finitely many weak inequalities)

**Statement.** For each i there is a finite A_i ⊂ Q^gp with the following property. For every valuation w : Q -> Gamma_{>=0}, w lifts to some g : Q_i -> Gamma'_{>=0} with Gamma' ⊇ Gamma iff w(a) >= 0 for all a ∈ A_i. In that case a lift exists into D(Gamma)_{>=0}, where D(Gamma) is the divisible hull of Gamma.

**Proof.**
1. *Reduction to a finite presentation.* Q_i is a retract under Q of Q' = (Q ⊕ N^k / R)^{int,sat,sharp} with R finite. This is the standard description of f.p. (compact) objects, cited from memory as in #16; it is trivial if f.p. is defined by such presentations. Lifts to Q_i exist iff lifts to Q' exist, by composing with the retraction maps.
2. *Lifts as solutions of a linear system.* Let V be a valuative monoid. Maps Q' -> V under Q are the y ∈ V^k satisfying the relations of R. With B an integer R×k matrix and c_r ∈ Q^gp, this reads: y >= 0 and B y = b(w), where b(w)_r = w(c_r).
3. *Description of the cone.* By Weyl–Minkowski over Q, B(Q^k_{>=0}) = {u ∈ Q^R : z_m·u >= 0, m = 1..M} with z_m ∈ Z^R; equalities are written as two inequalities.
4. *Necessity.* If a lift exists in any ordered group, then z_m·b = (z_m B)·y >= 0, because z_m B >= 0 coordinatewise.
5. *Sufficiency.* The sentence "for all u, (∧_m z_m·u >= 0) implies there is y >= 0 with By = u" holds in Q. The theory of nontrivial divisible ordered abelian groups is complete (Robinson/Tarski, cited from memory). So the sentence holds in D(Gamma); the trivial case is immediate.
6. Put A_i = {sum_r z_{m,r} c_r : m = 1..M}. ∎

**Notation.** E_i := {W ∈ Omega : A_i ⊂ W}, which is clopen. Property (L) gives Omega_Q ⊂ ∪_{i∈I} E_i.

## 3. Lemma 3 (valuation form)

**Statement.** sigma ∈ N_tau iff there is a W ∈ Omega with:
- Q ⊂ W;
- A_i ⊂ W for all i ∈ sigma;
- -f(x) ∉ W for all x ∈ P \ tau.

**Proof.**
- (⇐) Let w be the valuation of W. By Lemma 2, w lifts to every Q_i (i ∈ sigma) inside the same D(Gamma)_{>=0}. So it induces Q_sigma -> D(Gamma)_{>=0}. Each x ∈ P \ tau has w(f x) > 0, so x ∉ Phi_sigma. Hence Phi_sigma ⊂ tau.
- (⇒) Lemma 1 gives a valuation g of Q_sigma that is positive on Q_sigma \ 0. Then W := (g ∘ (Q -> Q_sigma))^{-1}(>=0) contains Q. It contains A_i by the necessity part of Lemma 2, because a lift exists. For x ∉ tau we have x ∉ Phi_sigma, so the image of x in Q_sigma is nonzero and g of it is > 0. ∎

**Nonemptiness of N_tau.** Apply Lemma 1 to Q with X = Q \ 0. Every x ∉ tau has x ∉ Phi_Q ⊂ tau, so f(x) ≠ 0. The resulting injective valuation lies in some E_i by (L), so {i} ∈ N_tau.

## 4. Lemma 4 (compactness)

**(a) Finite subcover.** There are a finite J_0 ⊂ I and a finite F_1 ⊂ Q with Omega_{F_1} ⊂ ∪_{i∈J_0} E_i. So every W ∈ Omega containing F_1, even one not containing Q, contains some A_i with i ∈ J_0.

*Proof.* Let U = ∪_I E_i, which is open. The family Omega \ U, Omega_F (F finite ⊂ Q) consists of closed sets, the Omega_F are directed, and their total intersection is Omega_Q \ U = ∅. Compactness gives a single F_1 with Omega_{F_1} ⊂ U. Since Omega_{F_1} is compact and the E_i are open, finitely many of them cover it. ∎

**(b) Finite witnesses for non-simplices.** For finite F ⊂ Q, finite G ⊂ P \ tau and finite J ⊂ I, put
N_{F,G}(J) = {sigma ⊂ J : there is W ∈ Omega with F ∪ A_sigma ⊂ W and -f(G) ∩ W = ∅}.
- N_{F,G}(J) contains N_tau(J) (the subcomplex on vertices J). It decreases as F and G grow.
- For (F,G) large enough, N_{F,G}(J) = N_tau(J). Indeed, if sigma ∉ N_tau, the set in Lemma 3 is an empty intersection of clopen sets of the compact space Omega. So some finite sub-intersection is already empty, and there are finitely many such sigma.

**(c) Real realization.** Let Λ ⊂ Q^gp be the subgroup generated by F, f(G) and the A_i (i ∈ J); it is free of finite rank. Then sigma ∈ N_{F,G}(J) iff some d ∈ Hom(Λ, R) satisfies d >= 0 on F ∪ A_sigma and d > 0 on f(G).
- (⇐) Extend d to Q^gp and take W = {d >= 0}.
- (⇒) Let w : Q^gp -> Gamma be the homomorphism of W. The finite system of weak and strict integral linear inequalities on the images of a basis of Λ is solvable in D(Gamma). That group is nontrivial if G ≠ ∅; if G = ∅, take d = 0. By completeness of the theory of divisible ordered abelian groups, the system is solvable in R.

## 5. Theorem (#19)

**Statement.** For every monoid P, every f.p. f : P -> Q, every family {Q -> Q_i} of f.p. maps satisfying (L) (in particular every birhizomic cover), and every face tau ⊇ Phi_Q:
- N_tau is nonempty;
- every finite subcomplex of N_tau lies in a finite contractible subcomplex.

Hence reduced integral homology of N_tau vanishes. Its augmented ordered chain complex is free and acyclic, hence split exact. So the augmented ordered cochain complex with coefficients in any abelian group A is exact. (Ordered and oriented simplicial chains have the same homology; this is standard.)

**Proof.** Nonemptiness is shown in Section 3. Now let L ⊂ N_tau be a finite subcomplex.
1. *Choose finite data.* Put J' = vert(L) ∪ J_0. Choose finite F ⊃ F_1 and finite G such that N_{F,G}(J') = N_tau(J'), using Lemma 4(b). Let Λ be as in Lemma 4(c), and put:
   - S_F = {d >= 0 on F}, a closed polyhedral cone;
   - T_i = {d >= 0 on A_i} for i ∈ J', closed polyhedral cones;
   - C_G = {d > 0 on f(G)}, a convex set.
2. *Witnesses.* For each sigma ∈ N_tau(J'), Lemma 4(c) gives d_sigma ∈ S_F ∩ C_G ∩ T_sigma. Let D be the convex hull of the d_sigma. It is compact, convex, nonempty, and contained in S_F ∩ C_G.
3. *The T_i ∩ D (i ∈ J') cover D.* Let d ∈ D. Extend d to Q^gp. Then W = {d >= 0} contains F_1, so by Lemma 4(a) it contains A_i for some i ∈ J_0 ⊂ J'. Hence d ∈ T_i.
4. *Their nerve is exactly N_tau(J').*
   - It contains N_tau(J'), because d_sigma ∈ D ∩ T_sigma.
   - If d ∈ D ∩ T_sigma, then d ∈ S_F ∩ C_G ∩ T_sigma, so sigma ∈ N_{F,G}(J') = N_tau(J') by Lemma 4(c).
5. *Contractibility.* By the nerve theorem for finitely many compact convex sets in R^r (Borsuk 1948 / Leray, cited from memory), N_tau(J') is homotopy equivalent to their union D, which is contractible. And L ⊂ N_tau(J'). ∎

**Remarks.**
- The proof never uses birhizomicity beyond the lifting property (L), never uses that tau is principal, and uses Phi_Q ⊂ tau only for nonemptiness.
- Lemma K of #15 becomes Lemma 4(a), with a Tychonoff proof.
- Real points of the approximating cones S_F replace real valuations of Q, which may not exist when P is not finitely generated. That was the obstacle in the fine-case proof.

## 6. Why the director's Hahn-convexification sketch fails as stated (proved example)

**The example.** Take Q = P = N^2 and two valuations into Z^2_lex:
- v_0 : e1 ↦ 0, e2 ↦ (0,1);
- v_1 : e1 ↦ (1,0), e2 ↦ (0,1).

Put w_μ = μ v_1 + (1-μ) v_0. For μ > 0 this is equivalent to v_1.
- For Q_1 = <e2, e1 - e2>, which is birhizomic at v_1 by R4, the set {μ : w_μ lifts} is (0,1].
- For N^2[-e1]^sharp, which is birhizomic at v_0 by R2, that set is {0}.

**Consequences.**
- On this segment the two loci are disjoint, so their nerve is disconnected. Thus convex families in a Hahn group can have disconnected nerves, and the proposed "openness along segments" fails at v_0.
- Lexicographic convex combinations jump across archimedean levels.
- Section 5 avoids this by realizing everything with real functionals on a finitely generated subgroup Λ, where the sets T_i are closed.

## 7. Check of the chain (steps 1–6 of the task)

I re-checked steps 1, 2, 3, 5 and 6 and found no flaw. Points checked:
- **Step 1 (Lan):** Lan F(Q) = F(Phi_Q) on f.p. Q via the terminal object P[-s]^sharp (#16), and pi_* is restriction.

- **Step 3 (Čech complex):** on a cover of f.p. Q, the augmented Čech complex of I_{tau,A}∘b is the ordered cochain complex of N_tau. It is zero if Phi_Q ⊄ tau.
- **Step 5 (sheafification):** G^+ = G on f.p. objects, because covers of f.p. objects and their fibre products are f.p. Hence G^{++} = G there.
