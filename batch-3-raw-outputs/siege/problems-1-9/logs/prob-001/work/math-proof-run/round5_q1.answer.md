## 1. Part B (principal kernel faces for f.p. P → Q)

**Reduction to a finite presentation.** This is correct, given Part D's Lemma 1(i). That proof works verbatim with P in place of Q as the base. The kernel of P → Q equals the kernel of P → Q′ when Q is a retract of Q′ under P. Proof: if x is killed in Q′, then x is killed in Q = image under Q′ → Q. If x is killed in Q, apply the section Q → Q′, which is a map under P; so x is killed in Q′.

**Kernel of P → Q′.** This is correct. Points I checked:
- The integralization of (P⊕N^k)/R is the image M0 of P⊕N^k in G = (P^gp⊕Z^k)/L.
- G may have torsion. The saturation M1 is taken inside G, so it contains the torsion of G. Torsion elements are units, and sharpening kills them.
- M1/M1^* lies in 𝒞 and has the universal property of the int-sat-sharp quotient: a map from P⊕N^k to N ∈ 𝒞 that respects R extends to G → N^gp. It sends M1 into N because N is saturated and N^gp is torsion-free, and it sends units to 0.
- x is killed ⇔ −x ∈ M1 ⇔ −nx ∈ M0 for some n ≥ 1 ⇔ (−nx, 0) − (p, m) ∈ L for some p ∈ P and m ∈ N^k.
- Write the element of L as Σ c_j l_j. The Z^k-part condition says c ∈ K, the set of lattice points of a rational polyhedral cone. K is finitely generated by Gordan's lemma.
- The P^gp-part gives nx + p = ψ(c) ∈ Y.
- The converse holds: put m := −(Z^k-part of Σ c_j l_j) ∈ N^k.
- So x is killed ⇔ nx ≤ y for some y ∈ S = Y ∩ P and some n ≥ 1 ⇔ x ≤ y for some y ∈ S. For the second equivalence, use x ≤ nx, which holds because (n−1)x ∈ P.
- This set is the face generated by S: it is closed under addition because S is a submonoid, and it is downward closed.

**Principality.** This is correct.
- F^gp ∩ P = F for a face F. If x = a − b with a, b ∈ F and x ∈ P, then x + b = a ∈ F, so x ∈ F. Saturation is not even needed for this.
- Suppose n s_{i+1} ∈ G_i. Then n s_{i+1} ∈ F(s_i)^gp ∩ P = F(s_i), so s_{i+1} ∈ F(s_i) and F(s_{i+1}) ⊂ F(s_i), which is a contradiction.
- So s_{i+1} has infinite order in G_{i+1}/G_i, and the ranks strictly increase inside the finitely generated group Y^gp. Note that P^gp is torsion-free.
- Hence chains have length at most rk Y^gp + 1, and a maximal F(s) exists, starting from s = 0 ∈ S.
- By directedness (F(s+t) = F(s) ∨ F(t)), the maximal F(s) contains every F(t).
- The face generated by S is ∪_{t∈S} F(t), so it equals F(s).

**Consequence.** If x and x′ generate the same face, then P[−x]^♯ ≅ P[−x′]^♯ under P, since inverting x inverts every y ≤ nx. Also ker(P → P[−x]^♯) = face(x): p becomes a unit iff p + q = nx for some q ∈ P and n. The localization of a saturated monoid is saturated: if m y ∈ P[−x], then m(y + kx) ∈ P for some k, so y + kx ∈ P. Hence B_P is equivalent to the poset of principal faces, and P[−s]^♯ is terminal in the comma category over an f.p. Q.

The side remark (P valuative of infinite rank, P → 0) is correct and not load-bearing.

## 2. Part D (nerve statement, arbitrary P)

**Injective valuations.** Correct.

**Lemma 1.**
- (i) Correct, with one wording point (repair R1). T(S,R) must denote the object ((Q⊕N^S)/R)^{int,sat,sharp} itself, not its image in M. Otherwise T would not be presented by finitely many relations, and (ii) would fail. The injectivity proof is written for the object reading and is right:

- (ii) Correct. H_{≥0} ∈ 𝒞, so a map out of Q⊕N^S that respects R factors uniquely through the int-sat-sharp quotient.
- (iii) Correct. The system is homogeneous in (y, c) with rational coefficients. Each equality is written as two inequalities.

  - The resulting conditions u_m·c ≥ 0 come from a formal procedure, so they are independent of H.
  - u_m·c = v(x_m) because v extends Q-linearly to U → H.

**Theorem T.**
- The complex is well defined. The factor maps go from a smaller tuple to a larger tuple. If the larger cone is in 𝒢, so is the smaller one by (G0), and the map is the identity; otherwise the target is 0.

  - For the degree −1 term one needs {j*} ∈ N(K) and K ∈ 𝒢.
- *Base case.* Correct: an undecided z cannot occur, so X_{j*} ⊂ K and j* is a cone point.
- *Row lemma.* Correct. It uses Lemma Z, (G1), totality and (G0) to get one vertex, and (G2) for the edge. The nerve on {+, −} is then a vertex or an edge, and the cone lemma applies.
- *Inductive step.* Correct.
  - Rows: for fixed p and varying q ≥ −1, the row is the finite product over σ of row-lemma complexes on K + cone X_σ. This includes p = −1.
  - Column q ≥ 0: it equals ∏_ρ C^•(K_ρ). The cover hypothesis passes to K_ρ ⊃ K, and m(K_ρ) < m(K) because z becomes decided and nothing becomes undecided.
  - Column q = −1 is C^•(K).
  - The double-complex lemma (quoted from memory) applies: a double complex supported in p, q ≥ −1 with exact rows has acyclic total complex, by the column filtration, which is finite in each total degree.
  - The columns q ≥ 0 form a subcomplex, since d_II raises q. Its total complex is acyclic by the q-filtration, which is finite in each degree.
  - The quotient is column −1 with differential d_I. The long exact sequence then gives exactness of C^•(K).
  - The boundary row and column p = −1, q = −1 are handled correctly.

## 3. Part C, Steps 0, 3, 5 and 6 read for arbitrary P (point (c))

**Step 0.**
- The first and last bullets of "B_P is a preorder" are general. The "x_Q = sum of generators" bullet and "finite poset" are replaced by Part B.
- Lan along a fully faithful functor: (Lan F)(Q) = colim over the comma category of F(b). For f.p. Q it equals F(Φ_Q). For general Q it is a filtered colimit over the directed poset of principal faces contained in Φ_Q.
- Filtered colimits are exact, so Lan is exact. Sheafification is exact, so π^{−1} is exact.
- Hom(π^{−1}F, G) = Hom(Lan F, G) = Hom(F, G|_B) for every sheaf G, so π_* = restriction.
- The unit F → (Lan F)|_B is an isomorphism because the inclusion is fully faithful (b is terminal in its own comma category).
- Nothing fine-specific remains.

## 4. Part A, and points (d) and (e)

**Steps 1–3.** Correct, as discussed above. In step 3, note that (Lan I_{τ,A})(Q′) = A iff Φ_{Q′} ⊂ τ holds for every Q′. The f.p. hypothesis is needed only for Lan to commute with the infinite product I^k.

**Steps 4–5.** Step 4 is supplied by Part D, applied to coverings in Cov: the members are f.p. and every valuation factors through one of them. Step 5 is then correct.

**Step 6.** Cartan's criterion, as I recall Stacks tag 03F7 (from memory): B ⊂ Ob, Cov ⊂ Cov(𝒞), such that
1. every 𝒰 ∈ Cov has target, members and all U_{i_0…i_p} in B;
2. for each U ∈ B, the coverings of U in Cov are cofinal among all coverings of U;
3. Ȟ^p(𝒰, G) = 0 for all p > 0 and all 𝒰 ∈ Cov.

Then H^p(U, G) = 0 for all p > 0 and U ∈ B.

Each hypothesis is verified with Cov as in step 7.
- (1): composites and pushouts of f.p. maps are f.p. Indeed Hom_P(Q_i, −) = ⊔_{g ∈ Hom_P(Q,−)} Hom_Q(Q_i, −), and Hom_{Q_j}(Q_i ⊔_Q Q_j, −) = Hom_Q(Q_i, −).
- (2): see (d) below.
- (3): by Part D.

**Every P[−x]^♯ is f.p.**
- Hom_P(P[−x]^♯, N) is a point if x ↦ 0 and empty otherwise.
- In a filtered colimit in 𝒞, which is computed in monoids, x ↦ 0 holds iff it holds at some stage.

**(d) Members that are not witnesses.** Correct.
- A witness is f.p. by the definition of "birhizomic at".
- The witness subfamily is again a birhizomic cover: each valuation factors through a witness at which it is birhizomic.
- The witness subfamily refines the original family.
- So Cov-coverings are cofinal among the coverings of each f.p. U. They are also directed among themselves: the fibre-product covering {U_i ×_U U_j} of two Cov-coverings again has f.p. members.
- Plus construction. G^+(U) = colim over coverings of U of Ȟ^0(𝒰, G). This colimit may be computed over the cofinal directed subsystem Cov(U). If G(U) → Ȟ^0(𝒰, G) is an isomorphism for every 𝒰 ∈ Cov(U), compatibly with the transition maps, then G(U) ≅ G^+(U) for f.p. U.
- Since G → G^+ is then an isomorphism on all f.p. objects, the Čech complexes of G^+ on Cov coverings agree with those of G. Hence G^{++}(U) = G(U), and G^{sh} = G^{++}.
- Cartan's criterion needs exactly hypothesis (2), which this cofinality supplies.
- Repair R5: the last bullet of step 7 (the case of a generated topology) is not needed. The problem states that the birhizomic covers form the topology, so covering sieves are those containing a birhizomic cover.
  - If one only wanted the topology generated by birhizomic covers, the bullet would need the extra fact that birhizomic covers are stable under composition and base change, i.e. that they form a pretopology. The problem's assertion supplies this; the chain does not prove it.

**(e) Identifications.**
- π_* = restriction (Step 0).
- π_* preserves injectives, being right adjoint to the exact functor π^{−1}.
- R^pπ_*G is computed by π_* of an injective resolution J^•, i.e. b ↦ H^p(J^•(b)) = H^p(b, G). Exactness in presheaves on B_P is pointwise, and the trivial topology on B_P means sheaves = presheaves.
- The unit F → π_*π^{−1}F is F → (Lan F)|_B → (Lan F)^{sh}|_B. The first map is an isomorphism because the inclusion is fully faithful. The second is an isomorphism on f.p. objects by step 5, and every b is f.p.
- Hence R^0π_*π^{−1}F ≅ F via the unit and R^{>0} = 0, so the unit is a quasi-isomorphism.

## 5. Minor points (no effect on validity)

- R6 (size): A_P is large. Sheafification and the plus construction need the usual universe or cardinality bound, as in Stacks' treatment of big sites. Every argument above is insensitive to this.
- R7 (meaning of f.p.): both readings work.
  - Compact in the under-category: Lemma 1(i) supplies the retract.
  - Literally presented by finitely many generators and relations: Lemma 1(i) is immediate.
  - Under both readings, composites, pushouts and the objects P[−x]^♯ are f.p.
- The infinitesimal condition in the definition of "birhizomic" is never used. Only f.p. of the witnesses and the factorization of valuations are used. This is consistent: the proof shows the conclusion for any topology whose covers have these properties.
