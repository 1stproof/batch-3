Open question attempted (flagged open by this run): is there a counterexample to the headline claim among NON-finitely-generated monoids P or for higher-rank phenomena? Settle the claim (prove it, or produce a fully verified counterexample) for the following test monoids.

=== Background: what earlier work on this problem established (proofs included; re-check anything you use) ===

Notation. For a monoid P (integral, saturated, sharp, possibly not finitely generated) a "valuation" is a homomorphism v : P -> V with V valuative. For P fine, sigma = Hom(P, R_{>=0}) is the dual cone; a face of P is a submonoid F with a+b in F <=> a,b in F; P[-x]^sharp is P localized at x and then sharpened, i.e. the quotient of P[-x] by the subgroup generated by the face spanned by x.

R0 (reduction; standard). id_P is terminal in A_P^op and in B_P^op. For y = P[-x]^sharp, the slice A_P^op/y is A_y^op and B_P^op/y is B_y^op (an object P[-x']^sharp under y is y[-x']^sharp), and restriction to slices commutes with pi^{-1}, pi_*, R pi_*. Since B_P^op has the trivial topology and terminal object P, the question is equivalent to: for EVERY monoid P and every F, (i) H^0(A_P, pi^{-1}F) = F(P) via the natural map, and (ii) H^i(A_P, pi^{-1}F) = 0 for i > 0 (cohomology of the site A_P^op with the birhizomic topology, at the terminal object).

R1 (proved). If y in M, p : M -> N is infinitesimal and p(y) = 0, then y = 0. Proof: put x = -y. Then p(x) = 0 in N, -y <= x <= 0*y so x prec y, and p(y) = 0 prec 0 = p(x). Infinitesimality gives -y in M; M sharp gives y = 0. Consequently, for M valuative, f : M -> N is infinitesimal iff f^{-1}(0) = {0} (iff f^gp injective): if the kernel is trivial and f(x) in N with x notin M, then -x in M, f(-x) = -f(x) in N, N sharp forces f(x)=0, so -x = 0, contradiction. So among valuative monoids "infinitesimal" = "injective"; the quotient Z^2_lex -> Z by the convex subgroup 0 x Z is NOT infinitesimal.

R2 (proved). For every finitely presented f : P -> Q and every V, f is birhizomic at the zero map Q -> V: in a factorization P -h-> M -p-> V of 0 with p infinitesimal, R1 gives h = 0, and any u : Q -> M with pu = 0 is 0 by R1; so u = 0 exists and is unique. Likewise, P -> P[-x]^sharp is birhizomic at every g : P[-x]^sharp -> V: p(h(x)) = g(0) = 0 forces h(x) = 0, so h factors uniquely through P[-x]^sharp by its universal property (and pu = g follows by uniqueness of maps out of P[-x]^sharp). In particular the zero valuation factors birhizomically through every object of A_P.

R3 (proved; corrects an earlier heuristic). Closed charts of a subdivision of the dual cone are NOT birhizomic at valuations lying on the walls. Example: P = N^2 (basis e1,e2), Q = <e2, e1-e2> subset Z^2 (the chart of the cone spanned by (1,0),(1,1) in the subdivision of R_{>=0}^2 by the ray (1,1)), g : Q -> N with g(e2) = 1, g(e1-e2) = 0 (so v(e1) = v(e2) = 1). Let M = {x in Z^2 : x1+x2 > 0} union {0} (integral, saturated, sharp, M^gp = Z^2), h : P -> M the inclusion, p : M -> N, p(x) = x1+x2. Then ph = gf. p is infinitesimal: if p(x) >= 0, x prec y, p(y) prec p(x): when p(x) > 0, x in M; when p(x) = 0, p(y) prec 0 forces p(y) = 0, so y = 0, and x prec 0 forces x = 0. But a u : Q -> M with uf = h must send e1-e2 to e1-e2 notin M. So P -> Q is not birhizomic at g. Hence birhizomic covers are NOT (refinements of) subdivision covers by closed charts.

R4 (proved). "Open-cone" neighbourhoods are birhizomic. Let v : P -> V be a valuation, a_1,...,a_k in P^gp with v(a_i) > 0, and suppose each a_i = b_i - c_i with b_i, c_i in P and v(b_i + c_i) prec v(a_i) in V (i.e. m v(a_i) <= v(b_i+c_i) <= n v(a_i); automatic if V is archimedean, e.g. V subset R_{>=0}). Let Q be the saturation in P^gp of the submonoid generated by P and the a_i, and g : Q -> V the extension of v. Then Q is sharp (if q, -q in Q then v(q) = 0, and nq = p + sum m_i a_i with v = 0 forces all m_i = 0, so nq, -nq in P, so q = 0), and P -> Q is birhizomic at g, provided it is of finite presentation (clear if P is finitely generated). Proof: given P -h-> M -p-> V infinitesimal, x = h^gp(a_i), y = h(b_i + c_i): y - x = 2h(c_i) >= 0 and y + x = 2h(b_i) >= 0, so x prec y; p(x) = v(a_i) in V; p(y) prec p(x) by hypothesis; so x in M. M saturated gives h^gp(Q) subset M; u = h^gp|_Q works, and is unique because Q^gp = P^gp (and M^gp is torsion-free). So for a rank-one valuation v with v^{-1}(0) = 0 on fine P, the birhizomic neighbourhoods include the monoids dual to rational polyhedral cones containing v in their INTERIOR.

R5 (director's heuristic, UNVERIFIED). Picture: the birhizomic topos should be the sheaf topos of a space X_P of valuations (up to equivalence), with open sets U_Q = {v : v factors through Q and P -> Q is birhizomic there}; the stalk of pi^{-1}F at v should be colim over x in P with v(x) = 0 of F(P[-x]^sharp) (the left Kan extension to an object Q is colim over the face {x : f(x) = 0} of F(P[-x]^sharp)). The zero valuation lies in every nonempty U_Q (R2). Each face object P[-x]^sharp is an open U containing the valuations killing x. For N^2, a rank-two valuation such as v(e1) = 1, v(e2) = eps (eps infinitely small relative to 1) seems to have only neighbourhoods Q generated by P and elements a with v(a) in the archimedean class of 1 (elements whose value is infinitesimal fail the prec condition of R4), and every such neighbourhood also contains the boundary valuation w(e1) = 1, w(e2) = 0; such higher-rank points would "glue" each face to the interior. Heuristic H^0 check: for P = N^2 and F with F(P) = 0, F(ray face) = A, other values 0, a global section of pi^{-1}F vanishes near each rank-two point v as above, hence at the boundary points w those neighbourhoods contain, so H^0 = 0 = F(P) as predicted. This picture (and the role of the prec condition for higher-rank valuations) has NOT been checked.

R6 (proved, may or may not be needed). Finite-poset lemma: for a fan Sigma subdividing a rational cone sigma and r(c) = smallest face of sigma containing c, R lim over Sigma^op of G o r equals G(sigma) in degree 0 for every G : Faces(sigma)^op -> Ab (Quillen's Theorem A; the relevant comma posets {c : r(c) contains tau} are homotopy equivalent to Delta minus the faces not containing tau, which is star-shaped about a point of relint tau). Note that by R3 the closed-chart covers are not birhizomic covers, so this lemma is not directly applicable.

Expected answer so far (nobody has proved it): YES. No counterexample has been found; the cases most at risk are non-finitely-generated P (non-principal faces, e.g. P = N^(infinity) where faces like the span of infinitely many basis vectors are not of the form "face of x", irrational cones, P = Q_{>=0}^2, P valuative of rank >= 2) and the effect of higher-rank valuations.

Test cases (do them in this order; each should end in a proved verdict for H^0 and H^1 at least):
(1) P = V valuative, e.g. V = positive part of Z^2 with the lexicographic order (faces: 0, 0 x N, V; B_P has three objects). Also a valuative monoid of rank one that is not finitely generated, e.g. Q_{>=0} or Z[sqrt 2] intersected with R_{>=0}: are there nontrivial covers (note finite presentation is required of each P -> Q_i)?
(2) P = N^(infinity) (countable direct sum). Faces spanned by infinitely many basis vectors are not of the form "face of a single x", so B_P sees only the faces spanned by finite sets. Is every birhizomic cover of N^(infinity) refinable by a finite one? (Each member P -> Q_i must be finitely presented, so it only "sees" finitely many coordinates.)
(3) An irrational cone P = {(a,b) in Z^2 : a >= 0, b >= alpha a} (alpha irrational) and P = (Q_{>=0})^2: same questions.
