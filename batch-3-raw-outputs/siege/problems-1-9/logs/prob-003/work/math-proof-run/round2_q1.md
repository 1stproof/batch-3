## 0. Conventions

**Coproduct (K–S).** Δ(E_i) = E_i⊗K_i + 1⊗E_i, Δ(F_i) = F_i⊗1 + K_i^{-1}⊗F_i, and Δ(K̂_j) = K̂_j⊗K̂_j, where K_i = K̂_i K̂_{i+1}^{-1} and K̂_1⋯K̂_n = 1.

**Notation for D.** U_+ = U_q(b_+) = ⟨E_i, K̂_j^{±1}⟩. U_- = U_q(b_-) = ⟨F_i, K̂'_j^{±1}⟩. The Cartan copy inside U_- is written with primes.

**The pairing.** σ: U_+ × U_- → C, with the first argument in b_+ and the second in b_-:
- σ(K̂_i, K̂'_j) = q^{1/n − δ_ij},
- σ(E_i, F_j) = δ_ij/(q^{-1} − q),
- all other generator pairings are 0, except σ(1, ·) = σ(·, 1) = ε.

σ is assumed to be a skew pairing, that is, a pairing of U_+ with U_- in which one coproduct is replaced by its opposite. Existence and extension are cited from K–S Ch. 8, the Drinfeld/Tanisaki pairing extended to the simply-connected Cartan; this is cited, not re-proved. The only consequence used below is that σ is multiplicative in each argument on grouplikes, which gives σ(K̂_i, K_j'^{-1}) = q^{δ_ij − δ_{i,j+1}} and σ(K_i, K̂'_j) = q^{−δ_ij + δ_{i+1,j}}.

**The double.** D is the vector space U_- ⊗ U_+. Both factors are subalgebras, and the cross relation is, for u ∈ U_+ and a ∈ U_-,

  Σ σ(u_(1), a_(1)) u_(2) a_(2) = Σ a_(1) u_(1) σ(u_(2), a_(2)).   (X)

Whichever of K–S's equivalent forms is used, the check is that on generators (X) gives the correct relations (§1).

**Presentation of D (proved).** Let P be the algebra generated by the generators of U_+ and U_-, subject to the defining relations of each Borel and the relations (X) for generator pairs.
- P → D is surjective.
- Each generator relation lets one move a U_+ generator to the right of a U_- generator. So P is spanned by products (U_-)(U_+).
- The composite U_-⊗U_+ → P → D is the linear isomorphism defining D. Hence P → D is injective, so P ≅ D.

## 1. Cross relations in D (computed from (X))

- K̂_i K̂'_j = K̂'_j K̂_i.
- K̂_i F_j K̂_i^{-1} = q^{−δ_ij + δ_{i,j+1}} F_j. From (X) with a = F_j: the left side is σ(K̂_i, K_j'^{-1}) K̂_i F_j and the right side is F_j K̂_i.
- K̂'_j E_i K̂'_j^{-1} = q^{δ_ij − δ_{j,i+1}} E_i. From (X): E_i K̂'_j = σ(K_i, K̂'_j) K̂'_j E_i.
- E_i F_j − F_j E_i = δ_ij (K_i − K'_i^{-1})/(q − q^{-1}). Expanding both sides of (X) gives E_iF_j + δ_ij K_i/(q^{-1}−q) = F_jE_i + δ_ij K'_i^{-1}/(q^{-1}−q).

Each Cartan copy therefore acts on both E and F with the U_q weights. Setting K̂ = K̂' reproduces U_q^ext(sl_n).


## 3. n = 2, completely

Write K̂ = K̂_1 (so K̂_2 = K̂^{-1}, K = K̂²) and K̂' = K̂'_1.

**R-matrix.** R = q Σ e_ii⊗e_ii + Σ_{i≠j} e_ii⊗e_jj + (q − q^{-1}) Σ_{i>j} e_ij⊗e_ji. The normalisation dictated by the pairing is q^{-1/n}·R. A scalar factor does not affect the relations RLL = LLR, so it is omitted.

**Entries of RLL.** Written out,

  c_{ik} x_{ij} y_{kl} + [i>k](q−q^{-1}) x_{kj} y_{il} = c_{jl} y_{kl} x_{ij} + [l>j](q−q^{-1}) y_{kj} x_{il},

where c_{ii} = q and c_{ik} = 1 for i ≠ k. With x = y = T this gives the O_q(M_n) relations. For example, entry (11,12) gives ab = qba.

**L-matrices.**
- L^+ = [[a, b], [0, d]] with a = K̂, d = K̂^{-1}, b = (q − q^{-1}) K̂^{-1} E.
- L^- = [[a', 0], [c', d']] with a' = K̂'^{-1}, d' = K̂', c' = (q^{-1} − q) F K̂'.

**Relations:**
- (R1) R L^+_1 L^+_2 = L^+_2 L^+_1 R, which here means ab = qba, bd = qdb, ad = da.
- (R2) R L^-_1 L^-_2 = L^-_2 L^-_1 R, which here means a'c' = qc'a', c'd' = qd'c', a'd' = d'a'.
- (R3) R L^-_1 L^+_2 = L^+_2 L^-_1 R. This is the correct variant. The variant R L^+_1 L^-_2 = L^-_2 L^+_1 R gives, at entry (12,21), bc' = c'b, which is false.
- (R4) ad = 1 = a'd'.

**Checking (R3).** Its correction terms occur only at entry (i,k,j,l) = (2,1,1,2), where it reads

  bc' − c'b = (q − q^{-1})(a'd − ad').

All other entries say that each pair from {a', c', d'} × {a, b, d} commutes up to a factor:
- q a'b = b a',
- c'a = q a c',
- q c'd = d c',
- d'b = q b d',
- all other pairs commute.

Each of these is one of the §1 relations, and I checked all nine.

For the correction term:
- bc' − c'b = −(q − q^{-1})² K̂^{-1}K̂' [E, F], using that EF has weight 0 and K̂^{-1}K̂' commutes with E.
- By §1, [E, F] = (K̂² − K̂'^{-2})/(q − q^{-1}).
- So bc' − c'b = (q − q^{-1})(K̂^{-1}K̂'^{-1} − K̂K̂') = (q − q^{-1})(a'd − ad'). ✓

**Theorem (n = 2).** The algebra A generated by a, b, d, a', c', d' with relations (R1)–(R4) is isomorphic to D via the formulas above.

*Proof.*
- **Surjective:** E = (q − q^{-1})^{-1} a b and F = (q^{-1} − q)^{-1} c' d'^{-1}, so the image contains all generators of D.
- **Inverse:** D ≅ P (§0). Under the inverse substitution, every defining relation of P is equivalent to one of (R1)–(R4), by the checks above.
- The two maps are mutually inverse on generators. ∎

Combined with §2, A/⟨aa' − 1, dd' − 1⟩ ≅ U_q^ext(sl_2). This is the problem's I, with the identifications b_{ii} ↔ l^+_{ii} and c_{ii} ↔ l^-_{ii}.
