### B-1 (report round1_q1): composition rule; linear-derivation obstruction; quotients
## 1. The composition rule (proved)

Here A and B are hypersums of finitely many terms, and t is an element.

**Rule.** If 0 ∈ A⊞t and 0 ∈ B⊞(−t), then 0 ∈ A⊞B.

*Proof.*
1. From 0 ∈ A⊞t there is an a ∈ A with 0 ∈ a⊞t. By uniqueness of negatives, a = −t, so −t ∈ A.
2. In the same way, from 0 ∈ B⊞(−t) we get t ∈ B.
3. Since 0 ∈ (−t)⊞t, it follows that 0 ∈ A⊞B. ∎

There is also a weakening step: 0 ∈ C⊞a⊞(−a) holds for every element a and every sum C, so it carries no information.

**What the rule does not give.** You cannot cancel a pair a, −a that sits inside a single relation: from 0 ∈ C⊞a⊞(−a) you cannot conclude 0 ∈ C. This is exactly where the field proof breaks down.

## 2. Obstruction for "linear" proofs (proved)

**Admissible derivations.** Call a derivation admissible if it uses only:
- the relations R_w : 0 ∈ wx⊞wy⊞(−w), for monomials w = ±xⁱyʲ (these come from distributivity applied to 0 ∈ x⊞y⊞(−1));
- the composition rule of §1.

**Term count.** Composing k such relations needs k−1 cancellations. Each cancellation removes 2 terms, so the result has 3k − 2(k−1) = k+2 terms, counted with multiplicity.

**Claim.** The target relation 0 ∈ x³⊞y³⊞xy⊞xy⊞xy⊞(−1) has 6 terms, so an admissible derivation would need exactly k = 4 relations. Taking x, y to be formal monomials, no choice of 4 relations works.

*Proof.* Treat x, y as formal monomials, i.e. as independent indeterminates with no relations among their monomials.
1. **Which relations are forced.**
   - The term −1 can only come from R_1. Its terms are x, y, −1.
   - The term x³ can only come from R_{x²}. Its terms are x³, x²y, −x².
   - The term y³ can only come from R_{y²}. Its terms are xy², y³, −y².
2. **No cancellation among these three.** None of the nine terms of R_1, R_{x²}, R_{y²} is the negative of another of them, formally.
3. **The fourth relation is too small.** The single remaining relation would therefore have to supply all 3 cancellations, one for each of its 3 terms. That would remove 3 of the 6 unwanted terms x, y, x²y, −x², xy², −y².
4. **Conclusion.** At least 3 unwanted terms survive, and no xy term is produced at all. So no admissible derivation exists. ∎

**Consequence.** The field identity has no "tree-shaped" realization.
- A natural field derivation uses x² = x − xy and x³ = x − xy − x²y, and then the step x²y + xy² = xy.
- That last step needs the *set* x²y⊞xy² to be contracted to its element xy.
- Hyperfield membership only allows replacing an element by a set that contains it, never contracting a set to one of its elements.

Any affirmative proof must therefore use extra elements of H: auxiliary witnesses c taken from sums such as 1⊞1 or x⊞(−xy), together with relations satisfied by those witnesses. Arbitrary hyperfields need not have such relations. This, together with (B3), is evidence that the answer may be NO. It is only evidence, and it conflicts with the unrefereed computer search reported in (B5).

### B-2 (report round1_q3): diagonal case and witness expansion
## Basic tool (proved)
If a ∈ S (a hypersum) then any multi-sum containing a as one summand is contained in the same multi-sum with S in place of a. This holds by associativity and because sums are unions over choices. It follows that replacing one summand c by a set that contains c can only shrink the target. That is the wrong direction for a proof, but it is used below in the following form: if c ∈ (p ⊞ q), then (… ⊞ p ⊞ q) ⊇ (… ⊞ c).

## Proposition 1 (diagonal case, proved): if 1 ∈ x ⊞ x, then 1 ∈ x^3 ⊞ x^3 ⊞ x^2 ⊞ x^2 ⊞ x^2.
Proof.
1. Multiplying 1 ∈ x ⊞ x by x^2 gives x^2 ∈ x^3 ⊞ x^3.
2. Therefore x^3 ⊞ x^3 ⊞ x^2 ⊞ x^2 ⊞ x^2 ⊇ x^2 ⊞ x^2 ⊞ x^2 ⊞ x^2, choosing x^2 from x^3 ⊞ x^3.
3. Multiplying by x gives x ∈ x^2 ⊞ x^2, so x^2 ⊞ x^2 ⊞ x^2 ⊞ x^2 ⊇ x ⊞ x.
4. Since 1 ∈ x ⊞ x, the target contains 1. ∎

## Proposition 2 (expansion, proved): 1 ∈ x^3 ⊞ y^3 ⊞ xy ⊞ xy ⊞ w for some w ∈ xy(x ⊞ y).
Proof.
1. From 1 ∈ x ⊞ y we get x ∈ x^2 ⊞ xy and x^2 ∈ x^3 ⊞ x^2y, so x ∈ x^3 ⊞ x^2y ⊞ xy.
2. Similarly y ∈ y^3 ⊞ xy^2 ⊞ xy.
3. Hence 1 ∈ x ⊞ y ⊆ x^3 ⊞ y^3 ⊞ xy ⊞ xy ⊞ (x^2y ⊞ xy^2), and x^2y ⊞ xy^2 = xy(x ⊞ y). ∎

So the implication holds whenever this witness can be taken to be w = xy, i.e. whenever the element u ∈ x ⊞ y used here can be taken to be 1. In particular it holds whenever x ⊞ y = {1}. For example, this covers hyperfields in which x ⊞ y is a singleton for this pair.

## 2. Linear derivations fail in the exponent-3 class (proved)

**Admissible moves.** Only the following moves are allowed:
- the relations 0 ∈ mx ⊞ mx² ⊞ mw, for monomials m = x^i w^j;
- the pairs 0 ∈ a⊞a;
- disjoint union of zero-sums (if 0 ∈ A and 0 ∈ B then 0 ∈ A⊞B);
- composition (B5), which cancels one shared term between two different components.

Cancelling a term inside a single component is not allowed (see B5).

**Claim.** In the generic situation, where the 9 monomials x^i w^j are distinct, no such derivation produces 0 ∈ 1⊞1⊞1⊞w⊞w⊞w. (Specific Δ might create extra coincidences among the monomials; that case is not covered.)

**Proof.**

*Step 1 (counting).* A component built from n triangles linked in a tree has n+2 remaining terms. A pair component has 2 terms. Attaching a pair to an existing term changes nothing, because 0∈A⊞a together with 0∈a⊞a gives back 0∈A⊞a. To get 6 terms, the possible shapes are:
- (i) a single tree of 4 triangles;
- (ii) a tree of 2 triangles plus one pair;
- (iii) two separate triangles.

*Step 2 (shapes (ii) and (iii)).* Each triangle has 3 distinct terms. Shape (ii) would need three equal leftover terms from two triangles; shape (iii) would need a triangle {1,1,w} or {1,w,w}. Both are impossible.

*Step 3 (shape (i), reduction to the group ring).* Reduce mod 2 in R = F_2[x,w]/(x³−1, w³−1) ≅ (F_2 × F_4)⊗(F_2 × F_4). Let f be the sum of the four chosen m's. Then f·(x+x²+w) = 1+w + 2(cancelled pairs) ≡ 1+w.

*Step 4 (solving at x = 1).* At x = 1 we have x+x² = 0. The equation becomes f(1,w)·w = 1+w, so f(1,w) = 1+w².

*Step 5 (solving at x = ω).* At x = ω we have x+x² = 1. The equation becomes f(ω,w)(1+w) = 1+w, so f(ω,w) ≡ 1 mod (1+w+w²).

*Step 6 (all solutions).* Write f = a + b w + c w². The conditions give a = 1, b = 0, c = 1+x+x², up to the kernel, which is h(x)(1+w+w²) with h ∈ {0, x+x², 1+x, 1+x²}. So the solutions are

f = 1 + (1+x+x²)w² + h(x)(1+w+w²).

The 4-term solutions include:
- {1, w², xw², x²w²};
- x + (1+x)w + x²w², i.e. {x, w, xw, x²w²}.

*Step 7 (checking multiplicities).* Expand the integer multiset of terms for either 4-term solution. It contains 1 and w exactly once each, and five other monomials exactly twice each. For example, the first solution gives x, x², xw², x²w², w² twice each. The target 1,1,1,w,w,w needs coefficient 3 on both 1 and w. Moreover, 3 tree edges can cancel only 3 of the 5 doubled pairs. So shape (i) fails as well. ∎

**Interpretation.** Unlike the generic case (B6), the mod-2 equation is solvable here. The obstruction comes from the integer multiplicities and the tree structure, not from parity. An affirmative proof would need witnesses from D = (1⊞1)\{0} or other auxiliary elements.


### B-6 (report round3_q2): with -1 = 1, exchanges are compositions; no linear derivation proves (C)
## 1. Exchanges are compositions

Assume -1 = 1. By (B11)(c), "0 ∈ a⊞b⊞c⊞e" holds iff (a⊞b)∩(c⊞e) ≠ ∅, and this relation is symmetric in a, b, c, e.

A 4-point exchange only re-reads this symmetric relation. The only way to *produce* a new 4-term (or longer) relation from triangles is to glue two relations along a shared element t. This is the composition rule (B5): from 0∈A⊞t and 0∈B⊞t, conclude 0∈A⊞B (here -t = t).

So a chain built only from the hypothesis triangles {g, gx, gy} (all g ∈ G, coming from y ∈ 1⊞x), using exchanges, is a "linear derivation" in the sense of (B6).

## 2. Proposition: no linear derivation proves (C) when -1 = 1

**Claim.** No linear derivation proves (C).

**Proof.**
1. Suppose a derivation glues k relations R_w = {w, wx, wy} (monomial labels w; repeats allowed) into a tree with k-1 gluings.
2. Each gluing removes 2 terms. The relations contribute 3k terms, so the final sum has 3k - 2(k-1) = k + 2 terms.
3. The target 0 ∈ 1⊞x^3⊞y^3⊞xy has 4 terms, so k = 2.
4. Two relations R_w and R_{w'} share a term only if w' ∈ {wx, wy, wx^{-1}, wy^{-1}, wxy^{-1}, wyx^{-1}}. Gluing them leaves 4 terms of the form w·{…}.
5. For the result to equal {1, x^3, y^3, xy} as monomials, the exponents would have to match. Checking all 6 cases, none does: the glued 4-sets have total degree spread at most 2, but {1, x^3} has spread 3.

So the derivation is impossible. ∎

**Why the field proof does not transfer.** Over F_2 one has 1+x^3+y^3+xy = (1+x+y)(1+x+y+x^2+xy+y^2). This combines the six relations R_1, R_x, R_y, R_{x^2}, R_{xy}, R_{y^2}, which have 18 terms. Reaching 4 terms needs 7 cancelled pairs, but a tree on 6 relations allows only 5 gluings. Closing the extra cycles would need the inference "0∈C⊞a⊞a ⇒ 0∈C", which is invalid in hyperfields.

The same argument covers the weaker target 1∈T, with T = x^3⊞y^3⊞xy⊞xy⊞xy. That target has 6 terms, so k = 4. The 12 terms of four relations, glued in a tree, would have to give exactly {1, x^3, y^3, xy, xy, xy}. The coefficient polynomial would have to be a degree-2 multiple of (1+x+y) matching the field identity, which needs 6 relations, not 4. So this is impossible too, as in (B6).

**Consequence.** Any affirmative proof must use auxiliary existential elements, such as d ∈ (1⊞1)\{0} or witnesses u ∈ x⊞y with u ≠ 1, together with the axioms they satisfy. Exchange chains alone, which are idea (a) of the task, cannot work.


### B-7 (report round3_q4): class a⊞-a = H with -1 ≠ 1, coincidences; union-type hyperfields satisfy the claim
## 1. Coincidences in the class a ⊞ -a = H (proved)

Let H be a hyperfield with a ⊞ -a = H for every a ≠ 0.

**Lemma 1.** Let S be a multi-sum whose summands include two nonzero opposite elements a and -a. Then S = H.

*Proof.* Write S = (a ⊞ -a) ⊞ R = H ⊞ R. We have H ⊞ r = H for every element r: given h, pick h' ∈ h ⊞ -r; by reversibility h ∈ h' ⊞ r. Applying this to each summand of R gives S = H. ∎

**Corollary.** If two of the summands of T ⊞ (-1) are opposite, namely the summands x^3, y^3, xy, xy, xy, -1, then T ⊞ (-1) = H ∋ 0 and the claim holds. So the claim holds whenever one of the following holds:
- x^3 = -y^3,
- x^3 = 1 or y^3 = 1 (opposite to -1),
- xy = 1,
- xy = -x^3, i.e. y = -x^2,
- xy = -y^3, i.e. x = -y^2,
- xy = -xy, which is impossible because -1 ≠ 1.

Only the "generic" case remains, where none of these coincidences occurs. In that case xy ⊞ xy does not contain 0, because 0 ∈ a ⊞ a forces a = -a. So nothing more can be extracted from Lemma 1. I could not settle this generic case.

## 2. A natural family in this class satisfies the claim (proved)

**Construction.** Let G be any abelian group containing an element -1 of order 2. Put H = G ∪ {0}, with 0 neutral, and for nonzero a, b define:
- a ⊞ b = {a, b} if b ≠ -a (in particular a ⊞ a = {a});
- a ⊞ -a = H.

**Claim.** H is a hyperfield.

*Proof.* Every multi-sum is computed as follows. If the nonzero summands contain an opposite pair, the sum is H. Otherwise it is the set of the distinct nonzero summands, or {0} if every summand is 0. This rule gives the same set under every bracketing, so ⊞ is associative. It is also commutative.

Reversibility: suppose c ∈ a ⊞ b with a, b ≠ 0.
- If b = -a, then c is arbitrary, and a ∈ c ⊞ a in each subcase c = 0, c = a, c = -a, or c generic, where c ⊞ a = {c, a}.
- If b = a, then c = a, and a ∈ a ⊞ -a = H.
- Otherwise c ∈ {a, b}. If c = a, then a ∈ a ⊞ -b = {a, -b}. If c = b, then a ∈ b ⊞ -b = H.

The cases where a or b is 0 are trivial. Distributivity holds because multiplication by w maps opposite pairs to opposite pairs. ∎

The sign hyperfield is the case G = {±1}.

**Claim.** The implication holds in this H.

*Proof.* Suppose 1 ∈ x ⊞ y with x, y ≠ 0. Then either y = -x or 1 ∈ {x, y}.
- If y = -x, then x^3 and y^3 are opposite, so T = H.
- If x = 1 or y = 1, then 1 is a summand of T. So T is either H or the set of its summands, and either way 1 ∈ T. ∎

So "union-type" hyperfields in this class satisfy the claim. A counterexample must have sums that are genuinely larger than the set of summands but smaller than H.


## Part C. Computational evidence (unrefereed) and coordinator observations

(C1) Exhaustive computer search over all hyperfields H = G ∪ {0} with |G| ≤ 9 (every abelian group of order ≤ 8, plus Z9 and Z3×Z3) found no counterexample. Any counterexample has at least 11 elements.

(C2) Exponent-3, characteristic-2 triangle systems (the class of (A4)/(A5), in the additive notation of B-5). The coordinator ran exhaustive constraint searches for counterexamples, i.e. structures with a triangle {x, x^2, w} and Q ∩ wQ = ∅. None was found:
- on F_3^3, among systems invariant under translations and under v ↦ −v;
- on F_3^3, among systems invariant under multiplication by the order-13 subgroup of F_27^*;
- on F_3^4, among systems invariant under multiplication by F_81^*.

In every non-field associative system the coordinator enumerated with 1 ∉ 1⊞1 (F_3^2 and F_3^3 with various multiplicative symmetries), Q = 1⊞1⊞1 contained all of G, so the claim held trivially. A counterexample in this class needs Q ∩ wQ = ∅, hence |Q| ≤ |G|/2. That requires a "sparse" structure, which small groups do not admit. Any counterexample in this class must live on a larger group F_3^k (k ≥ 5, or infinite rank) and have small sums.

(C3) Krasner extensions (-1 = 1 and a⊞a = {0, a}) correspond to projective geometries with point set G, on which G acts regularly by multiplication; here a⊞b is the line through a and b with a and b removed, for a ≠ b. In this class the claim becomes an incidence statement. All known such geometries are Desarguesian, hence quotients, hence satisfy the claim. So this class was judged unpromising, but it has not been refuted as a source of counterexamples.

(C4) Free-hyperfield reformulation (coordinator's observation, not refereed). Build a hyperfield "freely" from generators x, y and the single relation 1 ∈ x⊞y, by a chase: repeatedly add every membership forced by distributivity, commutativity and reversibility, and for every associativity instance and every empty sum add a fresh group generator as witness. If the resulting limit is a hyperfield (a statement still to be checked), then it maps to every hyperfield containing such x, y by a membership-preserving map. The question is then equivalent to whether 1 ∈ T holds in this free object. A counterexample amounts to an invariant of the chase steps that the target violates.
