## Candidate curve (conjectured, not proved here)
Use the normalization of item (2) with a real base parameter t in (0,1/2), so that 0 = a_0 < t = a_3 < 1/2 < 1 = a_2, a_1 = ∞, and v(t) real. Take γ to be the boundary of a thin neighborhood of an arc from v to a_1 = ∞ that, instead of following the real line (the arc whose twist is the cusp monodromy x_{1/2} = T_{γ0}, item (4)), first goes once around a_0 and a_3. Equivalently γ = h(γ0), where h = T_c^2 and c is the curve enclosing {a_0, a_3} along [0,t]. Since T_c^2 is the t = 0 cusp monodromy up to the v-correction, it lies in G, so by item (6) γ has the 3/0 split and T_γ = h T_{γ0} h^{-1} ∈ G (so k = 1 suffices). This gives (c) for this γ, modulo the item-(4) identification.

I recall from memory, without being able to check it, that Hironaka and Koch ("A disconnected deformation space of rational maps") treat exactly this example and show that D_f has infinitely many components, using a Dehn twist of this kind. I cannot reconstruct their curve precisely, so the description above is my own candidate and not a citation.

## What is proved here
- Items (1), (5), (6) as given: for any 3/0 curve γ around {a_1, v}, T_γ ∈ G, and the orbit of D_0 under ⟨T_γ⟩ is infinite if and only if T_γ^n ∉ K for every n ≠ 0 (item 7).
- Negative observation: for curves around {v, a_j} with j ∈ {0, 2, 3}, the quotients F/⟨⟨ℓ_1⟩⟩ and its mod-2 homology cannot separate T_γ^2 from K, because both are generated by conjugates of the squares ℓ_j^2. So that family needs a finer invariant.
