## 1. Step 1: the Serre-type lemma for stable curves (PROVED)

**Setting.** C a stable curve of genus g >= 2 with dual graph G (vertex weights g_v, edges = nodes), Ĉ_v the normalisation of the component v (compact, with its special points = node branches). C_s a nearby smooth fibre, c: C_s -> C the collapse map contracting the vanishing cycles c_e. Every σ ∈ Aut(C) lifts to a homeomorphism σ̃ of C_s with c∘σ̃ = σ∘c, well defined up to products T of Dehn twists about the c_e (and isotopy). G_m(C) := {σ : some σ̃∘T acts trivially on H_1(C_s; Z/m)}.

**Theorem 1 (level-m kills all automorphisms of stable curves).** If m >= 3, then G_m(C) = {id}. In particular: (a) no σ ∈ G_m(C) moves any irreducible component, of any genus; (b) no automorphism exchanging two twin components x, αx (of any genus, including genus 0) lies in G_m(C); (c) every σ ∈ G_m(C) is the identity on every component.

(Consistent with Ivanov's theorem, cited from memory: for m >= 3 every element of the level subgroup Γ_g[m] is pure; the proof below is self-contained.)

*Proof.* Let σ ∈ G_m(C), f = σ̃∘T trivial on H_1(C_s; Z/m).

*Step (i): σ acts trivially on H_1(C; Z).* T̃ is supported in collars of the c_e, and c maps each collar into a contractible neighbourhood of a node; so c∘T̃ ≃ c rel the complement of the collars, hence c_* ∘ f_* = σ_* ∘ c_* on H_1. Since c_*: H_1(C_s; Z) -> H_1(C; Z) is surjective (C is C_s with circles collapsed), σ_* ≡ id on H_1(C; Z/m) = H_1(C;Z) ⊗ Z/m (H_1(C;Z) is free). σ has finite order, so σ_* ∈ GL(H_1(C;Z)) is of finite order and ≡ I mod m; for m >= 3 the kernel of GL_n(Z) -> GL_n(Z/m) is torsion free (Minkowski/Serre, classical), so σ_* = id on H_1(C; Z).

*Step (ii): the weight pieces.* There is the standard exact sequence 0 -> ⊕_v H_1(Ĉ_v; Z) -> H_1(C; Z) -> H_1(G; Z) -> 0 (C is homotopy equivalent to the disjoint union of the Ĉ_v with an arc joining the two branches of each node), and it is σ-equivariant (σ acts on G by the induced graph automorphism, also written σ). Hence:
- σ = id on H_1(G; Z) = Z_1(G; Z) ⊂ C_1(G; Z) (in a graph there are no 2-chains, so homology classes are cycles): **σ(γ) = γ as a chain for every integral 1-cycle γ.**
- σ = id on ⊕_v H_1(Ĉ_v; Z). Since σ maps H_1(Ĉ_v) onto H_1(Ĉ_{σv}), and these summands are independent, **σ(v) = v for every vertex with g_v >= 1.**

*Step (iii): σ fixes the dual graph (combinatorial lemma).* 
**Lemma G.** Let G be a finite connected graph (loops, multi-edges allowed) with weights g_v >= 0, stable (every v with g_v = 0 has valence >= 3, loops counted twice; every v with g_v = 1 has valence >= 1, since g >= 2), and σ an automorphism of G fixing all vertices of positive weight and with σ(γ) = γ for every γ ∈ Z_1(G;Z). Then σ fixes every vertex, maps every edge to itself, and preserves the orientation of every non-bridge edge.

*Proof.* (1) Blocks. Decompose G into blocks (maximal 2-connected subgraphs, bridges = K_2-blocks, a loop is its own block). Let B be a block containing a cycle. For any simple cycle γ ⊂ B (a chain with coefficients ±1), σγ = γ as chains forces σ to map the edges of γ to edges of γ preserving the cyclic orientation. So σ(B) = B and σ preserves each simple cycle of B with orientation.
 - If B is not itself a simple cycle: call edges e, e' of B *in series* if every cycle through e passes through e'. Since σ(e) lies on every cycle through e, σ(e) is in series with e. Series classes in a 2-connected graph which is not a cycle are the edge sets of maximal paths P (from branch vertex a to branch vertex b, inner vertices of degree 2 in B). σ maps P to itself (as the class of e is preserved) and preserves the direction of traversal (orientation coefficients of the cycle chains), so it fixes the initial vertex a, hence is the identity on P. So σ is the identity on B (vertices and oriented edges).
 - If B is a simple cycle (including a loop, or two parallel edges), σ acts on B as an orientation-preserving rotation; so if σ fixes one vertex of B, σ is the identity on B (with orientations). A loop block has one vertex and its edge is preserved with orientation.
(2) The block–cut tree T (nodes = blocks and cut vertices). σ acts on T. If T has a single node, G is one block: a K_2 (both vertices of valence 1, so positive weight, fixed), a simple cycle (all vertices of valence 2, so positive weight, fixed; a single vertex with one loop has g_v >= 1), or a non-cycle 2-connected graph (identity by (1)). Otherwise T has >= 2 leaves, all of which are blocks L with exactly one cut vertex c_L. For a leaf block L: if L = K_2 its other vertex has valence 1, so positive weight, so fixed; if L is a simple cycle, its non-cut vertices have valence 2 in G so positive weight and are fixed (if L is a loop or 2-cycle on c_L plus ..., in any case σ(L) = L and σ(c_L) = c_L since c_L is the unique cut vertex of L); if L is not a cycle it is fixed pointwise by (1). So σ fixes every leaf of T. A tree automorphism fixing two leaves fixes the path between them pointwise, and every node of a finite tree with >= 2 nodes lies on such a path. So σ fixes every block and every cut vertex. Then every block is fixed pointwise: K_2-blocks (their vertices are cut vertices or valence-1 vertices of positive weight), cycle blocks (they contain a fixed cut vertex, so the rotation is trivial), non-cycle blocks (by (1)). ∎

*Step (iv): σ fixes every node branch.* For an edge between distinct vertices, both endpoints are fixed, so both branches are fixed. For a loop at v, σ preserves its orientation, i.e. does not swap the two branches. (Every half-edge is therefore fixed.)

*Step (v): σ|_{Ĉ_v} = id for every v.* σ|_{Ĉ_v} is an automorphism of the compact curve Ĉ_v fixing all its special points and acting trivially on H_1(Ĉ_v; Z) (step (ii)).
- g_v >= 2: an automorphism of a compact Riemann surface of genus >= 2 acting trivially on H_1(Z) (a fortiori trivially on H_1(Z/m), m >= 3) is the identity (Serre's lemma / Hurwitz–Lefschetz, classical, cited from memory).
- g_v = 1: acting trivially on H_1 means σ|_{Ĉ_v} is a translation; it fixes a special point (v has valence >= 1 because g >= 2 and C is connected), so it is the identity.
- g_v = 0: it fixes >= 3 points of P^1, so it is the identity.
Hence σ = id. ∎

**Corollary 1 (local structure of M̄_g[m], m >= 3).** Let P̃ ∈ M̄_g[m] lie over [C]. Let Π_C be the orbifold fundamental group of U° = (Def(C) ∖ D)/Aut(C) (D = {∏ s_e = 0}), an extension 1 -> Z^E -> Π_C -> Aut(C) -> 1 whose elements are the σ̃∘T. So the answer to step 1 of the route is that σ ∈ G_m(C) iff σ = id. No automorphism preserving a level structure exchanges twins, of positive genus or of genus 0. **Corollary 2 (labels are global on level strata).** Let f ∈ Γ_g[m], m >= 3, preserve a multicurve C (up to isotopy). Then the induced automorphism of the dual graph G of (S, C) is the identity, fixing all half-edges. *Proof.* Same as steps (ii)–(iv) of Theorem 1: f preserves the weight filtration W_{-2} = span(c_e) ⊂ W_{-1} = W_{-2}^⊥ ⊂ H_1(S), with gr_{-1} = ⊕ H_1(Ĉ_v), gr_0 = H_1(G); f ≡ id mod m on all pieces; the induced graph automorphism has finite order, so (Minkowski) it is the identity on H_1(G;Z); f moves no positive-genus vertex (gr_{-1}); Lemma G. ∎ Consequently, over every connected component of p^{-1}(Δ_G) ⊂ M̄_g[m] (p: M̄_g[m] -> M̄_g), the vertices and half-edges of G are globally and consistently labelled: the monodromy of the components of the universal stable curve along any loop in the stratum is trivial.

*Proof.* (a) By Theorem 1, Π_Q ∩ Γ_g[m] = Λ ⊂ Z^E; so Ũ° -> U° is the covering of U° attached to Λ ⊂ Π_Q, which factors through the covering Def(Q)° = B° -> U° attached to Z^E ⊂ Π_Q; Ũ° -> B° is Galois with group Z^E/Λ = T, and Ũ -> B is its normalisation, branched only over D. ### 2.2 Proposition L1 (lifted triviality forces isotropy preservation) — proved
Suppose H lifts near Q̃: there are ε > 0, a neighbourhood Ũ_0 ⊂ Ũ of Q̃, an open neighbourhood W of (Q̃,0) in (p×id)^{-1}(closure 𝒱), and a homeomorphism Ĥ: (p^{-1}(closure V_0) ∩ Ũ_0) × Δ_ε -> W commuting with the projections to Δ_ε, with Ĥ_0 = id and (p×id)∘Ĥ = H∘(p×id). Then **|Aut(H_t(P))| = |Aut(P)| for all P ∈ closure(V_0) near Q and all small t; in particular |Aut(Q_t)| = |Aut(Q)| for small t, i.e. (IP) holds at Q.**

*Proof.* Fix P ∈ closure(V_0) ∩ p(Ũ_0) and t small. Ĥ_t maps the finite set A := p^{-1}(P) ∩ Ũ_0 injectively into p^{-1}(H_t(P)). Conversely, if y ∈ p^{-1}(H_t(P)) with (y,t) ∈ W, then Ĥ^{-1}(y,t) = (z,t) with p(z) = H_t^{-1}(H_t(P)) = P, so z ∈ A. All points of p^{-1}(H_t(P)) ∩ Ũ converge to p^{-1}(P) ∩ Ũ as t -> 0 (properness), so for P = Q (where A = {Q̃}), and t small, they all lie in W; hence #(p^{-1}(Q_t) ∩ Ũ) = 1, and by L2(c) |Aut(Q_t)| = |Aut(Q)|. For general P near Q, apply the same argument at P (with Q̂ replaced by points of A, after shrinking) and L2(c), using that H_t preserves strata so the twist factors cancel. ∎

By R8-8 Corollary 1(a) (the run's result, which I re-checked: under (IP) the lift of Q_t is unique, so both transport closures contain it), (IP) at Q gives star coherence (SC) at Q; the run lists "(SC)/(NT)/(IP)" among the conditions under which MS10 holds (R8-8 Theorem 1; round9_q6 Cor. 3′). So **lifted triviality near Q ⟹ (IP) at Q ⟹ the already-known sufficient condition.** The level route therefore yields nothing beyond the orbifold reading (R2^orb) already recorded in R8-8 §3.

### 2.3 What lifts and what does not (answers to step 2 of the route)
- Lifts: (p×id)^{-1}(closure 𝒱) is a closed analytic set, proper over Δ (p is finite), with fibres p^{-1}(closure V_t); boundary strata and pieces lift; interior paths γ_n in q^{-1}(V_0) ∩ B lift to Ũ° (through λ, which is unbranched over B°); transport families lift as sets (components of preimages), carrying the same label data (L2(d)).
- Does not lift in general: H. By L1, a lift compatible with H exists near Q̃ only if |Aut| is preserved by H_t near Q; the problem explicitly allows H_t not to preserve automorphism groups, and the run's Proposition 3 (R8-8 §4) / Prop. D (R8-5) show that MS10 can fail only if |Aut(Q_t)| < |Aut(Q)|. So **lifted triviality fails exactly in (indeed is already excluded by) every potential counterexample configuration**: the defect is not a technicality of the route but the whole content of MS10.
- An abstract (not H-compatible) topological trivialisation of (p×id)^{-1}(closure 𝒱) -> Δ exists over Δ minus a discrete set (Thom–Mather first isotopy lemma applied to a Whitney stratification of the proper analytic map refining strata and isotropy types; cited from memory), but t = 0 may be one of the exceptional values, and an abstract trivialisation does not carry the t = 0 data (total geodesy, the joined paths γ_n) to t ≠ 0 compatibly with H. Since total geodesy is available only at t = 0, the base point cannot be moved to a generic time.
- **Identification of the defect with the round9_q5 obstruction.** The ramification locus of (p×id)^{-1}(𝒱) ∩ (Ũ×Δ) -> 𝒱 ∩ (U×Δ) is the image of ⋃_{α ∈ 𝔅∖{1}} Fix(α) ∩ q^{-1}(𝒱), with inertia over α. The failure of (IP) at Q means: some α ∈ Aut(Q) with α ∉ Aut(Q_t) for t ≠ 0. The failure of MS10 additionally requires (R8-5 Prop. D; round9_q5) such an α moving x whose fixed locus in the 3-fold track component has a component of dimension >= 2 (or the arc case (C)) accumulating at (Q,0): i.e. **a ramification divisor of the level cover of 𝒱 (α-symmetric curves of V_τ, τ ≠ 0) through (Q,0) whose limit at τ = 0 is not compatible with H_0 = id.** This is the same object as round9_q5's bad locus; the level cover only renames it.

## 3. Step 3: conclusion of the route

- The route's step 3 ("upstairs, twins are not exchanged by the local group; then the no-twin transport theorems apply") does not go through: by Proposition L2 the deck stabiliser 𝔖 of Q̃ surjects onto Aut(Q) and acts on labels exactly as Aut(Q) does on Def(Q). Theorem 1 kills only automorphisms preserving a level structure, and the coarse normalisation M̄_g[m] does not retain a level structure at Q̃. The only way to make the transport theorems apply upstairs is lifted triviality, and by Proposition L1 that already implies (IP) at Q, which was known (R8-8 Cor. 1(a) + Theorem 1) to suffice without any level structure.
- Pushing down: nothing new to push down.
- Genus 0: needs no separate treatment either way. Theorem 1 covers genus-0 twins as well, and the obstruction in L2 does not depend on the genus.
- No counterexample is produced. Constructing one would require a family V_t (with V_0 smooth and totally geodesic) whose boundary point Q loses an automorphism exchanging twin Y_0-copies for t ≠ 0, with persistent twins as in R8-8 Prop. 3. That is beyond reach here, as it is in the earlier rounds (R7-3 §5 gives only a chart-local model).

## 4. Summary: proved / not proved / open

2. Corollary 2: for m >= 3, an element of Γ_g[m] preserving a multicurve acts trivially on the dual graph, half-edges included (a form of Ivanov's purity, proved here directly for the dual-graph part).
