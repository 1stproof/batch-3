## 1. Intrinsic special sets

Notation. For t ∈ Δ, B_t = closure(V_t) ∩ ∂M̄_g. For a point w ∈ M̄_g, G_w is its dual graph (so w ∈ Δ_{G_w}). For 0 < r ≤ 1,

 ℬ_r := ⋃_{|t|<r} B_t × {t} = closure(𝒱) ∩ (∂M̄_g × Δ_r).

**Classical facts used (cited from memory).**
- (F1) For a compact complex-analytic set C, the singular locus Sing(C) is a closed analytic subset that is nowhere dense in C. C has finitely many irreducible components. A compact analytic set of dimension 0 is finite. In particular C has only finitely many isolated points.
- (F2) Let C be an analytic set and W ⊂ C a closed analytic subset. Then closure(C ∖ W) is the union of the irreducible components of C not contained in W (it is analytic).
- (F3) An irreducible compact analytic curve minus finitely many points is connected. (Its normalisation is a compact connected Riemann surface, and removing finitely many points keeps it connected.)
- (F4) Lemma 0.1 of the task file: Z_k = {|Aut| ≥ k} is closed analytic in M̄_g. |Aut| is upper semicontinuous, hence bounded on the compact M̄_g, so only finitely many k are relevant.
- (F5) C2: closure(Δ_G) is closed algebraic, and closure(Δ_G) ∖ Δ_G is a closed algebraic union of strata. M̄_g has finitely many strata.

**Lemma 1.0 (basic properties of B_t).** For every t:
- H_t restricts to a homeomorphism B_0 → B_t with H_t(B_0 ∩ Δ_G) = B_t ∩ Δ_G for every boundary stratum G;
- B_t is a compact analytic set of dimension ≤ 1;
- H restricts to a homeomorphism B_0 × Δ → ⋃_t B_t × {t}.

*Proof.*
- By (R2), H is a homeomorphism over Δ. So H_t : closure(V_0) → closure(V_t) is a continuous bijection of compact Hausdorff spaces, hence a homeomorphism.
- It maps closure(V_0) ∩ Δ_G onto closure(V_t) ∩ Δ_G for every stratum G, including the open one. Hence it maps B_0 onto B_t, and B_0 × Δ onto ⋃ B_t × {t}.
- B_t = closure(V_t) ∩ ∂M̄_g is compact and analytic by (R1).
- dim B_0 ≤ 1: closure(V_0) is irreducible of dimension 2 (V_0 is smooth and connected, hence irreducible), and B_0 is a proper analytic subset of it, since V_0 ≠ ∅.
- B_t is homeomorphic to B_0. The complex dimension of an analytic set is half its topological dimension. So dim B_t ≤ 1. ∎

**Definition 1.1 (topologically special points).** A point w ∈ B_t is *top-regular* if it has an open neighbourhood U in B_t with U ⊂ Δ_{G_w} and U homeomorphic to ℝ². Otherwise w is *top-special*. Write:
- Σ^top_t for the set of top-special points;
- R_t := B_t ∖ Σ^top_t, which is open in B_t and is a topological surface.

On R_t the stratum is locally constant, so each connected component of R_t lies in a single stratum.

**Definition 1.2 (isotropy-special points).** I_t is the set of w ∈ R_t at which the function |Aut| restricted to R_t is not locally constant. Put Σ_t := Σ^top_t ∪ I_t (a disjoint union).

These definitions use only B_t (that is, closure(𝒱)), the stratification and |Aut|.

**Lemma 1.3 (invariance).** Let h : B_0 → B_t be a homeomorphism with h(B_0 ∩ Δ_G) = B_t ∩ Δ_G for all G. Then h(Σ^top_0) = Σ^top_t and h(R_0) = R_t. If moreover |Aut h(w)| = |Aut w| for all w ∈ B_0, then also h(I_0) = I_t and h(Σ_0) = Σ_t.

*Proof.*
- h preserves the stratum of each point: G_{h(w)} = G_w.
- If U is a neighbourhood of w as in Definition 1.1, then h(U) is an open neighbourhood of h(w), homeomorphic to ℝ² and contained in Δ_{G_w} = Δ_{G_{h(w)}}. So h maps top-regular points to top-regular points. The same argument for h^{-1} gives the converse.
- Hence h(R_0) = R_t, and h|_{R_0} : R_0 → R_t is a homeomorphism.
- If h preserves |Aut|, then |Aut|∘h = |Aut| on R_0. So |Aut| is locally constant on R_t at h(w) iff it is locally constant on R_0 at w. ∎

**Lemma 1.4 (finiteness).** For every t, Σ_t is finite and R_t has finitely many connected components.

*Proof.* Fix t and write B = B_t. For a boundary stratum G put C_G := B ∩ closure(Δ_G) (compact analytic) and A_G := B ∩ Δ_G.

1. **Points adjacent to another stratum.** Fix G′. Put W′ := C_{G′} ∩ (closure(Δ_{G′}) ∖ Δ_{G′}), a compact analytic set by (F5), so that A_{G′} = C_{G′} ∖ W′.
   - By (F2), closure(A_{G′}) is the union of the irreducible components K of C_{G′} not contained in W′. Hence closure(A_{G′}) ∖ A_{G′} ⊂ ⋃_K (K ∩ W′).
   - Each such K is irreducible of dimension ≤ 1 and K ⊄ W′. So K ∩ W′ is a proper analytic subset of K. It is finite if dim K = 1, and empty if K is a point.
   - So the set F_1 := ⋃_{G′} (closure(A_{G′}) ∖ A_{G′}) is finite.
2. **Points not adjacent to another stratum.** Let w ∈ A_G ∖ F_1.
   - For G′ ≠ G we have w ∉ A_{G′}, and w ∉ closure(A_{G′}) ∖ A_{G′}. So w has a neighbourhood missing every A_{G′} with G′ ≠ G (finitely many). Near w, therefore, B = A_G.
   - Also, w has a neighbourhood missing the closed set closure(Δ_G) ∖ Δ_G. So near w, B = A_G = C_G.
   - If w is a smooth point of C_G at which dim C_G = 1, then w is top-regular.
   - Hence Σ^top ⊂ F_1 ∪ ⋃_G (Sing(C_G) ∪ {isolated points of C_G}).
   - Sing(C_G) is nowhere dense in C_G (F1). Points of Sing(C_G) on 1-dimensional components form a nowhere dense analytic subset of a compact analytic set of dimension ≤ 1, so they are finite in number. Isolated points are finite (F1). So Σ^top is finite.
3. **Isotropy-special points.** Let w ∈ I_t lie in A_G ∖ (Σ^top ∪ Sing(C_G)), and put k := |Aut w|.
   - Every point of F_1 is top-special: it lies in the closure of a stratum different from its own. So w ∉ F_1, and by step 2, near w, B = C_G is a connected 1-dimensional complex manifold germ.
   - By upper semicontinuity, nearby points have |Aut| ≤ k.
   - Since |Aut| is not locally constant at w, there are points arbitrarily close to w with |Aut| < k, i.e. not in Z_k.
   - So Z_k ∩ C_G is an analytic subset of a connected 1-dimensional manifold germ which is not the whole germ. Hence w is an isolated point of the compact analytic set Z_k ∩ C_G.
   - By (F1) and (F4) (finitely many G and k), only finitely many such w exist. So I_t is finite.
4. **Components of R_t.** B has finitely many irreducible components (F1).
   - The 0-dimensional components are isolated points, hence top-special.
   - For each 1-dimensional component K, the set K ∖ Σ^top is connected (F3) and contained in R_t, so it lies in one component of R_t.
   - These sets cover R_t. ∎

## 2. The condition (NGD) and the two directions

Put 𝒮_r := ⋃_{|t|<r} Σ_t × {t} ⊂ ℬ_r.

**Definition 2.1 ((NGD)_r, "no genuine isotropy drop/split").**
- (N1) There are finitely many continuous maps σ_1, …, σ_N : Δ_r → M̄_g such that, for every |t| < r, the points σ_1(t), …, σ_N(t) are pairwise distinct and Σ_t = {σ_1(t), …, σ_N(t)}. (Equivalently, 𝒮_r → Δ_r is a finite covering map; over a disc every such covering is trivial.) The case N = 0 (all Σ_t empty) is allowed.
- (N2) The function (w, t) ↦ |Aut w| is locally constant on 𝒮_r and on ℬ_r ∖ 𝒮_r.

**(NGD)** means: (NGD)_r holds for some r > 0.

This is stated only in terms of closure(𝒱), the strata and |Aut|. No H is involved.

**Lemma 2.2 (uniqueness of sections).** Assume (N1). If s : Δ_r → M̄_g is continuous with s(t) ∈ Σ_t for all t, then s = σ_j for some j.

*Proof.* The sets E_j := {t : s(t) = σ_j(t)} are closed and pairwise disjoint (the σ_j(t) are distinct), and they cover Δ_r. Each E_j is the complement of the finite union of the other closed sets, so it is open. Δ_r is connected, so some E_j equals Δ_r. ∎

**Definition 2.3 (boundary trivialisation).** A *boundary trivialisation over Δ_r* is a homeomorphism H′ : B_0 × Δ_r → ℬ_r over Δ_r, written H′(z, t) = (H′_t(z), t), such that H′_t(B_0 ∩ Δ_G) = B_t ∩ Δ_G for every boundary stratum G and every t. It satisfies **(AP)** if |Aut H′_t(z)| = |Aut z| for all z ∈ B_0 and |t| < r.

By Lemma 1.0, H restricted to B_0 × Δ_r is a boundary trivialisation with H_0 = id.

### Theorem 1 ((NGD) ⇒ an (AP)-trivialisation, obtained by modifying H)

**Theorem 1.** Assume (R1), (R2) and (NGD)_r. Then there are r′ ∈ (0, r] and a boundary trivialisation H′ over Δ_{r′} with the following properties:
- H′_0 = id;
- (AP) holds;
- H′_t = H_t∘Ψ_t, where Ψ : B_0 × Δ_{r′} → B_0 × Δ_{r′} is a homeomorphism over Δ_{r′} that is the identity outside ⋃_{z∈I_0} D_z × Δ_{r′}, the D_z being small disjoint closed discs in R_0;
- H′_t(Σ_0) = Σ_t.

*Proof.*
1. **Labelling the sections.** Let σ_1, …, σ_N be as in (N1).
   - Σ_0 = {σ_j(0)}, so we may index the sections by z ∈ Σ_0, with σ_z(0) = z.
   - For z ∈ Σ^top_0, the map t ↦ H_t(z) is continuous, and by Lemma 1.3 (applied to h = H_t) it takes values in Σ^top_t ⊂ Σ_t. By Lemma 2.2 it is a section σ_j, and evaluating at t = 0 shows it is σ_z. So **H_t(z) = σ_z(t) for z ∈ Σ^top_0.**
   - Again by Lemma 1.3, Σ^top_t = H_t(Σ^top_0) = {σ_{z′}(t) : z′ ∈ Σ^top_0}. The values σ_z(t), z ∈ Σ_0, are pairwise distinct. So for z ∈ I_0 we get σ_z(t) ∉ Σ^top_t, i.e. **σ_z(t) ∈ I_t ⊂ R_t for z ∈ I_0.**
2. **Pulled-back targets.** For z ∈ I_0 put τ_z(t) := H_t^{-1}(σ_z(t)), i.e. the first coordinate of H^{-1}(σ_z(t), t).
   - τ_z is continuous, because H|_{B_0×Δ} is a homeomorphism (Lemma 1.0).
   - τ_z(0) = z.
   - τ_z(t) ∈ H_t^{-1}(R_t) = R_0 (Lemma 1.3).
3. **Discs.** I_0 is finite (Lemma 1.4) and contained in the topological surface R_0, which is open in B_0. Choose, for z ∈ I_0, closed sets D_z ⊂ R_0, pairwise disjoint, with homeomorphisms χ_z : D_z → 𝔻̄ (closed unit disc) such that χ_z(z) = 0 and χ_z^{-1}(𝔻) is open in B_0. (Take closed round discs in a chart ℝ² ≅ U ⊂ R_0 around z, small enough to be disjoint.)
   - D_z is connected and contained in R_0, on which the stratum is locally constant. So D_z ⊂ Δ_{G_z}.
   - Choose r′ ∈ (0, r] such that τ_z(t) ∈ χ_z^{-1}({|w| < 1/2}) for all z ∈ I_0 and |t| < r′. This is possible by continuity of τ_z at 0, since there are finitely many z. Put a_z(t) := χ_z(τ_z(t)), so |a_z(t)| < 1/2.
4. **The push maps.** For |a| < 1/2 define P_a : 𝔻̄ → 𝔻̄ by P_a(w) := w + (1 − |w|)a. Then:
   - (w, a) ↦ P_a(w) is continuous;
   - P_0 = id, P_a(0) = a, and P_a = id on ∂𝔻;
   - **P_a maps 𝔻̄ into 𝔻̄**, since |P_a(w)| ≤ |w| + (1 − |w|)|a| ≤ 1;
   - **P_a maps 𝔻 into 𝔻**: for |w| < 1, |P_a(w)| ≤ |w| + (1 − |w|)/2 < 1;
   - **P_a is injective**: if P_a(w_1) = P_a(w_2), then w_1 − w_2 = (|w_1| − |w_2|)a, so |w_1 − w_2| ≤ |w_1 − w_2|/2, hence w_1 = w_2;
   - **P_a is a bijection of 𝔻̄**: by invariance of domain, P_a(𝔻) is open in ℂ, and it lies in 𝔻. It is also closed in 𝔻, because P_a(𝔻) = P_a(𝔻̄) ∩ 𝔻 (P_a is injective and maps ∂𝔻 onto ∂𝔻) and P_a(𝔻̄) is compact. So P_a(𝔻) = 𝔻 by connectedness, and P_a(𝔻̄) = 𝔻̄. A continuous bijection of a compact Hausdorff space is a homeomorphism.
5. **Ψ.** Define Ψ_t(w) := χ_z^{-1}(P_{a_z(t)}(χ_z(w))) for w ∈ D_z, and Ψ_t(w) := w for w ∉ ⋃ D_z. Put Ψ(w, t) := (Ψ_t(w), t) on B_0 × Δ_{r′}.
   - **Continuity.** B_0 is covered by the finitely many closed sets D_z and F := B_0 ∖ ⋃_z χ_z^{-1}(𝔻). On D_z ∩ F = χ_z^{-1}(∂𝔻) the two formulas agree (both give the identity). Both formulas are jointly continuous in (w, t). So Ψ is continuous by the pasting lemma.
   - **Bijectivity.** Each Ψ_t is a bijection of B_0 that maps each D_z onto itself.
   - **Homeomorphism.** For r″ < r′, Ψ restricts to a continuous bijection of the compact Hausdorff space B_0 × {|t| ≤ r″} onto itself, hence a homeomorphism. The open sets B_0 × Δ_{r″} cover B_0 × Δ_{r′}, so Ψ^{-1} is continuous.
   - **Normalisation and strata.** Ψ_0 = id, since a_z(0) = 0. Ψ_t preserves every stratum, because D_z ⊂ Δ_{G_z}.
   - **Special points.** Ψ_t(z) = χ_z^{-1}(a_z(t)) = τ_z(t) for z ∈ I_0, and Ψ_t(z) = z for z ∈ Σ^top_0 (because D_z ⊂ R_0).
6. **H′.** Put H′ := H∘Ψ, i.e. H′_t = H_t∘Ψ_t.
   - It is a composition of homeomorphisms over Δ_{r′}: Ψ, then H|_{B_0×Δ_{r′}} : B_0 × Δ_{r′} → ℬ_{r′} (Lemma 1.0). So it is a homeomorphism.
   - H′_0 = id, and H′_t(B_0 ∩ Δ_G) = H_t(B_0 ∩ Δ_G) = B_t ∩ Δ_G.
   - For z ∈ Σ^top_0, H′_t(z) = H_t(z) = σ_z(t) (step 1). For z ∈ I_0, H′_t(z) = H_t(τ_z(t)) = σ_z(t). Hence **H′_t(z) = σ_z(t) for all z ∈ Σ_0**, and H′_t maps Σ_0 bijectively onto Σ_t.
7. **(AP).** Fix z ∈ B_0 and |t| < r′, and let ℓ(s) := (H′_{st}(z), st) for s ∈ [0, 1], a continuous path with ℓ(0) = (z, 0).
   - If z ∈ Σ_0, then ℓ(s) = (σ_z(st), st) ∈ 𝒮_r.
   - If z ∉ Σ_0, then H′_{st}(z) ∉ Σ_{st}, because H′_{st} is injective and maps Σ_0 onto Σ_{st}. So ℓ lies in ℬ_r ∖ 𝒮_r.
   - In both cases (N2) says |Aut| is locally constant along the connected path ℓ, hence constant. So |Aut H′_t(z)| = |Aut z|. ∎

*Points handled with care (cf. the task).*
- Points where several pieces meet, isolated points, singular points, and points adjacent to deeper or shallower strata are all in Σ^top_0. There H′ = H, and H already follows the unique continuation σ_z; (NGD) is exactly the requirement that |Aut| is constant along that continuation.
- Excess-isotropy points on pieces (I_0) are pushed inside discs in their own piece and stratum.
- Uniformity in t is obtained by taking r′ as a minimum over the finite set I_0.

### Theorem 2 ((AP)-trivialisation ⇒ (NGD))

**Theorem 2.** Assume (R1), (R2). If some boundary trivialisation H′ over Δ_r satisfies (AP) (H′_0 = id is not needed), then (NGD)_r holds.

*Proof.*
1. **(N1).** By Lemma 1.3 applied to h = H′_t, H′_t(Σ_0) = Σ_t for every t. Σ_0 is finite (Lemma 1.4). So σ_z(t) := H′_t(z), z ∈ Σ_0, are continuous maps whose values at each t are pairwise distinct (H′_t is injective) and fill Σ_t.
2. **|Aut| on B_0 ∖ Σ_0.** On B_0 ∖ Σ_0 = R_0 ∖ I_0 the function |Aut| is locally constant: R_0 is open in B_0, and |Aut|_{R_0} is locally constant at every point outside I_0.
3. **(N2).** The homeomorphism H′ maps Σ_0 × Δ_r onto 𝒮_r and (B_0 ∖ Σ_0) × Δ_r onto ℬ_r ∖ 𝒮_r. By (AP), |Aut|∘H′(z, t) = |Aut z|.
   - On Σ_0 × Δ_r (Σ_0 discrete) this function is locally constant.
   - On (B_0 ∖ Σ_0) × Δ_r it is locally constant by step 2.
   - Transporting by H′ gives (N2). ∎

**Corollary 2.4.** Under (R1), (R2): (NGD) holds iff, for some r > 0, some boundary trivialisation over Δ_r satisfies (AP); and then one may take it of the form H∘Ψ with H′_0 = id. In particular, **if (NGD) fails, no boundary trivialisation over any disc Δ_r, whatever its value at t = 0, satisfies (AP)**: the failure is a property of the analytic family closure(𝒱) alone.

## 3. Concrete form of (NGD)

Let R be a connected component of R_0 (there are finitely many, Lemma 1.4). Then R ∖ I_0 is connected (a connected surface minus a finite set) and |Aut| is locally constant on it, so |Aut| takes a constant value k_R there.
- k_R = min_R |Aut|.
- Every z ∈ I_0 ∩ R has |Aut z| > k_R. Indeed, the points near z other than z have order k_R, so |Aut z| ≥ k_R by upper semicontinuity, and equality would make |Aut| locally constant at z.
- By Lemma 1.3, H_t(R) is a connected component of R_t.

(In the terminology of the task file's Prop. 2, R is a piece E° with finitely many further points removed, and k_R = k_E.)

**Proposition 3.** Assume (R1), (R2). Then (NGD) holds iff the following four conditions hold.
- **(α) (no isotropy change at topologically special points).** For each z ∈ Σ^top_0: |Aut H_t(z)| = |Aut z| for all sufficiently small |t|.
- **(α′) (no generic drop along pieces).** For each component R of R_0 and all sufficiently small |t|: every point of H_t(R) ∖ I_t has |Aut| = k_R.
- **(β) (excess points continue uniquely, with their order).** For each z ∈ I_0 and every sufficiently small open neighbourhood N of z in M̄_g, the following holds for all sufficiently small |t| (depending on N): I_t ∩ N is a single point, and its order is |Aut z|.
- **(γ) (no excess points from elsewhere).** For every open N ⊃ I_0, we have I_t ⊂ N for all sufficiently small |t|.

("Sufficiently small" in (β) means: contained in β(z, ρ_z) for some ρ_z > 0 depending on z. In the proof below, ρ_z is any radius smaller than the distance from z to I_0 ∖ {z}.)

*Remarks on H-independence.*
- Any boundary trivialisation H″ with H″_0 = id satisfies H″_t(z) = H_t(z) for z ∈ Σ^top_0. Both are continuous sections of ⋃_t Σ^top_t × {t} = H(Σ^top_0 × Δ), which is a disjoint union of finitely many graphs, so the argument of Lemma 2.2 applies.
- So (α) does not depend on H. Likewise, H_t(R) is the component of R_t that contains points close to R. Proposition 3 is a check-list; (NGD) itself is the intrinsic condition.

*Relation to the task file.*
- (α′) is the "no drop" alternative of Prop. 2(b),(c), for every piece.
- For isolated points of B_0 ∩ Δ_{G_z}, (α) is the "no drop" alternative of Prop. 3; that proposition shows the alternative is all-or-nothing on a punctured disc.
- (β) and (γ) exclude three phenomena: excess points disappearing for t ≠ 0 (a point drop), splitting into several excess points, and new excess points appearing (from nowhere, or out of top-special points).

*Proof of "(NGD) ⇒ (α), (α′), (β), (γ)".* Let r′, H′ = H∘Ψ and σ_z be as in Theorem 1, so H′_t(z) = σ_z(t) for z ∈ Σ_0, and H′ has (AP).
- **(α).** For z ∈ Σ^top_0, H_t(z) = H′_t(z), and |Aut H′_t(z)| = |Aut z|.
- **(α′).** Ψ_t maps each D_z onto itself and is the identity elsewhere, so Ψ_t(R) = R and H′_t(R) = H_t(R). By Lemma 1.3 and (AP), H′_t(I_0) = I_t. So H_t(R) ∖ I_t = H′_t(R ∖ I_0), whose points have order k_R by (AP).
- **(β).** Let N be an open neighbourhood of z with closure(N) ∩ I_0 = {z}. By continuity of the sections, for small |t| we have σ_z(t) ∈ N and σ_{z′}(t) ∉ N for z′ ∈ I_0 ∖ {z}. Since I_t = H′_t(I_0) = {σ_{z′}(t) : z′ ∈ I_0}, we get I_t ∩ N = {σ_z(t)}, which has order |Aut z|.
- **(γ).** I_t = {σ_z(t) : z ∈ I_0}, and σ_z(t) → z. ∎

*Proof of "(α), (α′), (β), (γ) ⇒ (NGD)".*
1. **Choices.**
   - Let ε(τ) := sup{d(H_s u, u) : u ∈ B_0, |s| ≤ τ}. Then ε(τ) → 0 (task file 0.3). For w ∈ B_t, putting u := H_t^{-1}w gives d(u, w) ≤ ε(|t|).
   - For z ∈ I_0 write k_z := |Aut z| and R(z) for the component of R_0 containing z.
   - Choose ρ > 0 such that: the closed balls β̄(z, 2ρ), z ∈ Σ_0, are pairwise disjoint; for z ∈ I_0, β̄(z, 2ρ) ∩ B_0 ⊂ R(z) (possible since R(z) is open in B_0); and β(z, ρ) is "sufficiently small" in the sense of (β).
   - Choose r_1 > 0 such that, for |t| < r_1: (α) and (α′) hold for all of the finitely many z, R; (β) holds with N = β(z, ρ) for all z ∈ I_0, giving I_t ∩ β(z, ρ) = {ζ_z(t)} with |Aut ζ_z(t)| = k_z; and (γ) gives I_t ⊂ ⋃_{z∈I_0} β(z, ρ).
   - Choose r_2 ≤ r_1 with ε(r_2) < ρ.
2. **Claim A.** For |t| < r_2 and z ∈ I_0, every w ∈ B_t ∩ β(z, ρ) with |Aut w| ≥ k_z equals ζ_z(t).
   - u := H_t^{-1}w satisfies d(u, z) < 2ρ, so u ∈ R(z) and w ∈ H_t(R(z)) ⊂ R_t.
   - If w ∉ I_t, then (α′) gives |Aut w| = k_{R(z)} < k_z, a contradiction.
   - So w ∈ I_t ∩ β(z, ρ) = {ζ_z(t)}.
3. **ζ_z(t) → z as t → 0.** For any ρ′ < ρ that is sufficiently small for (β), the set I_t ∩ β(z, ρ′) is a single point for small |t|. It lies in I_t ∩ β(z, ρ) = {ζ_z(t)}, so d(ζ_z(t), z) < ρ′ for small |t|. Choose r ≤ r_2 with d(ζ_z(t), z) < ρ/2 for |t| < r and all z ∈ I_0.
4. **Continuity of ζ_z on Δ_r.** Let t_n → t_1 in Δ_r, and let w be a limit of a subsequence of ζ_z(t_n) (M̄_g is compact).
   - (w, t_1) ∈ closure(𝒱) ∩ (∂M̄_g × Δ) (closed), so w ∈ B_{t_1}.
   - d(w, z) ≤ ρ/2 < ρ.

   - By Claim A, w = ζ_z(t_1). Every subsequence therefore has a further subsequence converging to ζ_z(t_1), so ζ_z(t_n) → ζ_z(t_1).
5. **(N1).** Put σ_z(t) := H_t(z) for z ∈ Σ^top_0 and σ_z(t) := ζ_z(t) for z ∈ I_0.
   - These maps are continuous.
   - Σ^top_t = H_t(Σ^top_0) (Lemma 1.3), with distinct values; I_t = {ζ_z(t)} by (β) and (γ), with distinct values, since the balls β(z, ρ) are disjoint; and Σ^top_t ∩ I_t = ∅.
   - So Σ_t = {σ_z(t) : z ∈ Σ_0}, with pairwise distinct values.
6. **(N2) on 𝒮_r.** |Aut σ_z(t)| = |Aut z| for |t| < r: by (α) for z ∈ Σ^top_0, and by (β) for z ∈ I_0. The graphs of the σ_z are finitely many, pairwise disjoint and closed in 𝒮_r, hence also open in 𝒮_r. So |Aut| is locally constant on 𝒮_r.
7. **(N2) on ℬ_r ∖ 𝒮_r.** Let (w, t) ∈ ℬ_r ∖ 𝒮_r. Then w ∈ R_t ∖ I_t. Let R be the component of R_0 containing u := H_t^{-1}(w).

   - Let (w′, t′) ∈ ℬ_r ∖ 𝒮_r be close to (w, t). Then u′ := H_{t′}^{-1}(w′) is close to u (H^{-1} is continuous, Lemma 1.0), so u′ ∈ R (R is open in B_0). Hence w′ ∈ H_{t′}(R) ∖ I_{t′}, and |Aut w′| = k_R by (α′).
   - So |Aut| is locally constant on ℬ_r ∖ 𝒮_r. ∎

## 5. What failure of (NGD) is, concretely

By Corollary 2.4 the failure is genuine: no boundary trivialisation over any disc satisfies (AP). By Proposition 3, (NGD) fails iff one of the following holds along some sequence t_n → 0.

- **(F-α) Isotropy change at a top-special point z.** Examples of such z: a node of B_0, a meeting point of pieces, a point adjacent to another stratum, an isolated point. Here |Aut H_{t_n}(z)| ≠ |Aut z|. By upper semicontinuity, for small t this can only be a drop (<).
  - At isolated points of B_0 ∩ Δ_{G_z}, Prop. 3 of the task file shows that t ↦ H_t(z) is holomorphic, and that the drop then holds on a whole punctured disc.
  - The Q-points of Cor. C.3(d) (draft) are of this kind when isolated.
- **(F-α′) Generic drop along a piece R.** All points of H_t(R) ∖ I_t have order k′ < k_R, for 0 < |t| < r. It is all-or-nothing by Prop. 2(b) of the task file, and "rise" is impossible by Prop. 2(a).
  - By 2.1–2.3 of the task file: in a Kuranishi chart at a generic J ∈ R with A = Aut(J), the lifted family 𝒮 ⊂ D × Δ maps with degree m ≥ 2 onto c̃ × Δ under (P, t). So the lifted transported boundary is non-reduced over c̃ at t = 0, with ≥ 2 sheets permuted by A that coalesce at t = 0.
  - The drop is caused by elements of A acting non-trivially on the stratum germ D (2.3).
- **(F-β) Behaviour of an excess point z ∈ I_0 on a piece R, with k_z > k_R.** Assume no generic drop. Then the points of order ≥ k_z near z, for t small, are exactly the points of I_t near z with that order (Claim A of §3 shows this whenever (α′) holds). Write A := Aut(z) and q : B → q(B) for the chart at z. Near z, B_0 is the image of the A-invariant lifted curve c̃_0 = q^{-1}(B_0) ∩ B.
  - c̃_0 is an A-invariant curve germ. Its generic points have stabiliser of order k_R < k_z = |A|, and its only point with stabiliser A near 0 is 0 itself.
  - For t ≠ 0 put c̃_t := q^{-1}(B_t) ∩ B. A point of B_t near z of order ≥ k_z lifts to a point of c̃_t whose stabiliser has order ≥ k_z = |A|, hence equals A. So it lifts to c̃_t ∩ Fix(A), and the lift is unique: the fibre of q is a single A-orbit, and that orbit is a fixed point.
  - Hence, given (α′), (β) at z is equivalent to two conditions for small t ≠ 0. **(β1)** The A-invariant curve c̃_t meets Fix(A) near 0 in exactly one point. **(β2)** No point of c̃_t near 0 outside Fix(A) has stabiliser of order > k_R. Here (β2) excludes excess points of intermediate order k_R < k < k_z near z; these lift to Fix(C) for subgroups C < A with k_R < |C| < k_z.
  - Failure of (β1) means c̃_t ∩ Fix(A) near 0 is empty (a point drop) or has ≥ 2 points (a splitting), for t = t_n → 0.
  - **The alternative is all-or-nothing.** 𝒳 := (Fix(A) × Δ) ∩ (q × id)^{-1}(ℬ) is an analytic set near (0, 0) (by (R1)), and its fibre over t = 0 near 0 is Fix(A) ∩ c̃_0 = {0}. So the projection 𝒳 → Δ is finite near (0, 0). Each 1-dimensional irreducible component of 𝒳 at (0, 0) is a finite branched covering of a small disc, distinct components meet only over t = 0 after shrinking, and 0-dimensional components are {(0, 0)}. Hence #(c̃_t ∩ Fix(A) near 0) is constant on a small punctured disc: (β1) holds or fails on a whole punctured disc. The same argument with Fix(C) for each subgroup C applies to (β2). (Standard local analytic geometry, cited from memory.)
- **(F-γ) Excess points of B_t accumulating, as t → 0, at a point of Σ^top_0.** By Claim A, under (α′) they cannot accumulate at a point of R_0 ∖ I_0. Indeed, a limit point would lie in R_0 and have order ≥ the excess order > k_R; a short variant of Claim A rules this out.

*Proof of the (F-γ) remark.* Suppose w_n ∈ I_{t_n}, t_n → 0, w_n → u ∈ R_0 ∖ I_0, and (α′) holds. Then u lies in some component R. For large n, H_{t_n}^{-1}(w_n) ∈ R (by the ε-estimate, since R is open), so w_n ∈ H_{t_n}(R). The order of w_n is not the generic one, so by (α′) it is > k_R. By upper semicontinuity (Z_k closed), |Aut u| > k_R. This contradicts u ∈ R ∖ I_0. ∎

So, given (α′), excess points at small t live near I_0 ∪ Σ^top_0 only.

**Which failures are excluded by known criteria.**
- (K_z) for all z ∈ B_0 (Theorem C.7) gives (AP) for H itself on a disc, hence (NGD) by Theorem 2.
- More locally: if Aut(z) acts trivially on the germ of the stratum locus D at z (Remark C.9(b)), then no failure occurs at z.
- In particular, the elliptic-tail case (C.9(d)) satisfies (NGD).
- So failures are confined near the closed set F of Theorem C.8.
